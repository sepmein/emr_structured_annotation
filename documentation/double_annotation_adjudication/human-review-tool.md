# 全量双人标注人工裁决工具

本工具把已有双人标注、AI样例和逐点处理记录批量格式化为审查网页。数据整理复用当前Schema读取、原始导出解析和关系拓扑校验；不调用模型或外部服务，不重新进行医学裁决。源码入口为[review_tool.py](../../emr_annotation/adjudication/review_tool.py)，页面维护源为[human_review.html](../../emr_annotation/adjudication/templates/human_review.html)。

## 页面审查方式

- 左侧按项目、任务号、病例理由及审查状态查找病例；含原未决点或既有抽查问题的病例可单独筛选。
- 每例按原文位置组合重叠标注，分别显示标注A、标注B和当前裁决。A/B按该例annotation ID排序，仅为阅读代号。双方一致的内容、AI新增内容、病例分类、关系及无效选区均保留，全部追溯点恰好归入一个组。
- 可修改实体起止、标签及适用属性，选择A/B作为本组裁决，删除或新增实体，新增/删除有向关系。实体删除或标签变化会移除受影响关系，并要求重新审查关系。
- 原始全文可展开；直接选择文字新增实体。浏览器使用Unicode字符偏移，和原始Python `[start,end)` 一致，包括非BMP字符。原文、患者键和原任务归属不可编辑。
- 逐点或整组选择认可、修改、删除、暂缓。点击“核查本组全部点”自动记录实际操作，补充意见可选，原未决点也无需手动填写理由。组级选项和未应用的意见随草稿保存，选择后仍需点击核查才会更新点级状态。
- 审查人在同批次内填一次即可自动沿用；已填写过的病例保留原审查人。浏览器保存默认审查人，新窗口也可从服务器最近的审查记录取得默认值。
- 病例审查意见及确认按钮直接显示，页面顶部和内容最下方均可确认。“一键核查并确认本例”表示用户已核查本例全文及已有问题，会核查尚未审查的点、确认全文及已知问题核查，并尝试完成全例确认；保留已有修改和明确暂缓的点，暂缓点不会被自动认可。
- “批量核查常规点”会跳过原未决点、已知问题所在组及已经处理的点。复制A/B、删除实体及批量核查直接执行，无重复弹窗；可通过历史版本恢复。

## 保存与确认

修改自动保存至该运行目录的`review_state.sqlite3`。每次保存递增版本并记录完整历史；可查看和恢复历史版本，恢复本身另存新版本。页面切换前等待全部修改保存，多窗口保存使用版本检查，冲突不覆盖另一窗口的内容。保存失败显示具体错误，未保存的修改仍在当前页面，并尽力写入本机浏览器的本地备份。刷新后，同一服务器版本可自动恢复未保存编辑；版本不同则保留本地备份并提示人工核对，不能覆盖更新的服务器草稿。浏览器存储不可用时会提示，不能将本地备份当成服务器保存成功。

“导出本页编辑备份”无需服务器保存成功，包含本页编辑和该批次浏览器中的未保存备份，用于网络失败或多窗口冲突时保留内容。此文件是排查/手工恢复依据，不直接作为服务器备份导入。

保存草稿与全例确认分开：未审查、原未决及明确暂缓的内容可以正常保存。全例确认需要审查人、全部追溯点非暂缓状态、必填属性完整，以及全文遗漏/新增实体核查确认；已知问题需要核查确认。确认失败保留已保存草稿及其版本，不将草稿误标为保存失败。修改已确认病例会回到审查中。自动操作记录只说明用户点击了什么，不编造医学裁决依据。

“导出审查备份”包含当前所有已保存草稿，可导入同一来源批次恢复。导入先整体校验，再一次事务写入；现有草稿有冲突时不覆盖。服务数据库保留历史，导出的备份包含各例最新草稿，不包含完整历史；需要保存完整历史时备份运行目录及数据库。

“导出已确认裁决”只导出已完成全例确认的病例，包含`records`和标准化`references`。状态为`human_reviewed_not_expert_gold`，`expert_signed=false`；工具不自动形成专家签署、不回写Label Studio，不自动替换已有AI参考、冻结划分或模型。当前关系仍为正例参考，未标实体对不自动成为无关系。

本轮导出尚未接入`training_data.ai_sample`，该入口严格接受AI样例状态。人工结果如需训练，须另行按最终参考准备与冻结流程核对监督完整性，不能改状态字符串冒充原AI样例。

## 构建与启动

从仓库根目录使用根环境Python，不需要模型依赖。新生成使用新的run_id，不覆盖旧网页和审查数据库。

```powershell
.venv/Scripts/python.exe -m emr_annotation.adjudication.review_tool build `
  --source-dir output/schema_training_trial_20261011_v001/adjudication/run_001/proposal_pass_004 `
  --schema data/schema_training_trial_20261011_v001/schema/pneumonia_config.xml `
  --review-findings output/schema_training_trial_20261011_v001/adjudication/run_review_examples_001/review_manifest.json `
  --output-dir output/schema_training_trial_20261011_v001/adjudication/run_review_tool_002

.venv/Scripts/python.exe -m emr_annotation.adjudication.review_tool serve `
  --root output/schema_training_trial_20261011_v001/adjudication/run_review_tool_002 `
  --port 4181
```

访问`http://127.0.0.1:4181/review.html`；旧六例网页地址`/review_examples.html`兼容显示此工具。服务仅监听本机回环地址。网页、病例快照、Schema、输入/源码哈希、版本和未提交状态位于本轮输出目录，真实病历不写入源码或测试夹具。
