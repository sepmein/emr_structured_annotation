# 双人标注可视化裁决工作台 v2

更新日期：2026-10-10。基于首批36例、795个既有核查项，改进差异展示与裁决入口。原始双标JSON、核查编号、审阅规则及统计口径不改变。

## 页面如何使用

页面分为病例队列、差异对照、裁决记录三栏。首屏直接显示选中病例的A/B结论与原文片段；分歧总览默认收起，需要时展开查看全批问题。

| 功能 | 看到什么 | 可以做什么 |
|---|---|---|
| 核查项分布条形图 | 病例、实体、属性、关系、结构问题与病例建议的需处理/一致项数 | 点击条形直接筛选该类核查项 |
| 病例四分类交叉表 | A为行、B为列，精确展示各类别组合的病例数 | 点击非零格筛选病例；可比较一致项和两例结论分歧 |
| 实体原文高亮 | 同一个原文片段并排展示两人的实际跨度，绿=精确共同、橙=A不同、紫=B不同 | 点击高亮词或选区表行，定位该选区并打开对应裁决项 |
| 实体选区对照表 | 按重叠跨度分组，分别列出A/B的全部标签和偏移；提示边界、标签、数量、属性、多标签等差异 | 逐组选区核查；分组只帮助阅读，不改变严格匹配或自动确定谁正确 |
| 属性对照表 | 中文字段名、A/B中文选项、漏填与已填差异 | 点击行直接裁决；选填空白与无法判断不混同 |
| 关系方向图 | A/B实际有向连接、节点当前标签、关系序号；缺类型边用虚线、多标签节点用警示边框 | 点击边定位关系记录；点击节点返回实体核查。长边绕开中间节点，避免把指标分别指向数值/单位误看成链式连接 |
| 关系核查表 | 端点标签、原文、偏移、实际方向和是否记录类型 | 逐条处理；一侧无对应连接单独显示，不假装同位配对 |
| 病例复核与问题 | 36例复核建议、按侧列出的结构问题、具体修复说明 | 查看同错候选、技术问题与医学裁决理由 |
| 标签条形图与49标签表 | 精确共同/仅A/仅B的实体数量，严格F1及未覆盖标签 | 点击标签查看字典规则并筛选对应病例 |
| 完整核查清单 | 原有795项、稳定编号、原始核查状态与裁决状态 | 查到不在当前实体表中的病例级或结构核查项 |
| 原始结果追溯表 | 全部1060条导出result的独立编号与人可读概要 | 分页查看，并展开单条原始字段 |

## 裁决记录

选择核查项后，右侧显示两人的人可读答案和对应规则。“采用A/B为候选”仅填入建议答案，不自动改为已裁决。病例四分类有选择框；实体、属性和关系候选按结构保留具体跨度/标签/字段/端点，并可继续编辑。

签署仍填写：最终答案、证据偏移、规则、原因类别、理由、裁决人、时间、是否回标。导出时检查已裁决记录的必要签署字段。未裁决项仍可作为草稿导出；已裁决不是Label Studio已经修复或训练数据已经冻结。

本地草稿使用v1的同一个来源/规则绑定键，保持原795项ID和`version=1.0`的裁决导出合同。可导入旧版导出的裁决记录，原答案和签署状态保留。导入验证来源、配置/规则哈希与核查ID，拒绝属于其他批次或重复ID的记录。正式记录仍应导出保存。

原始一致性图表不随裁决答案改变；签署进度单独显示。项目内A/B身份固定；跨项目汇总明确提示不是同一对人。标签未出现时F1记不可评价，不记100%。

## 原文和偏移

新页面加入最小原文展示片段，片段覆盖双人已标选区及病例建议证据，并记录原文起止坐标。带直接身份字段和长编号的展示内容采用等字符长度遮盖，以免改变偏移。原文导出不变；此遮盖不构成完整去标识化验收。

浏览器使用Unicode字符序列定位，与当前审计脚本的Python字符坐标相同；不会因emoji等非BMP字符按JavaScript UTF-16切片而漂移。若未来项目导出使用UTF-16偏移，须先明确该批偏移合同，不能无声切换。

同选区多标签、重复实体和导出`value.text`不符均保留在表格及原始详情中。高亮以精确原文片段及原始start/end为准，不能修复或掩盖既有导出差异。只读高亮和重叠分组不会变更病例/实体/属性/关系的核查记录。
