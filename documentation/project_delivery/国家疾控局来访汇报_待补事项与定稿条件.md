## 初步结果的主页面

1. **实体质量。** 同一人工裁决测试集，逐标签比较正则、训练前模型、训练后模型；展示参考数量、TP/FP/FN、精确率、召回率、F1及差值。主页面优先展示12个症状分组标签，附表保留49类。无参考实体的类注明“本批不可验证”，保留误报。
2. **判别质量。** 先明确小型模型的输出类别和参考字段，再展示总体准确率、逐类P/R/F1、混淆矩阵及类别数量。实体提及识别不能代替否定状态或病例判断准确率。
3. **运行速度。** 同一版本和同一测试任务，展示成功延迟P50/P95、有效吞吐、全部失败率、硬件及计时范围；另报文本覆盖和截断。负责人已确认最终对照本地大模型，可先用外部模型测试。已实现[分布图及容量情景工具](../model_evaluation/model-speed-capacity-comparison.md)，当前仅虚构记录演示；正式医院容量需同资源本地持续负载与业务量。规则本地CPU抽取与模型NER+RE HTTP端到端耗时暂分列，不能直接计算倍数。

有条件时补充人工标注效率及经过审核的原文复核案例，不能以推理快直接推导人工节省时间。

## 当前必须取得的输入

| 输入 | 决定什么 | 当前状态 |
|---|---|---|
| 判别模型的目标类别 | 训练目标、参考数据字段、准确率分母和混淆矩阵 | 尚未确认；XML病例四分类不能自动当作负责人意图 |
| 训练前任务模型及初始化协议 | 有意义的训练前后比较；是否从现有任务权重继续训练 | 尚未确认；基础语言模型加随机任务头不能冒充已可用任务基线 |
| 真人完整导出、医学裁决及稳定患者分组 | 正式数据统计、独立划分与真实评价 | 负责人预计约两天后可能取得部分数据，尚未收到本批裁决参考 |
| 实际训练产物、运行环境与硬件 | 模型重载、真实预测、token/截断覆盖、测速 | 当前约定的本地结果目录中未找到可引用的任务模型训练和真实测速产物；仓库外成果需补充位置 |
| 通用大模型及业务负载 | 两阶段对照、同资源持续吞吐与医院容量估算 | 已确定先外部模型、最终本地对照；具体模型/服务、硬件预算、各院日量及高峰待补 |
| 来访日期、时长、重点及支持诉求 | 篇幅、页面取舍、里程碑和最后一页 | 尚未确认 |

200条病历、400次标注是负责人估计的计划量，不是当前已完成量。400次独立标注也不能直接作为400条独立训练样本。

## 输入到位后的执行顺序

确认判别目标和训练前基线；冻结指南/XML及参考协议；保存完整导出、完成裁决；核查负例、患者及重复文本；锁定训练/验证/测试；在训练/验证集复核并冻结规则；检查token表示与截断；开展独立训练并重载指定产物；保存同一测试集三方原始预测及测速记录；生成结果表、错误案例和正式讲稿。

模型输出经人工修订后不能再当作原始模型预测；最终测试不得因结果不理想回流调参。缺少真实结果时，结果页继续标“待测”，虚构演示放在工具流程说明中。

## 本轮核查与资料入口

本轮核对了当前指南/字典的v2.2.0草案状态、XML的49个实体/9个区域属性/5种关系，以及历史Round 3汇总文件的200任务与158唯一文本口径。持久化示例均明确标记`synthetic_demo`：正则实际运行、训练数据预检、大模型离线预检及人工构造的测速制图分别记录，没有训练前后真实模型结果。
