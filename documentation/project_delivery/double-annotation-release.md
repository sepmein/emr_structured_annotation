## 发布和协作约定

本批HTML内嵌病历片段与标注结果。现有展示遮盖不等于完整去标识化验收；请选择受控内网或有访问权限的平台。公开展示应先生成虚构病例演示版。静态页面本身不提供登录或权限控制。

发布`index.html`到网站根目录后，用发布地址访问。尽量固定访问地址和浏览器；文件地址和网站地址的本地草稿不互通。迁移前在旧地址导出裁决JSON，再到新地址导入。发布包不包含浏览器里的个人草稿。

裁决答案在每个浏览器本地保存，并不会实时同步到其他裁决员。负责人先分配病例/标签范围，裁决员定期导出JSON并另存到受控共享目录。多人文件需要负责人核对核查ID、处理重复或冲突后再汇总；工具没有多人自动合并或并发锁定。导入整批记录前先导出当前草稿备份。

页面发布代表工具可用，不代表本批医学裁决完成。已签署结果仍需按裁决方案回标、复核和冻结；本工具不会自动写回Label Studio，也不会自动产生训练金标。

## 重新打包

从仓库根目录运行，下列输出目录必须不存在：

```powershell
python scripts/package_double_annotation_review.py --review-dir data/double_annotation_review_batch_001_20261009_v001/batch_1/review_2026-10-09_final --output data/double_annotation_review_batch_001_20261009_v001/batch_1/release_v2_2026-10-10
```

打包脚本仅复制已生成的页面和辅助材料，不修改原始标注或现有裁决页面。网页副本与原`review.html`逐字节一致；清单记录各文件SHA256。
