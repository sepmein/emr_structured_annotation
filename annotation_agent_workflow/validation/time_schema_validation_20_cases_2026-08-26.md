# 三层时间模型20例真实病历验证

## 结论先行

三层结构可以保留：**时间表达、事件时态、病程变化**三者在20份真实EMR中均有独立作用，没有发现必须增加“第四层”才能表达的案例。

但原始标签集合只能完整处理13/20例（65%），另外7/20例（35%）需要补充定义或标签；未发现完全无法表达的病例。这里的“100%概念覆盖”只表示三层框架能容纳这些现象，不表示现有XML已经达到100%可标。

建议的最小修改是：

1. 第一层仍只保留3个可见标签，但将“时间点”改名为“时间定位”，把绝对日期、相对时间、事件锚定时间和病程日序都放进去。
2. 第二层改成临床事件的属性，而不是把“当前、既往、计划”画成时间实体。
3. 第三层在原有病程状态上增加“未改善”和“稳定”。
4. 暂不增加BEFORE/AFTER事件图，也不要求标注者判断检验数值升降是否代表临床好转。

## 验证方法与适用范围

- 数据源：`/Users/sepmein/x/projects/emr_structured_annotation/output/emr_merged_202608.json`。
- 从非空文本中按时间线索类型进行目的抽样，共20份，以提高少见表达被发现的机会。
- 样本包含呼吸/发热、其他专科和纯检验记录。这适合做时间Schema压力测试，但不是“20份肺炎病例”的代表性随机样本，也不能据此估计标签在总体中的发生率。
- 审查单位是一份合并EMR任务；报告只使用T01-T20和去标识化短语，不保留姓名、患者ID、证件号或地址。
- “完整”表示现有三层和预设标签可直接表达；“部分”表示大框架可容纳，但缺标签或操作规则；“无法表达”表示需要新增维度。本轮分别为13、7、0例。

## 建议采用的时间Schema v1

### 第一层：时间表达（文本跨度）

| 标签 | 包含内容 | 例子 |
|---|---|---|
| 时间定位 | 绝对日期、相对时间、事件锚定时间、病程日序 | 2025-05-15、1周前、入院后、服药后、次日、今晨、第4天 |
| 时长/时间窗 | 持续长度或观察窗口 | 3天、5年余、近半个月、7天内、长期 |
| 频率 | 单位时间次数或周期 | 每日1次、每周、偶有、时有 |

这一步不需要再把“绝对日期、相对日期、事件锚定、第几天”拆成四个按钮。对未经培训的标注者，拆分会提高选择负担，而这四类都可以在导出后按规则或模型进一步标准化。

### 第二层：事件时态（事件属性）

保留“当前、既往、计划/未来、无法判断”。它回答的是“这个症状、检查或治疗相对于本次就诊处于什么时态”，不是识别一个新的时间词。

- “今仍有发热”：发热的时态=当前，同时病程=持续。
- “既往有高血压”：高血压的时态=既往。
- “拟复查CT”：复查CT的时态=计划/未来。
- 既往史、治疗计划等章节可由系统提供默认值；标注者只在文本与默认值冲突时修改。

### 第三层：病程变化（线索跨度）

建议使用7个标签：持续/仍存在、反复、加重、好转/缓解、未改善、稳定、已结束。

本轮只新增两个：

- **未改善**：无好转、未见缓解、效不佳。它表示经过一段时间或治疗后没有达到改善，不等同于“稳定”。
- **稳定**：病情稳定、无明显变化。它表示变化方向为零，也不等同于“持续存在”。

“持续下降趋势”暂不标成“好转”：血肌酐下降可能是改善，但某些指标下降可能是恶化。若项目以后需要连续检验趋势，应单独建立“测量值变化”模块（上升、下降、波动），避免让普通标注者作医学解释。

## 时间关系与边界规则

v1只需要两种语义关系：

- `TIME_OF`：时间表达 → 临床事件。
- `COURSE_OF`：病程线索 → 临床事件。

对于“服药后睡眠好转”，v1把“服药后”整体标为时间定位并关联“睡眠好转”；暂不要求再画“服药 AFTER→ 好转”的事件图。这样会损失一部分复杂时序结构，但显著降低普通标注者的学习成本和关系错误率。

频率与反复的界线：

- 能回答“一段时间内几次/多久一次”的，标频率，如“每日1次、每周、偶有、时有”。
- 表示同一临床事件消失后再次发生或多次发作，但没有稳定周期的，标反复，如“反复发热”。
- “反复咳嗽5年”可以同时有反复和时长，两者不互斥。

章节标题只作上下文，不作为时间实体。否定、主体和时态可以同时附着在同一个事件上，例如“近7天无境外旅居史”应保留时间窗，同时把旅居事件设为否定。

## 对项目的具体决定

1. 三层模型通过概念验证，继续使用，不增加第四层。
2. 第一层不增加按钮，只将“时间点”扩大并改名为“时间定位”。
3. 第二层采用事件属性，不让标注者给“当前/既往”单独画实体和关系。
4. 第三层增加“未改善、稳定”，最终为7个病程标签。
5. 暂缓复杂BEFORE/AFTER关系和检验数值趋势，避免把医学推断交给未经培训的标注者。
6. 下一轮应再抽取至少50份“呼吸/发热相关且有叙述文本”的病例，由2名标注者独立标注，按实体边界、TIME_OF、COURSE_OF和事件时态分别计算一致性；20例压力测试不能替代正式试标。

## 局限

- 本轮是目的抽样，不是随机样本；65%不能解释为全库准确率。
- 样本不是纯肺炎病例，因此证明的是时间Schema的通用可表达性，而不是肺炎专病的标签充分性。
- 当前结果是Schema审查，不是模型精度评估；还没有用金标准计算precision、recall或F1。
- 合并文本中存在重复段落、非标准日期和文本噪声，正式导入前仍需要质量检查。
