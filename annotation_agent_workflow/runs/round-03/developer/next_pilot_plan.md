Round 0—3已完成5→20→100→200例的AI双标压力测试，规则边界（B3、B5核心入口）已经过三次修订并趋于稳定。Round 3裁决复核显示：8个原始A/B分歧中7个可以用已有规则解释和统一，只有1个（R3-117）暴露了两套流程共同的系统性偏差（旧无关检查误当作当前索引病种），且该偏差已通过澄清写入v2.1.0，不需要再开一轮AI测试来验证同类问题。

按`ITERATION_PROTOCOL.md`的建议迭代规模，AI侧已经超额完成"第2轮：20例单人复测"和"第3轮：至少50例、2名独立试标者"的要求（Round 3做了200例双标）。**不建议再安排一轮AI标注**；下一步应是真人培训校准，这也是`schema_manifest_v2.1.0.json`状态字段`locked_for_next_human_case_level_calibration`一直标注的目标。

## 建议下一轮（真人Round 1）设计

### 前置准备（在启动真人标注前完成）

1. 将`empty_text`和`missing_context`两个data_issue枚举值实现为自动化预处理门禁脚本（可扩展`scripts/audit_deidentification.py`或新建`audit_case_form.py`），在样本进入标注队列前自动拦截并记录，不让真人标注员手工处理空任务。
2. 改用完整去标识化就诊文本而非当前的节选/截断文本，避免"数据本身不完整"和"标注规则不清楚"两类问题混淆。
3. 确认Label Studio导出配置包含实体`start`/`end`偏移和关系`from_id`/`to_id`，为后续计算严格实体F1和关系F1做准备。

### 样本组成

- 培训校准集：20例，讲评用，不计入正式一致性统计。取自Round 3的200例中未被判定为blocker的代表性案例（跨all four四分类、跨B1-B6入口）。
- 正式验证集：不少于30例，100%双标，且不得与Round 0/1/2/3的AI压力测试样本、培训集重叠——需从`output/emr_merged_202608.json`中重新分层抽样，可复用Round 3的分层框架（other/low_info/blank/acute_resp）但换随机种子。
- 必须覆盖的场景（沿用Round 3 `adjudication_review.md`第6节的对照案例设计）：
  1. 年度多次加重但本次好转 vs 本次明确加重伴低氧（验证B5边界）；
  2. 未改善但无客观证据 vs 症状加重伴湿啰音（验证B5边界）；
  3. 急性咳痰加湿啰音但无发热 vs 孤立湿啰音（验证B3边界）；
  4. 短而明确无关计划 vs "同前/如前"缺失病种（验证3.2C-5 vs 3.2D边界）；
  5. 当前明确病种稳定复诊 vs 只有旧无关检查和"治疗同前"（验证R3-117暴露的系统性偏差是否也影响真人标注）。

### 执行顺序

1. 两名有医学背景的真人标注员独立阅读v2.1.0指南、`label_dictionary_v2.1.0.md`和附录A快速判定卡。
2. 共同完成5例示范，讲解四分类判定顺序（3.3节）和B1-B6入口。
3. 独立完成20例培训校准集，讲评分歧，不覆盖原始答案。
4. 独立完成不少于30例正式验证集，提交前不得互看。
5. 先提交病例级判断，再提交结构化实体和关系，避免界面操作影响病例初判（沿用v2.1.0第11章操作流程要求）。
6. 裁决员逐例记录最终答案、引用规则、分歧原因分类（指南缺失/培训不足/操作错误/数据问题/Schema问题）、是否回标。

### 通过门槛（沿用Round 2 next_pilot_plan.md，未变更）

- 完成率至少95%，隐私blocker为0；
- 病例级Cohen's kappa至少0.80，且目标/待复核的重大漏标无重复模式；
- 核心肺部实体严格F1建议至少0.85；
- 关系F1建议至少0.80，且无病原断言反转；
- 所有major问题有书面裁决和回归例。

## 明确不建议的做法

- 不建议再增加一轮AI双标（如Round 4：300-500例）来"进一步验证规则"——AI探索性压力测试的边际收益已经很低，Round 3新发现的1个系统性偏差(R3-117)已通过澄清解决，继续加大AI样本量不能替代真人一致性证据。
- 不建议跳过20例培训集直接进入30例正式验证——`ITERATION_PROTOCOL.md`明确要求先培训后独立验证。
- 不建议在真人校准中混用v2.0.1和v2.1.0——`schema_manifest_v2.1.0.json`的`mode_rule`要求同一批标注员必须使用同一份锁定清单。
