## 2. 三条应写入下一版指南的规则

### 2.1 结构性肺病加重门槛

“近期”不用固定天数替代临床语境，但必须由原文把加重锚定到本次就诊、当前连续疗程或明确复诊原因。以下不能单独满足B5：

- “今年急性加重6次”等年度计数；
- “未改善、仍有、效果不佳”等持续语义；
- 根据痰培养换抗生素或继续抗感染治疗；
- 单独一个低氧数值而没有当前呼吸症状加重。

进入B5仍需同时满足：本次/近期咳嗽、咳痰或气促明确加重，加发热、低氧或湿啰音至少一项客观证据。治疗后好转不自动排除同一索引事件，但必须能确认加重、治疗和当前复诊属于同一疾病过程。

### 2.2 无发热时咳嗽、咳痰加湿啰音

B1的“急性发热加呼吸证据”和B3的“性质未明肺部异常”是两个独立入口。当前咳嗽/咳痰合并双肺湿啰音，可按B3判待专业复核，不要求同时存在发热。湿啰音单独出现、没有当前呼吸症状或其他支持证据时，仍不得机械进入待复核；它也绝不是目标病例直接证据。

### 2.3 短记录、无关记录和缺失上下文

- “建议电子喉镜”等短文本已经明确给出无关索引行为，且没有肺炎触发证据：非目标。
- “病情稳定，治疗同前”“慢性病复诊，病史同前”而被引用病种缺失：信息不足。
- 旧糖化血红蛋白、旧脑部MR等无关检查不能替代当前索引疾病，也不能据此把“治疗同前”判为明确非目标。
- “前症/如前”缺失，但当前仍是同一疗程复诊，且缺失内容可能包含肺炎直接证据：信息不足并回源补上下文。

## 3. 数据质量与重复样本

200个任务折叠为158个唯一文本；空文本27个任务属于同一空字符串组，另有8个非空重复组。原始观察一致率0.960、kappa 0.915；唯一文本观察一致率0.956、kappa 0.879。后者更适合描述规则压力，但二者都不能作为真人一致性证据。

建议导入门禁执行：

1. 空文本在进入医学标注前拦截，并结构化记录 `empty_text`；
2. “同上、如前、前症”但引用内容缺失时记录 `missing_context`，回源拼接后复标；
3. 精确重复按全文哈希折叠，保留原task_id到唯一文本ID的审计映射；
4. 近重复只标记，不在没有来源证据时自动删除；
5. `other`继续保留，但应要求非敏感的 `data_issue_note`。

## 4. Schema与标签效用门禁

### 建议进入XML变更提案

咳嗽、咳痰、气促/呼吸困难在20个任务中反复出现，并直接参与B1、B5和B6病例判断。三者具备清楚医学边界，不能由现有XML实体替代，符合标签效用门禁。建议在获批的下一版XML中加入；在此之前只进入病例级evidence，不计为当前XML实体漏标。

### 暂不增加通用“肺/胸部异常”按钮

B3证据可能是结节、磨玻璃影、胸水、条索影或听诊体征。把这些异质概念放入一个按钮，既容易与“肺部组织炎症”重叠，也会模糊影像与体征边界。当前先保留最小病例级evidence，并积累唯一案例。只有在多例中证明该实体能稳定提高病例判断或解释质量、且形成可复述边界后，才重新评估一个通用标签或少量子类。

### 不增加的按钮

不新增“未改善”“更换抗生素”“全年急性加重次数”“湿啰音”病例级按钮。这些问题可通过既有原文证据、指南组合规则和后处理解决，新增按钮只会扩大操作复杂度。
