# 决策日志

## v0.1.0

- 当前成人和儿童XML作为本轮可用标签事实来源。
- 病例级四分类仅为试标用暂定定义，等待项目负责人确认。
- 标签必须映射到病例纳入、排除、复核优先级或必要解释。
- 不直接修改XML；时间简化、关系简化和机械通气分组均作为提案。
- 明确排除GIS聚集人工标注。
- 采用“指南草案—真实病例试标—结构化反馈—逐条处置”的迭代方式。

## v0.1.1

- 根据5例反馈接受一个通用时间表达需求，但未修改XML。
- 未直接增加咳嗽/咳痰；先要求负责人确认症状是否能触发需复核。
- “无好转/效不佳”暂归持续语义；单次“今日加重”不等于进行性加重。
- 复杂胸部病程而无明确肺炎证据，Round 0暂归需专业复核，等待负责人确认。
- “稳定”、独立“频率”和复杂BEFORE/AFTER关系不进入v1。
