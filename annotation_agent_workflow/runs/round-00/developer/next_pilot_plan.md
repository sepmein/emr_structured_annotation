# Round 0五例试标计划

## 输入

- 指南：`annotation_guide_v0.1.0.md`
- 病例：`../inputs/pilot_cases_5.json`
- 当前成人/儿童XML及其SHA-256

## 必须验证的问题

1. XML没有“咳嗽”和明确时间表达标签时，标注者能否按规则停止并记录问题。
2. “无好转、仍有、今日加重、效不佳”在现有持续/进行性加重中是否有稳定边界。
3. 肺部炎症、肺炎诊断和肺部感染是否能稳定区分。
4. 否定词共同修饰多个事件时，关系负担是否可接受。
5. 暂定病例四分类是否能覆盖5例且不要求临床推断。

## 输出和进入下一轮条件

输出 `annotation_results.json`、`annotator_feedback.json`、`run_summary.md`。所有身份信息必须删除，反馈JSON必须通过Skill验证脚本。

本轮不以一致性分数为目标；重点是发现blocker和major问题。若5例中超过1例必须发明规则才能完成，不进入扩大样本，先修订指南。
