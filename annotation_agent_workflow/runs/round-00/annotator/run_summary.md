# Round 0医学试标摘要

## 结果

- 样本：5例真实EMR去标识化节选。
- 可按现有指南完成：4例。
- 阻塞：1例（T003，复杂胸部病程缺少明确时间和可用肺部证据标签）。
- 问题：1个blocker、4个major、0个minor。

## 主要发现

1. 当前XML不能保存“1周前、5年余、第4天、7天内”等明确时间，直接影响近期病例判断，是本轮唯一blocker。
2. “无好转、效不佳、今日加重、好转”的病程归类不完整，但它们主要影响优先级，不应扩张成大量标签。
3. 成人XML没有咳嗽、咳痰。是否增加不能仅按出现频率决定，必须先确认“症状但无肺部诊断”是否进入需复核。
4. 复杂胸部疾病不能靠标注者医学推断为肺炎；病例级“需复核”和“非目标”的最低证据边界需要负责人确认。

## 建议

暂不扩大到10例。先由指南开发者逐条处理ISS-001至ISS-005，并由项目负责人确认两项关键定义：症状组合是否可触发复核，以及复杂胸部疾病缺乏明确肺炎证据时如何分类。时间问题优先采用“一个通用时间表达标签或自动解析”，避免拆分多个按钮。
