# Round 2 指南开发决策日志

- 保持病例级四分类，不新增第五类；“数据错误”通过 `data_issue` 和门禁处理。
- 保持三层轻量时间模型，不增加新的人工时间类别。100例的新问题是索引事件归属和来源边界，而不是时间标签不足。
- 保持状态、时间、测量、标本、检测方式五类关系；检验错配通过记录组边界解决，不新增“检测事件”或因果关系。
- “少许慢性炎症”和稳定/非感染性间质性肺病不再无条件进入目标。
- 明确肿瘤、心衰等替代解释且无独立感染证据时判非目标。
- “支气管扩张伴感染”不映射为肺部感染；稳定复诊非目标，急性恶化加客观证据待复核，明确肺实质感染才目标。
- 纯检验列表与完整无关临床记录分开：前者信息不足，后者可判非目标。
- 只有当前文书明确引用并延续治疗/复查的旧证据才可并入索引临床事件。
- 隐私、跨记录拼接、重复段落和检验字段展平首先是预处理责任，不把清洗负担转给医学标注员。
- 本轮不修改生产XML；病例单选、三个症状、一个时间表达和数据问题控件保留为明确提案。
