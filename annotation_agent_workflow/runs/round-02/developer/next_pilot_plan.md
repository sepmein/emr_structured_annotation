# 下一轮真人校准计划

## 目标

验证v2.0.0在真人医学标注员中的可执行性，并区分医学分歧、数据问题和Label Studio操作问题。

## 前置条件

1. 使用 `guides/schema_manifest_v2.0.0.json` 锁定的“当前XML + 外部病例表单”模式；未批准的推荐标签不得混入同一批。
2. 导入前启用隐私、空白、重复、就诊拆分和检验成组门禁。
3. 使用完整去标识化就诊文本，不再用1600字符节选作病例金标准。
4. 输出必须保存实体字符起止偏移和关系端点ID。

## 样本

- 20例培训校准集，用于讲评，不纳入正式一致性验证。
- 另设不少于30例正式验证集，100%双标；与示范、培训、Round 1和Round 2均不重叠。
- 至少各3例覆盖：明确急性肺炎、慢性/非感染性间质性肺病、支气管扩张稳定/急性恶化、替代病因、连续诊疗旧影像、纯检验、完整无关病例、数据拼接。
- 另设5例门禁回归样本，不计入普通医学一致性分母。

## 执行

1. 两名具有医学背景的真人标注员独立阅读v2.0.0和快速判定卡。
2. 共同讲解5例；20例培训集讲评完成后，再进入不少于30例的独立验证集，提交前不得互看答案。
3. 先提交病例级，再提交结构化实体和关系，防止界面操作影响病例初判。
4. 裁决员逐例记录最终答案、规则、分歧原因、是否回标。

## 通过门槛

- 完成率至少95%，隐私blocker为0；
- 病例级Cohen's kappa至少0.80，且目标/待复核的重大漏标无重复模式；
- 核心肺部实体严格F1建议至少0.85；
- 关系F1建议至少0.80，且无病原断言反转；
- 所有major问题有书面裁决和回归例。
