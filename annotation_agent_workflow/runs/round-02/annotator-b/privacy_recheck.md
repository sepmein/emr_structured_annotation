# Round 02 B组隐私门禁复核

复核范围仅限 R2-032、R2-044、R2-084；未重新进行医学标注，也未修改原始标注结果。本文不记录任何敏感值。

## 逐例结论

| 任务 | 字面字段命中 | 启发式命中 | 复核结论 |
|---|---|---|---|
| R2-032 | 无 `姓名`、`住院号`、`床位号` 字面字段；无源 `patient_name` 键 | 命中“`患者` + 冒号 + 2—4个连续汉字”的姓名样式，同时命中“`患者` + 2—4个连续汉字 + 逗号”的姓名样式 | 不是字面字段命中，但不是误报。人工复核确认该位置是患者姓名槽位，应继续按隐私门禁阻塞。 |
| R2-044 | 无 `姓名`、`住院号`、`床位号` 字面字段；无源 `patient_name` 键 | 命中“`患者` + 2—4个连续汉字 + 逗号”的姓名样式 | 不是字面字段命中，但不是误报。人工复核确认该结构处于患者姓名槽位，应继续按隐私门禁阻塞。 |
| R2-084 | 存在 `姓名`、`住院号`、`床位号/床位` 字面字段；无源 `patient_name` 键 | 不依赖姓名样式启发式 | 明确的字面字段命中，不是误报；即使姓名值已替换，仍存在未安全移除的住院标识字段，应继续按隐私门禁阻塞。 |

## 总结

- R2-084 是确定的结构化字段门禁命中。
- R2-032、R2-044 是启发式命中，不是基于 `patient_name` 或 `姓名` 字面字段；结合局部语法槽位人工复核后，二者均不属于启发式误报。
- 建议门禁同时保留两层规则：结构化字段名强规则，以及“患者 + 姓名样式 + 标点/人口学或就诊叙述上下文”的高精度启发式规则。仅用 `姓名` 或 `patient_name` 字段检索会漏掉后两类正文姓名。
