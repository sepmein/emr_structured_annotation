# 下一轮儿童配置试标计划

1. 项目负责人同步旧字典、锁定清单；后端属性尚未适配时人工填写，并禁止将不完整预标注当最终答案。
2. 使用去标识化构造例23—28做操作培训及页面验收：逐实体面板、必填/选填、切换实体、导出属性归属、时间/测量方向。
3. 两名有医学背景标注员先独立校准至少20个去标识化真实儿童任务，覆盖阴性/可疑/计划、过去与持续、时间开始结束、暴露主体、标本缺项、同病原多检测、空文本与缺上下文。构造例不计真人真实病例结果。
4. 校准后依第15.2节另取不少于30例正式真人验证任务，不与示范/校准集重叠，100%独立双标。病例一致率/kappa、严格实体F1、各适用属性缺失率与一致性、方向敏感关系F1分别报告；保存偏移与实体ID，原始/唯一文本分母同时报告。不用历史AI结果代替新验收。
5. 每条分歧按指南、UI、数据、训练、schema限制分类裁决，补反馈与定向回标记录。按第14—15章既有门槛验收：至少90%无需临时规则完成、完成率≥95%、无未处理blocker，并达到预设双标门槛后才锁定发布。
