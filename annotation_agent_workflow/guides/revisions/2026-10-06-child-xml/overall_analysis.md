# 儿童 XML 与指南整体分析 — 2026-10-06

修订对象：annotation_guide_v2.1.1.md；结构事实来源：当前 pneumonia_children_config.xml。

## 主要差异与逐章更新顺序

1. 封面、文件说明、第2章：限定新版儿童操作适用范围，保留成人旧页操作，说明病例四分类和数据问题仍在外部表单。
2. 第5—6章：儿童删除独立断言、时态、标本和方法实体；肺部证据改为肺炎影像/肺炎诊断；新增体温、时间表达、周围聚集性发病现象、高风险职业史、境内外旅居史；测量不再有阈值判断。
3. 第7—8章：时间分为事件时间属性、原文时间表达及关系、可选病程变化；断言改为按选中实体填写的属性。空白不是默认答案。
4. 第9章：儿童只用发生时间、起始时间、结束时间、持续时长、测量；明确起点和终点，成人仍按旧版五类关系操作。
5. 第11—12章：逐例替换旧操作，追加实体属性、检验配对和时间关系案例；病例结论保持原有规则。
6. 第14—16章及附录：独立评价各属性、关系方向和漏填；历史AI压力测试不证明新schema可用；记录迁移、回标及发布阻塞。

## 发布前未完成事项

- label_dictionary_v2.1.1.md 与 schema_manifest_v2.1.0.json 尚未同步；不得将旧字典的儿童按钮说明覆盖本次修订。
- ml_backend/prompts.py 固定旧标签/关系；ModernBERT目前只解析实体和关系，未处理 Choices；当前预测不能视为完整新版标注。
- 检验属性在XML中不强制必填；指南要求对可配对检测记录逐项填写，非检测提及不能臆造结果。
- 机械通气不在临床属性面板作用域；时间表达也不在这些 Choices 的作用域。不要求标注员填写不存在的属性。
- 单选属性无法完整表示同一病原提及对应多次检测；不能将多个结果压成一条，须记录并交裁决。
- 本次为文档静态对齐，未重新导入Label Studio，也未开展真人双标。正式使用仍须实测。
