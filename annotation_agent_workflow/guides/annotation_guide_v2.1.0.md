## 1. 项目背景、目标与非目标



### 1.1 背景

本项目从电子病历中发现肺炎相关公共卫生信号，使后续人员能够回到原文复核。系统提供的是“值得复核的信号”，不是肺炎临床诊断，也不能替代医生、实验室或疾控调查结论。

### 1.2 最终用途

标签只在能支持以下至少一项用途时保留：

1. 判断病例是否进入肺炎相关复核队列；
2. 排除明显无关、纯既往或证据不足的病例；
3. 对复核优先级进行排序；
4. 说明系统为何给出该病例级判断。

### 1.3 本指南不处理

- 不标病例间空间聚集、14天聚集或传播链；这些由地址地理编码和GIS算法处理。
- 不根据医学常识补造原文没有写出的肺炎、病原或因果。
- 不穷举全部症状、疾病和用药。
- 不构建完整的时间图。
- 不把“病原体阳性”自动等同于“肺炎”。

### 1.4 三条总原则

1. **原文优先**：只标文本明确表达的内容。
2. **病例目标优先**：先判断该信息是否会改变病例纳入、排除、优先级或解释。
3. **不确定时保守**：不确定的实体不补造，不确定的关系不连；记录问题并交裁决。

## 2. 标注模型与Schema实施状态

本任务分成两个互相关联、但不能混为一谈的层次。

### 2.1 任务A：病例级判断

阅读整份文本，选择且只选择一个结论：

- 目标病例信号
- 待专业复核
- 非目标
- 信息不足

目标病例信号、待专业复核和非目标同时保存1—3条最小证据片段；信息不足允许0—3条，有可用残片时保留最小片段。若发现身份信息，设 `annotation_status=blocked_privacy`，立即停止医学判断，`case_decision=null`、`evidence=[]`。病例级证据可以引用当前XML未覆盖的症状原文，但不能把它私自标成不存在的实体。

### 2.2 任务B：结构化证据

按XML标注与病例判断相关的实体、断言、时间、测量、标本、检测方式和关系。结构化证据服务于模型训练和可解释性，不要求覆盖全文所有医学概念。

### 2.3 当前XML与v2推荐实施


| 功能               | 当前XML | v2推荐                 | 生产要求              |
| ---------------- | ----- | -------------------- | ----------------- |
| 病例级四分类           | 无     | 新增单选 `case_decision` | 必须增加，否则需在外部表单记录   |
| 数据问题             | 无统一控件 | 新增多选或文本 `data_issue` | 推荐增加              |
| 咳嗽、咳痰、气促         | 无     | 各新增1个实体              | 推荐增加；更新前只作病例级原文证据 |
| 时间表达             | 无     | 新增一个通用跨度             | 推荐增加；归一化由程序完成     |
| 当前、既往、持续、进行性加重   | 有     | 保留，但分组解释             | 继续使用              |
| 好转、稳定、频率         | 无     | 不新增                  | 记录在病例证据，必要时后处理    |
| 状态、时间、测量、标本、检测方式 | 有     | 保留                   | 继续使用              |
| 因果、完整事件时序        | 无     | 不新增                  | 不标                |


在生产XML正式更新前，标注员必须以当前XML按钮为准，并把缺失功能记录为 `xml_guide_mismatch`；不得临时创造同义标签。

### 2.4 本任务的“病例”含义

本指南中的“目标病例信号”不是对患者作临床确诊，而是判断当前记录中是否存在值得公共卫生人员回看、且可能代表感染性肺实质病变的证据。为控制过筛，以下内容不能仅凭名称进入目标队列：

- 慢性、稳定或明确非感染性的间质性肺病；
- 非呼吸主诉中偶然出现的少许慢性炎症；
- 已被影像或临床明确解释为肿瘤、心衰等非感染病因的肺部异常；
- 支气管扩张伴感染，但未明确累及肺实质。

这些情况按第3章和第4章判断为待专业复核或非目标，不新增疾病亚型标签。

## 3. 病例级判断



### 3.1 “索引临床事件”

索引临床事件指当前文本所描述的本次门急诊、当前住院或同一次连续诊疗过程。判断“当前或近期”时，以是否属于索引临床事件为准，不用固定天数代替临床语境。

- 同次住院早期有明确肺炎、出院时已好转：仍属于索引临床事件。
- 仅在既往史中提到多年前肺炎、与本次无关：不属于索引临床事件。
- 连续治疗或复诊记录只有同时满足以下四项，才把既往证据并入索引临床事件：当前文书明确引用；写明继续治疗、复查或病程延续；能确认同一患者同一疾病过程；该旧证据仍被当前诊疗作为判断依据。具体操作见第7.3节。
- 仅由系统拼接进来的旧检查、无当前医生引用或来源不清：不自动并入；若时间归属会改变结论，进入待专业复核并上报时间问题。
- 多个互不相干记录疑似错拼，且归属会反转结论：不是待专业复核，而是信息不足并退回数据修复。



### 3.2 四分类定义



#### A. 目标病例信号

满足以下条件：

1. 索引临床事件中存在至少一条“直接肺部证据”；
2. 证据不是全部被否定、仅为计划、仅为条件假设或仅属于他人；
3. 文本足以确认该证据属于患者；
4. 证据不是明确慢性、稳定或非感染性的肺部改变，也没有被明确替代病因充分解释。

直接肺部证据见第4.1节白名单。病例已好转、正在治疗或出院，不取消索引临床事件中明确存在过的肺炎信号，但可降低活动性和复核优先级。

#### B. 待专业复核

不存在足够的直接肺部证据，但满足以下任一入口（编号B1—B6，供后文和操作字典引用）：

1. **B1** 急性发热，加至少一项呼吸证据：咳嗽、咳痰、气促/呼吸困难、低氧、异常肺部体征；
2. **B2** 文本写“疑似肺炎、考虑肺炎、不除外肺炎、待排肺炎”；
3. **B3** 索引临床事件中有性质或活动性不明的肺/胸部异常，包括影像异常，或当前咳嗽/咳痰等呼吸症状合并双肺湿啰音等客观肺部听诊异常；此入口不要求同时存在发热。孤立湿啰音、单纯呼吸音粗或已有明确非感染性替代解释时不自动触发；
4. **B4** 呼吸道标本中检出本项目关注的呼吸道病原体，但没有足够肺炎直接证据；
5. **B5** 已知支气管扩张等结构性肺病，需同时满足以下两项：
   - 本次明确加重：原文把咳嗽/咳痰/气促明显加重锚定到本次就诊、当前连续疗程或明确复诊原因；
   - 至少一项客观急性证据：发热、低氧、湿啰音等。
   以下情形均不能替代上述组合：“今年加重多次”等年度计数、仅写未改善/仍有、更换抗生素、单独一个低氧数值；
6. **B6** 慢性或非感染性解释不确定，同时存在新发/加重呼吸症状或新的肺部异常；

未命中以上显式条件的证据组合不得仅凭“感觉不安全”进入待专业复核。若指南确有缺口，按第13章上报；数据足以判断且未命中规则时判非目标，数据本身不足或错拼时判信息不足。

#### C. 非目标

满足以下任一情况，且没有未解释的直接肺部证据：

1. 明确是其他疾病或无关复诊；
2. 孤立轻症，如单独短期咳嗽、鼻塞流涕、咽痛；
3. 长期稳定的慢性呼吸症状，无急性改变；
4. 所有相关证据均被明确否定；
5. 仅有筛查、暴露史或计划检查，且无急性呼吸证据；
6. 仅有纯既往肺炎，与索引临床事件无关；
7. 慢性、稳定或明确非感染性的间质性肺病，无急性感染证据；
8. 非呼吸主诉中偶见少许慢性肺部炎症，且急性呼吸证据均被否定；
9. 肺部异常被报告明确或高度解释为肿瘤、心功能不全等非感染病因，且没有独立感染证据；
10. 支气管扩张伴感染稳定复诊，或只有持续/未改善、换药、年度加重次数而没有本次明确症状加重加客观急性证据。



#### D. 信息不足

文本为空、严重截断、字段错位，或仅有无法归属的项目/数值，使目标、待复核和非目标均无法可靠判断。只有“病情稳定、继续治疗、病史同前、前症复诊、检查如前”等泛化或引用语句，而被引用疾病/证据缺失且可能改变四分类，也判信息不足。孤立的旧无关检查不能代替当前索引疾病。

“看不懂但明显与肺炎无关”不是信息不足，应判非目标。短文本若已明确给出无关索引行为或计划，例如“建议电子喉镜”，且无肺炎触发证据，仍判非目标；不能仅按字符长度判信息不足。

### 3.3 判定顺序

按以下顺序执行，不跳步：

1. 文本是否可用？不可用 → 信息不足。
2. 是否有明确慢性/非感染性语境或明确替代病因？有 → 先按第3.2节C判断非目标；若同时存在独立急性证据，继续第3步。
3. 是否有索引临床事件内的感染性或活动性直接肺部证据？有 → 目标病例信号。
4. 是否有疑似肺炎、急性发热加呼吸证据、急性呼吸症状加客观肺部听诊异常、结构性肺病本次明确急性恶化、性质不明肺/胸影像异常，或呼吸道标本中明确检出关注病原体？有 → 待专业复核。
5. 其余 → 非目标。



### 3.4 证据最小化

病例级证据只保留足以解释结论的最小原文片段：目标、待复核和非目标为1—3条；信息不足为0—3条；`blocked_privacy`固定为空数组且不作病例级判断。不要复制整段病历。优先顺序是：

1. 直接肺部证据；
2. 急性时间和核心症状；
3. 否定、计划、他人或既往等排除信息；
4. 病原、暴露或严重程度证据。

## 4. 证据优先级与病例筛查



### 4.1 直接肺部证据白名单

可直接支持“目标病例信号”的原文包括，但必须同时满足“属于索引临床事件、不是明确慢性/非感染性改变、没有充分替代解释”：

- 明确感染性诊断：肺炎、支气管肺炎、大叶性肺炎、病毒性/感染性间质性肺炎等；
- 明确感染：肺部感染、两肺感染、下呼吸道感染且上下文明确指肺实质；
- 明确炎症/实变：右肺炎症、两肺炎症、感染性病变、肺实变或影像明确提示肺炎。

必须保留原文语义。不能因为词中含“肺炎”就标肺炎诊断，例如：肺炎支原体、肺炎克雷伯菌、肺炎链球菌。

“间质性肺炎”不能脱离语境机械纳入：明确为慢性间质性肺病、稳定复诊或非感染性病因时判非目标；性质不明且有新发/加重呼吸证据时判待专业复核；明确急性感染性间质性肺炎时才判目标。

### 4.2 不能单独作为直接肺部证据

以下内容单独出现时不判目标病例信号：

- 胸水/胸腔积液、气胸、胸膜增厚、脓胸、支气管胸膜瘘；
- 条索影、小斑片影、结节、肿块、纤维化、陈旧性结核、肺不张；
- 双肺呼吸音粗、啰音、胸痛；
- CRP、PCT、白细胞等炎症指标升高；
- 发热、咳嗽、咳痰、气促；
- 病原体阳性；
- “抗感染治疗”或抗菌药物使用。
- “支气管扩张伴感染/支扩伴感染”，除非另有明确肺实质感染、炎症、实变或肺炎证据；
- “少许慢性炎症”“慢性间质性肺炎稳定复诊”；
- 已明确归因于心衰的两肺渗出，或高度考虑肿瘤的肺占位。

这些证据可与其他内容共同触发待专业复核。

### 4.3 四个高频边界



#### 慢性/非感染性肺部改变

- 慢性、稳定、非感染性语境明确，且无急性呼吸证据：非目标。
- 性质不明，同时有新发或加重呼吸症状：待专业复核。
- 明确急性感染性肺实质病变：目标病例信号。



#### 明确替代解释

- 影像或医生明确/高度解释为肿瘤、心衰、肺栓塞等，且没有独立感染证据：非目标。
- 替代解释不确定，并有急性呼吸证据或未解释的新肺部异常：待专业复核。
- 不能仅因出现“占位、渗出、模糊影”就判目标。



#### 支气管扩张伴感染

- 该固定短语不等于“肺部感染”实体，不直接判目标。
- 稳定复诊、配药、体温正常且无近期恶化：非目标。
- “未改善、仍有、继续抗感染、更换抗生素”表示持续或治疗调整，不等于加重，也不是客观急性证据。
- “今年加重6次”等年度次数不等于本次加重；“近期”不设机械天数，但必须由原文锚定到本次就诊、当前连续疗程或明确复诊原因。
- 本次咳嗽/咳痰/气促明确加重，并伴发热、低氧、湿啰音等至少一项客观证据：待专业复核。
- 另有明确肺炎、肺实质感染、炎症或实变：目标病例信号。



#### 纯检验和无关临床记录

- 空文本或仅有无法归属的检验项目/数值：信息不足，生产时由门禁另队列处理。
- 完整的非呼吸索引记录，附带明确阴性病原结果：非目标。
- 项目与结果展平错位、无法唯一配对：不连关系、不作阳性触发；若影响病例结论则信息不足并退回修复。



### 4.4 漏筛与过筛的平衡

采用两阶段策略，不要求一个规则同时完成所有判断。

#### 阶段0：数据质量门禁

程序先排除空字符串、纯空格、只有分隔符、无法解析的记录，并记录排除原因。不要让医学标注员手工清理大量空任务。

#### 阶段1：高召回粗筛

只要命中以下任一条件就保留给病例级模型或人工：

- 直接肺部证据词；
- 急性发热加呼吸证据；
- 疑似/待排肺炎；
- 性质不明的当前肺/胸异常；
- 呼吸道标本中关注病原体阳性。

阶段1允许多筛，不直接输出“真实病例”。

#### 阶段2：四分类判断

按第3章规则区分目标、待复核、非目标和信息不足。

#### 防止漏筛

- 从阶段1排除的记录中随机抽取5%—10%复核；
- 对含“肺、胸、呼吸、CT、影像、感染、发热”等宽词但被排除的记录加大抽样；
- 分别报告目标/待复核合并后的漏筛数，不能只看总体准确率；
- 一旦发现规则性漏筛，补充规则并回溯同批数据。



#### 防止过筛

- 单独鼻塞、流涕、咽痛、孤立咳嗽不进入待复核；
- 暴露史单独出现不进入待复核，只用于已有呼吸证据病例的优先级；
- 病原体名称或计划检测不等于阳性结果；
- 非特异影像不直接判目标。
- “慢性炎症、间质性肺炎、支气管扩张伴感染”必须结合急性/感染性语境，不能只按关键词直纳目标。

## 5. 通用实体跨度规则



### 5.1 最小完整跨度

选择能表达完整医学概念的最短原文，不带否定词、时间词、提示词或标点。

- “CT提示右肺炎症” → 标 `[右肺炎症]`，不含“CT提示”。
- “无发热” → 实体标 `[发热]`，状态标 `[无]`，再连状态关系。
- “今仍有发热” → 实体 `[发热]`；时间/病程修饰分别标 `[今]`、`[仍有]`。



### 5.2 保留必要限定

侧别、解剖部位或能改变概念的限定词应包含在实体跨度中，如“右肺炎症”“两肺感染”。纯程度词通常不并入实体，除非它属于固定结果词，如“弱阳性”作为完整状态跨度。

### 5.3 否定、计划和主体不并入实体

“未见、否认、拟、建议、家属”等另标断言并连接，不与临床实体合并。

### 5.4 不拆词内误标

- `[肺炎支原体]`只标病原体，不在其中再标“肺炎诊断”。
- `[肺炎克雷伯菌]`只标病原体。
- “抗肺炎治疗”若不是明确诊断，不因“肺炎”二字自动标诊断。



### 5.5 重复和并列

- 原文每个明确、独立出现的相关实体都标。
- 同一事实在复制粘贴段落中完全重复时，仍按界面文本标注，但同时记录 `duplicate_text`；预处理阶段应优先去重。
- 空文本先按 `empty_text` 门禁处理，不因为多个空字符串相同再标 `duplicate_text`。
- 同一批中的全文精确重复任务保留审计映射，但病例分布和一致性主分析只保留每个唯一文本的一个确定性代表；同时报告原始任务口径和唯一文本口径。
- 近重复只标记并抽查，不能在没有患者、就诊、时间和来源证据时自动删除。
- 并列实体分别标，例如“肺炎支原体、肺炎衣原体IgM阴性”应标两个病原体。



### 5.6 不连续跨度

当前任务不创建不连续实体。若修饰语与实体分开出现，分别标跨度并通过关系连接。

## 6. 实体标签体系

本章保留供流程学习使用的标签概览。实际画实体或连关系前，标注员必须查阅 `label_dictionary_v2.1.0.md` 中对应标签卡。每张卡把“医学上是什么”与“本项目在原文中标什么”分开；医学定义不能用于补造原文未表达的事实。

### 6.1 核心肺部实体


| 标签     | 定义                       | 纳入例               | 排除例                        | 病例判断作用           |
| ------ | ------------------------ | ----------------- | -------------------------- | -------------- |
| 肺炎诊断   | 原文明写感染性或活动性肺炎诊断          | 肺炎、支气管肺炎、病毒性间质性肺炎 | 肺炎支原体；慢性非感染性间质性肺病；待排肺炎需加可疑 | 满足索引和断言条件时直接纳入 |
| 肺部感染   | 明确指向肺实质/两肺的感染            | 肺部感染、两肺感染         | 支气管扩张伴感染；抗感染治疗；CRP升高       | 满足索引和断言条件时直接纳入 |
| 肺部组织炎症 | 影像/病理明确活动性肺实质炎症、感染性病变或实变 | 右肺炎症、两肺炎症         | 少许慢性炎症、胸水、条索影、结节           | 直接纳入或复核        |




### 6.2 症状和严重程度



#### 当前成人XML

- 发热
- 呼吸衰竭
- 休克
- 器官衰竭
- 机械通气



#### 当前儿童XML新增

- 鼻翼煽动
- 三凹征
- 喘鸣喘息
- 意识障碍
- 惊厥
- 拒食或喂养困难
- 脱水征



#### v2推荐最小新增症状

- 咳嗽
- 咳痰
- 气促/呼吸困难

这三个症状只用于与发热、低氧、异常肺部证据等组合判断待专业复核；不新增干咳/湿咳、痰色、频率、程度等子标签。

#### 解释规则

- 发热包括“低热、高热、体温升高”等明确症状表达；单纯数值另标体温测量。
- 呼吸衰竭、休克和器官衰竭提高复核优先级，但不证明病因是肺炎。
- 机械通气是治疗/支持措施，不是症状，也不证明肺炎；保留标签是为了严重程度排序。
- 儿童体征只有原文明确出现才标；“无鼻翼煽动”仍标实体并连接否定。



### 6.3 测量



#### 测量指标

- 成人：体温、呼吸频率、静息状态指氧饱和度、动脉氧分压(PaO2)、吸氧浓度(FiO2)
- 儿童：呼吸频率、静息状态指氧饱和度、动脉氧分压(PaO2)、吸氧浓度(FiO2)



#### 测量组成

- 数值
- 单位
- 比较符
- 阈值判断

例：“SpO2 < 93%”分别标指标、比较符、数值、单位；每个组成部分都通过“测量”关系连接到SpO2。不根据医学常识自行生成“异常”。

### 6.4 流行病学暴露



#### 成人职业

- 医务人员
- 禽、畜类从业人员
- 农牧民等野外作业人员
- 病原微生物实验室检测人员



#### 成人和儿童共同

- 可疑动物或动物制品接触史
- 可疑环境暴露史
- 外出外来史

暴露史只按原文标。否认暴露仍标实体并连接否定。暴露单独出现不触发肺炎待复核；只有病例已有呼吸证据时才提高优先级。GIS聚集不在此处标注。

### 6.5 病原体



#### 病毒

新冠病毒、流感病毒、呼吸道合胞病毒、腺病毒、人偏肺病毒、副流感病毒、普通冠状病毒、博卡病毒、鼻病毒、肠道病毒。

#### 细菌

A族链球菌、百日咳鲍特菌、肺炎链球菌、流感嗜血杆菌、军团菌、肺炎克雷伯菌。

#### 其他

肺炎支原体、曲霉菌、隐球菌、鹦鹉热衣原体、肺炎衣原体。

只标XML列出的病原体。未列出的病原体若可能改变病例判断，记录问题，不私创标签。病原体名称本身不表示检测阳性。

#### 病原阳性对病例级判断的作用

- 呼吸道标本（咽/鼻咽拭子、痰、肺泡灌洗液）中明确检出关注病原体，且记录组归属完整：无直接肺部证据时可触发待专业复核。
- 血清IgM/抗体阳性不能等同呼吸道标本检出；单独出现不触发待专业复核，须结合索引临床事件中的急性呼吸证据。
- 血培养、尿抗原、胸水或其他非呼吸道标本结果，只按原文和标本记录，不自动套用“呼吸道标本阳性”入口。
- 只有项目名、无结果，或项目—结果无法唯一配对：不视为阳性。
- 脱离就诊语境的纯检验列表：信息不足；完整无关临床记录中的附带阴性结果：非目标。



### 6.6 标本

- 咽/鼻咽拭子
- 痰
- 肺泡灌洗液
- 血
- 尿
- 胸水

只有在检测语境中才标标本。例如“痰培养”中的“痰”是标本；“咳痰”中的“痰”是症状内容，不标为标本。

### 6.7 检测方式

- 核酸检测
- mNGS
- 抗原快速检测
- 抗体IgM
- 抗体滴度/双份
- 培养

检测方式必须与原文明确的病原检测对应。计划检测加假设性；未完成的计划不当作结果。

## 7. 时间模块



### 7.1 三层轻量模型的设计原因

原XML中的“当前、既往”描述事件相对位置，“持续、进行性加重”描述病程。具体日期、相对时间和时长又是另一类信息。把这些混成一个互斥分类会造成分歧，因此v2分为三层，但只新增一个人工标签。

### 7.2 第一层：时间表达 `TimeExpression`（推荐新增）

标原文明确出现的时间跨度：

- 绝对日期：`2025-02-16`、`7月15日`
- 相对时间：`今`、`昨日`、`1周前`、`入院前2天`
- 时长：`持续3天`中的`3天`、`反复20年`中的`20年`
- 病程日序：`输液第4天`、`住院第2日`
- 时间窗口：`近7天`、`近期`

人工只选原文跨度，不填写标准日期。程序结合文档时间归一化为日期、时长或窗口。

### 7.3 第二层：事件相对位置



#### 当前

明确表示索引临床事件当前状态的词，如“今、今日、目前、现、本次”。只标原文存在的提示词，不给普通陈述补造“当前”。

#### 既往

明确表示非索引临床事件的过去史，如“既往、曾经、数年前患有”。具体日期不自动等于既往；同次住院早期日期仍属于索引临床事件。

复诊文本引用较早检查时，按以下顺序判断：

1. 当前文书是否明确引用该检查；
2. 是否写明继续治疗、复查、病情进展/好转或同一疗程；
3. 是否能确认属于同一患者、同一疾病连续诊疗；
4. 检查结果是否仍是当前判断的临床依据。

四项均明确时，才可并入索引临床事件；只有系统拼接日期或孤立旧报告时，不自动并入。前三项虽明确、但旧结果已不再被当前诊疗采用，也不并入。无法确认且会改变四分类时判待专业复核；疑似跨患者/跨就诊错拼时判信息不足并退回。

反例：“肺病复诊，继续维持治疗。系统附带两年前CT曾示肺炎；本次医师写明该病灶已消失、当前治疗针对其他慢病。”虽然有当前引用和连续随访，旧肺炎已不再作为当前依据，不并入索引临床事件。

#### 未来/计划

当前XML不设“未来”。用假设性/计划断言表达“拟、计划、建议、将行”。

### 7.4 第三层：病程



#### 持续

提示事件仍存在或治疗后未改善，如“仍有、一直、持续、未愈、无好转、效不佳”。

#### 进行性加重

只有明确逐步恶化时标，如“逐渐加重、进行性恶化、持续加重”。单次“今日加重”表示当前变化，不自动等于进行性。

#### 好转/稳定

不新增人工标签：

- “好转、缓解”保留在病例级证据中，用于降低活动性/优先级；
- “稳定”通常不改变是否存在过肺炎；
- 若索引临床事件中已有明确肺炎，不能仅因出院时好转改判非目标。



### 7.5 时间关系

只有时间词明确修饰某个临床事件时才连“时间”关系。

- “今仍有发热” → 今—时间—发热；仍有—时间—发热。
- “1周前发热，今日咳嗽” → 1周前只连发热；今日只连咳嗽。
- “既往肺炎，本次无发热” → 既往只连肺炎；无只连发热。

不要因为同句出现就把所有时间词连接给所有实体。

### 7.6 时间归一化建议

导出后程序可生成以下派生字段，人工不直接标：

- `normalized_date_or_interval`
- `in_index_episode`
- `activity`: active / improving / resolved / unclear
- `course`: ongoing / worsening / unclear

这些字段用于模型和复核排序，不增加标注界面复杂度。

### 7.7 三层时间模型的边界

本模型表达的是“原文时间跨度 + 相对索引临床事件的位置 + 病程状态”，足以支持当前病例级目标。它不负责：

- 推断没有明写的病程先后；
- 建完整BEFORE/AFTER图；
- 修复跨就诊拼接；
- 仅凭日期间隔决定“近期”。

100例压力测试没有发现必须再增加人工时间标签的案例；主要问题来自索引临床事件归属和源文档边界，应优先修数据和指南，而不是增加按钮。

## 8. 断言模块



### 8.1 标签定义


| 标签      | 提示词/例子               | 解释                 |
| ------- | -------------------- | ------------------ |
| 肯定      | 阳性、检出、培养见、证实、弱阳性     | 原文明确报告存在；弱阳性保留完整跨度 |
| 否定      | 无、未见、否认、阴性、未检出、不伴    | 明确不存在或检测阴性         |
| 可疑      | 疑似、考虑、不除外、待排、可疑阳性、临界 | 不当作确诊或确定阳性         |
| 条件性     | 若、如出现、必要时            | 条件尚未满足             |
| 假设性     | 拟、计划、建议、将行           | 计划或预期，未证明已发生       |
| 与患者本人无关 | 家属、母亲、接触者、同事         | 事件不属于患者本人          |




### 8.2 默认规则

普通肯定陈述没有显式提示词时，只标临床实体，不补造一个不存在的“肯定”跨度。病例逻辑可把没有否定/可疑/计划/他人提示的普通陈述视为患者当前存在，但这一默认值由后处理完成。

### 8.3 病原检测映射

- “阳性、检出、培养见、弱阳性” → 肯定。
- “可疑阳性、临界、不排除污染” → 可疑。
- “阴性、未检出” → 否定。
- 仅出现病原体和检测方式、无结果词 → 不补断言。
- “拟行新冠核酸” → 新冠病毒/核酸检测加假设性，不算已检测。



### 8.4 作用域

一个修饰词共同作用于多个实体且语法明确时，对每个实体分别连边。

“无咳嗽、发热、气促”中，“无”分别修饰三个症状。若并列结构不清，宁可少连并上报，不能猜测。

### 8.5 文书章节的默认解释

章节名只提供语境，不替代原文断言；以下规则用于处理常见模板：

- 现病史/入院情况：默认属于患者和索引临床事件，除非句内明确写既往、计划、否定或他人。
- 既往史：默认是非索引过去事实；实体仍按XML标，能定位提示词时连接“既往”。
- 家族史/接触者描述：默认不属于患者；只有原文明确涉及项目关注证据时标实体并连接“与患者本人无关”。
- 治疗计划/建议：未实施内容连接“假设性”；不能当成已发生检测、治疗效果或诊断。
- 出院记录：同次住院早期明确事实仍属于索引临床事件；“好转/已缓解”改变活动性，不删除该次事实。
- 复制模板或“相关后文”：只有来源和索引临床事件归属明确时使用；与当前段矛盾且影响结论时退回数据修复。

句内明确表达优先于章节默认。例如既往史中写“此次再次发热”，仍需核对其实际来源；现病史中写“母亲患肺炎”仍属于他人。

## 9. 关系模块



### 9.1 关系的目的

实体说明“有哪些证据”，关系说明“修饰语、数值、标本和方法属于哪一条证据”。关系错误可能把阴性变阳性或把一个病原体的标本连给另一个，因此关系必须比实体更保守。

### 9.2 Label Studio中的方向

Label Studio当前 `Relation` 标签文档只定义关系值和显示颜色，没有独立的“无向边”配置参数。界面创建关系时会产生起点和终点，但本项目不把点击先后当作医学业务方向。

本项目采用“逻辑无向、语义有角色”的方式：

- 标注员只需选对两个端点和关系类型；
- 导出后按端点标签自动归一化为 `modifier → target`、`specimen → pathogen` 等标准角色；
- 评分时若两个端点和关系类型相同，不因点击顺序相反扣分。

这能降低操作复杂度，同时保留明确的医学含义。

### 9.3 合法端点矩阵


| 关系   | 语义角色A               | 语义角色B           | 合法例       | 非法/不充分例      |
| ---- | ------------------- | --------------- | --------- | ------------ |
| 状态   | 肯定/否定/可疑/条件性/假设性/他人 | 症状、诊断、暴露、病原体或检测 | 阴性—肺炎支原体  | 同句的阴性连到无关病原体 |
| 时间   | 当前/既往/持续/加重/时间表达    | 症状、诊断、暴露或检测事件   | 1周前—发热    | 因同句出现而连全部实体  |
| 测量   | 数值/单位/比较符/阈值判断      | 测量指标            | 38.3—体温   | 38.3连到呼吸频率   |
| 标本   | 标本                  | 相应病原体           | 痰—肺炎克雷伯菌  | 胸水连到尿培养病原体   |
| 检测方式 | 检测方式                | 相应病原体           | IgM—肺炎支原体 | 核酸连到仅做抗体的病原体 |




### 9.4 逐关系规则



#### 状态

- 每个被修饰实体各连一条边。
- “不除外肺炎”用可疑，不用否定。
- “肺炎支原体IgM阴性”中阴性连病原体；IgM用检测方式关系连病原体。



#### 时间

- 只连接语义上被修饰的事件。
- 同一时间表达可以连接多个事件，但必须语法作用域明确。
- 不根据常识推断“先发热后肺炎”等未明说关系。
- 跨文书的旧时间只在来源和连续诊疗关系明确时连接；无来源日期不能支配整份拼接文本。



#### 测量

- 指标、数值、单位、比较符分别标，所有组成连接到对应指标。
- 多项生命体征并列时按最近且语义唯一的指标配对。



#### 标本

- 标本必须处于检测语境。
- “痰培养见肺炎克雷伯菌” → 痰—标本—肺炎克雷伯菌。
- “咳痰，肺炎支原体IgM阴性”不能把症状中的“痰”连到支原体。



#### 检测方式

- 每种方法只连其实际检测的病原体。
- 并列清晰时逐项连边。
- 方法被多个病原共享且作用域明确时，可分别连边。



#### 展平检验字段

- 只有同一检验记录组内的项目、结果、标本和方法才可连接。
- “最近出现”不是充分依据；跨组、错位或相互矛盾时不连。
- 导入端应保留检验记录ID、项目组边界或结构化组块；无法唯一配对的结果不得用于触发病原阳性。



### 9.5 不标的关系

- 症状导致诊断
- 暴露导致感染
- 病原体导致肺炎
- 药物治疗疾病
- BEFORE、AFTER、OVERLAP等完整事件时序
- 仅因两个实体在同一句或相邻句出现而产生的关系



### 9.6 关系不确定时

1. 先确认两个端点是否都标对；
2. 再确认原文是否明确表达归属；
3. 若有两种合理连接，暂不连；
4. 在反馈中写出最小片段、两种解释和对病例判断的影响。

100例压力测试表明，五类关系本身够用；主要错误风险来自端点归属和展平数据，而不是缺少新的关系类型。因此v2不增加因果、治疗或完整时序关系。

## 10. 数据质量门禁

“数据质量门禁”是指在病历进入医学标注前，用程序检查它是否值得进入任务队列，不是医学纳排标准。

### 10.1 导入前自动排除

以下记录不进入普通标注队列，另写排除日志：

- `text`缺失、空字符串或纯空格；
- 去除标点/分隔符后没有有效文字；
- 任务JSON无法解析；
- 文本完全重复且已有同源任务；
- 仍含姓名、证件号、电话、精确住址等身份信息。
- 住院号、床位号、姓名字段等结构化身份槽位未清空；
- 多个就诊/文书被拼接但没有来源、时间和索引临床事件标识，且自动规则无法安全拆分。

日志至少保存任务号、排除原因、规则版本和时间，不保存额外身份信息。

门禁实现顺序建议：

1. JSON和必需字段校验；
2. 空白/无有效文字校验；
3. 身份字段白名单删除，加姓名、证件号、电话、住院号、床位号模式扫描；
4. 非空文本按去标识化全文哈希精确去重，保留全部task_id到唯一文本ID的审计映射；
5. 按患者、就诊流水、activity/source和时间拆分索引临床事件；
6. 检验按原始记录ID成组输出；
7. 生成排除日志和少量门禁回归样本。

门禁排除的是“不可安全标注的数据”，不是医学上的非目标。完整但与肺炎无关的记录仍需保留为负例。

### 10.2 进入标注后发现的问题


| 问题                    | 动作                                         |
| --------------------- | ------------------------------------------ |
| 空字符串、纯空格、仅分隔符         | 记录 `empty_text`，不进入普通医学标注队列                |
| “同上/如前/前症”引用内容缺失      | 记录 `missing_context`；若缺失可能改变四分类则信息不足并回源补齐  |
| 部分截断但仍可判断             | 正常分类，记录 `truncated`                        |
| 明显拼接错误且不影响结论          | 不纠正文，跳过错误片段并记录                             |
| 拼接错误可能改变结论            | 阻塞，退回数据修复                                  |
| 非空文本精确重复              | 记录 `duplicate_text`；保留审计映射，主分析折叠为一个唯一文本    |
| 仍有身份信息                | 立即停止该例并按项目隐私流程处理                           |
| 只有“病情稳定/继续治疗/同前”等泛化内容 | 索引病种缺失且可能改变分类时，记录 `missing_context` 并判信息不足 |
| 完整无关记录附带阴性检验          | 非目标；不因检验项目名称改判                             |


`data_issue=other` 时必须填写一条简短、去标识化的 `data_issue_note`，说明数据工程人员可以采取的动作；不能用“医学上不确定”作为other。

### 10.3 无关病历的保留策略

无关病历本身是“非目标”训练数据，不应全部在导入前删除。建议：

- 空白、损坏、重复、含身份信息由门禁排除；
- 医学内容完整但与肺炎无关的记录保留一部分，作为真实负例；
- 通过分层抽样控制正例、待复核、硬负例和普通负例比例；
- 不要只用关键词命中的病历训练，否则模型无法学习排除无关内容。

## 11. Label Studio操作流程



### 11.1 每例操作顺序

1. 检查文本可用性和去标识化。
2. 阅读主诉、现病史、检查摘要和相关后文，形成病例级初判。
3. 标直接肺部证据和最小症状证据。
4. 标断言、时间和病程提示词。
5. 标与病例解释相关的测量、病原、标本、检测方式和暴露。
6. 按合法端点建立关系。
7. 回看病例级结论，保存1—3条最小证据。
8. 记录数据问题或指南问题。



### 11.2 不要做的事

- 不因担心漏标而把所有医学词都标出来。
- 不把模型预标注当成正确答案。
- 不自行修改原文、标签名或关系名。
- 不在无法确定关系时随意连最近实体。
- 不用个人临床经验替代指南中的显式证据规则。



### 11.3 提交前检查

- 病例级只选了一个结论；
- 目标病例信号有直接肺部证据；
- 待复核有明确触发原因；
- 否定、可疑、计划和他人证据没有被当成确定当前事实；
- 所有关系端点合法；
- 没有把病原体名称中的“肺炎”误标为肺炎诊断；
- 问题反馈不含身份信息。

## 12. 完整案例



### 案例1：明确当前肺炎

原文：“1周前发热伴咳嗽，今仍有发热。CT提示右肺炎症，门诊以‘肺炎’收住院。”

- 病例级：目标病例信号。
- 实体：发热；右肺炎症；肺炎；推荐新增后标咳嗽。
- 时间：1周前→发热；今→发热；仍有→发热。
- 说明：有索引临床事件内直接肺部证据。



### 案例2：急性发热加呼吸证据

原文：“发热1天，偶有咳嗽，双肺呼吸音粗，未行胸部影像。”

- 病例级：待专业复核。
- 实体：发热；推荐新增后标咳嗽。
- 不标：肺炎诊断、肺部感染、肺部组织炎症。
- 说明：符合急性发热加呼吸证据，但没有直接肺部证据。



### 案例3：孤立轻症

原文：“咳嗽1天，无发热，无胸闷气促，双肺未及啰音。”

- 病例级：非目标。
- 实体：发热，连接否定；推荐新增后可标咳嗽、气促并连接相应否定。
- 说明：孤立轻症，缺少急性组合和直接证据。



### 案例4：长期稳定咳嗽

原文：“反复咳嗽咳痰20年，心肺无殊。”

- 病例级：非目标。
- 时间表达：20年。
- 说明：长期稳定症状，无急性改变。



### 案例5：复杂胸腔感染

原文：“右侧脓胸，支气管胸膜瘘，胸水病原菌测序提示相关病原感染，近期无发热。”

- 病例级：待专业复核。
- 可标：胸水、mNGS、病原体、发热及否定。
- 不标：肺炎诊断、肺部组织炎症。
- 说明：胸腔感染严重但不等于肺实质肺炎。



### 案例6：非呼吸主诉中的偶然影像

原文：“因混合痔入院。影像见两肺纤维条索影及小斑片状影。”

- 病例级：待专业复核。
- 不标：肺部组织炎症，除非报告明确写炎症/感染/实变。
- 说明：性质和活动性不清，不能直接纳入目标。



### 案例7：住院期间肺炎已改善

原文：“入院胸部CT示两肺炎症。治疗后复查明显改善，现无发热咳嗽，予出院。”

- 病例级：目标病例信号。
- 实体：两肺炎症；发热、咳嗽连接否定（如相应标签可用）。
- 病例证据：治疗后改善。
- 说明：肺炎发生在同一次索引住院内；改善降低活动性，不删除病例信号。



### 案例8：纯既往肺炎

原文：“5年前曾患肺炎，本次糖尿病复诊，无咳嗽发热。”

- 病例级：非目标。
- 实体：肺炎并连接既往；发热连接否定。
- 说明：纯既往、与索引临床事件无关。



### 案例9：病原体弱阳性

原文：“呼吸道合胞病毒IgM弱阳性，肺炎支原体IgM阴性。”

- 病例级：按语境三选一：
  - 脱离就诊语境的纯检验列表 → 信息不足；
  - 附在一份完整、明确无关的临床记录中 → 非目标；
  - 同一索引临床事件另有急性呼吸证据 → 待专业复核。
  任何情况下都不能仅凭该结果判目标病例。
- 实体：呼吸道合胞病毒、肺炎支原体、抗体IgM。
- 状态：弱阳性→呼吸道合胞病毒；阴性→肺炎支原体。
- 不标：“肺炎支原体”中的肺炎诊断。



### 案例10：计划排除肺炎

原文：“拟行胸部CT排除肺炎，无发热咳嗽。”

- 病例级：非目标。
- 肺炎：`拟行`标假设性并连接肺炎；`排除`在此表示检查目的，不再额外连接可疑，避免同一实体出现两个冲突断言。若原文写“不除外肺炎/待排肺炎”，才用可疑。
- 说明：只有计划且缺少急性证据。



### 案例11：空文本

原文：空。

- 病例级：信息不足。
- 实体和关系：均为空。
- 运营动作：应由数据质量门禁在导入前拦截。



### 案例12：偶然慢性炎症

原文：“因胸痛就诊。CT示两肺少许慢性炎症；无发热、咳嗽、咳痰和呼吸困难。”

- 病例级：非目标。
- 不把“少许慢性炎症”作为活动性感染性肺实质证据。
- 说明：非呼吸索引临床事件、慢性语境明确、急性呼吸证据均被否定。



### 案例13：支气管扩张急性恶化

原文：“支气管扩张史。3天来咳嗽加剧、咳痰增多；SpO2 92%，双肺可闻湿啰音，无发热。”

- 病例级：待专业复核。
- 不直接标“肺部感染”，除非原文另写肺实质感染/炎症/实变。
- 说明：无发热不自动排除；结构性肺病急性症状恶化并有低氧/湿啰音。



### 案例14：支气管扩张稳定配药

原文：“支气管扩张伴感染复诊配药，目前病情稳定，体温正常。”

- 病例级：非目标。
- 说明：固定诊断短语不等于当前肺实质感染，且没有近期恶化。



### 案例15：明确替代解释

原文：“气促、双下肢水肿。影像示两肺渗出，可符合心功能不全表现；无发热及感染证据。”

- 病例级：非目标。
- 说明：肺部异常已有明确非感染性解释，没有独立感染证据。



### 案例16：连续诊疗中引用旧影像

原文：“肺病复诊，继续原疗程。当前医师记录引用上月CT：两肺炎症较前进展，建议继续治疗后复查。”

- 病例级：目标病例信号。
- 时间：上月→两肺炎症；不把“上月”机械标成纯既往排除。
- 说明：当前文书明确引用旧证据，并说明同一疾病连续治疗和复查。



### 案例17：疑似跨记录拼接

原文：“上腹痛入院，无发热咳嗽。检验数值中间无过渡拼入‘病程中发热，支原体阳性，已治疗’。”

- 病例级：信息不足。
- 运营动作：阻塞该例，按来源/就诊ID拆分并重新导入。
- 说明：后段归属会反转四分类，医学标注员不能猜测。



### 案例18：慢性间质性肺病稳定复诊

原文：“间质性肺炎复诊，病情稳定，无发热、咳嗽，活动后气促长期无明显变化。”

- 病例级：非目标。
- 说明：慢性稳定且无感染性证据；若明确写急性感染性间质性肺炎，则按目标判断。



### 案例19：无发热信息的咳痰加湿啰音

原文：“咳嗽、咳痰3天。两肺可闻及湿啰音。”

- 病例级：待专业复核。
- 说明：当前呼吸症状加客观肺部听诊异常命中B3，不要求同时写发热；没有肺炎或肺实质感染，故不判目标。
- 近似反例：“体检偶闻湿啰音，无咳嗽咳痰，心衰解释明确。”不能机械进入待复核。



### 案例20：支扩未改善并换药，但没有急性客观证据

原文：“支气管扩张伴感染复诊配药，咳嗽咳痰较前未见好转，根据痰培养更改抗生素；无发热、低氧或湿啰音记录。”

- 病例级：非目标。
- 说明：未改善属于持续，不等于明确加重；换药和痰培养不能替代本次症状加重加客观急性证据。



### 案例21：短而完整的无关计划

原文：“建议电子喉镜。”

- 病例级：非目标。
- 说明：内容虽短，但索引行为明确且无肺炎触发证据；不能仅按字符数判信息不足。



### 案例22：缺失“同前/如前”引用

原文：“慢性病复诊，病史同前。症状好转，维持原治疗。”

- 病例级：信息不足。
- 数据问题：`missing_context`。
- 说明：当前病种未给出，被引用内容可能含同一疗程肺炎证据；正常心肺查体或孤立旧无关检查不能补足索引疾病。

## 13. 疑难问题与上报



### 13.1 何时必须上报

- 两种解释会改变四分类；
- 指南和XML按钮不一致；
- 实体边界无法唯一确定；
- 一个修饰词可能连接多个不同实体；
- 原文损坏、截断或仍含身份信息；
- 出现当前Schema未覆盖、但可能改变病例判断的证据。



### 13.2 反馈必须包含

1. 任务号；
2. 去标识化的最小必要片段；
3. 问题类别；
4. 两种可能解释；
5. 对纳入、排除、优先级或解释的影响；
6. 本轮保守处理；
7. 希望指南明确回答的问题。



### 13.3 不允许的反馈

- 只写“不会标”“不确定”；
- 复制整份病历；
- 含姓名、证件号、电话或精确住址；
- 标注员自行宣布新规则或修改标签。

## 14. 质控指标和计算



### 14.1 先评病例级，再评结构化标签

建议顺序：

1. 病例级四分类一致性；
2. 核心肺部实体和关键症状；
3. 断言与时间；
4. 关系。

如果实体端点还不稳定，关系分数没有解释价值。

### 14.2 Cohen's kappa

两名标注员对同一批病例各给一个四分类结论。设：

- `Po`：实际一致比例；
- `Pe`：按两人各类别边际比例计算的随机一致概率；
- `kappa = (Po - Pe) / (1 - Pe)`。

例：20例中18例一致，`Po=0.90`。再根据两名标注员各自四类数量计算`Pe`，不能直接把0.90当kappa。

项目建议门槛，不是国际通用硬标准：

- kappa ≥ 0.80：可进入扩大试标；
- 0.67—0.79：分析分歧、修订指南并复测；
- < 0.67：暂停生产，重新培训和裁决。

即使总体kappa较高，也必须逐类报告目标、待复核、非目标和信息不足的混淆，避免类别不平衡掩盖目标病例漏标。

### 14.3 实体、属性和关系F1

计算前必须在输出中保存字符起止偏移。

- 严格实体匹配：标签、起点和终点全部相同。
- 重叠实体匹配：标签相同且跨度有重叠，仅用于诊断边界问题。
- 属性F1：实体匹配后比较状态/时间类别。
- 关系F1：关系类型和两个端点都匹配；本项目忽略点击方向，按语义角色归一化后比较。

分别报告precision、recall和F1，不只报一个总分。核心肺部证据、病原结果和病例级判断应单独报告。

### 14.4 完成率和问题门槛

进入生产前建议满足：

- 双标病例完成率 ≥ 95%；
- 未处理blocker = 0；
- 所有major问题有裁决和回归案例；
- 核心实体严格F1建议 ≥ 0.85；
- 关系F1建议 ≥ 0.80，且没有会反转病原结果的系统错误；
- 阶段1筛查排除样本经人工抽查后，无重复模式的目标病例漏筛。



### 14.5 当前100例双智能体压力测试结果

两名独立医学标注智能体按v1.0.0完成同一批100例，脱敏修复并独立复标3例后：

- 病例级一致94/100，观察一致率0.94；
- Cohen's kappa = 0.898；
- 6例分歧集中在泛化稳定文本、旧影像归属、纯检验、支气管扩张急性加重和跨记录拼接；
- 另发现4例两名智能体一致、但会导致系统性过筛的边界，v2已修订慢性/非感染性改变和明确替代解释规则；
- v2裁决参考分布：目标病例信号18、待专业复核9、非目标62、信息不足11。

该结果只表明两套独立AI执行流程能够解析大部分规则，并帮助定位规则缺口；它不证明真人可执行性、标注有效性或关系可靠性。裁决参考不是临床金标准，生产前仍须按第15章完成人类双标。

### 14.6 当前新增200例双智能体压力测试结果

两名独立医学标注智能体按v2.0.1完成同一批新增200例，均无隐私阻塞：

- 标注员A分布：目标1、待复核4、非目标136、信息不足59；
- 标注员B分布：目标1、待复核9、非目标130、信息不足60；
- 原始任务口径一致192/200，观察一致率0.960，Cohen's kappa=0.915，8例分歧；
- 去标识化全文精确折叠后为158个唯一文本，一致151/158，观察一致率0.956，Cohen's kappa=0.879，7个唯一文本分歧；
- 裁决参考原始分布：目标1、待复核6、非目标132、信息不足61；唯一文本分布：目标1、待复核6、非目标121、信息不足30；
- 分歧主要集中在结构性肺病是否属于本次急性加重、无发热的咳痰加湿啰音、短而完整的无关记录，以及缺失“同前/如前”上下文；
- 200任务中只有158个唯一文本，说明正式抽样必须先做空文本门禁和全文精确去重。

该结果仍是AI指南压力测试，不是真人IAA、临床效度或病例患病率估计。样本有意纳入剩余空白和低信息记录，不能把类别分布外推到总体。

### 14.7 指标解释注意事项

- 观察一致率说明两人有多少例完全相同；kappa还扣除按类别比例随机一致的部分。
- 100例中非目标占比较高，必须同时查看混淆表和所有目标/待复核分歧，不能只看总kappa。
- 空白、隐私阻塞和跨记录拼接应另报数据质量指标；生产医学一致性主分析可预先规定是否排除这些门禁失败样本。
- 实体和关系输出尚未统一保存字符偏移，当前不能报告严格实体F1或关系F1。

## 15. 培训、双标与裁决



### 15.1 标注员培训

1. 阅读本指南和快速判定卡；
2. 由培训者讲解病例级四分类、时间三层模型和关系端点；
3. 共同完成5例示范；
4. 独立完成20例培训校准集；该批用于讲评，不作为正式一致性验证集；
5. 讨论分歧，但不覆盖原始答案；
6. 达到项目门槛后进入生产。



### 15.2 双标设计

- 正式真人验证：不少于30例、100%双标，且不得与5例示范和20例培训校准集重叠；应覆盖明确肺炎、疑似肺炎、复杂胸腔病变、孤立轻症、纯既往、慢性间质性肺病、支气管扩张急性/稳定病例、替代病因、病原检测、无关病例和数据损坏。
- 扩大试标：50—100例，至少20%双标。
- 稳定生产：每批随机10%双标，并对高风险边界病例额外双标。

两名标注员必须独立完成，不能在提交前互看结果。

### 15.3 裁决

裁决员查看原始双份结果、指南版本和最小原文片段，逐项给出：

- 最终答案；
- 使用的规则；
- 分歧原因：指南缺失、培训不足、操作错误、数据问题或Schema问题；
- 是否修订指南；
- 是否回标历史数据。

裁决不是简单选A或B，也不能覆盖原始标注文件。所有裁决进入日志。

### 15.4 指南修订门槛

只有满足以下条件之一才增加标签：

1. 会改变病例纳入或排除；
2. 会改变复核优先级；
3. 是解释病例判断不可缺少的证据；
4. 在多例中重复出现，且现有标签无法稳定表达。

新增标签前必须说明定义、纳入、排除、正例、反例、合法关系、复杂度成本和回标需求。

## 附录A：快速判定卡

1. 空文本→`empty_text`并由门禁拦截；缺“同前/如前”且可能反转分类→`missing_context`和信息不足。
2. 先排慢性/非感染性或明确替代病因；无独立感染证据时通常非目标。
3. 本次就诊/住院明确活动性感染性肺炎、肺实质感染、炎症/实变？→ 目标病例信号。
4. 疑似肺炎，急性发热+呼吸证据，呼吸症状+湿啰音，结构性肺病本次明确加重+客观证据，当前肺/胸异常性质不明，或呼吸道标本明确检出关注病原？→ 待专业复核。
5. 孤立轻症、长期稳定、纯既往、全部否定、单纯无关病历？→ 非目标。
6. 病原体名称不等于阳性；阳性不等于肺炎。
7. 胸水、条索影、小斑片影、结节、脓胸不自动等于肺炎。
8. 时间表达标原文，标准日期交给程序。
9. 关系只连明确归属；同句出现不够。
10. 点击先后不计医学方向；端点和关系类型必须正确。
11. 不确定时不猜，写最小片段和问题。
