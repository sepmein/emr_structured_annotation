# 肺炎相关EMR逐标签医学定义与操作字典

版本：v2.1.0  
发布日期：2026-08-28  
配套指南：`annotation_guide_v2.1.0.md`  
适用Schema：见 `schema_manifest_v2.1.0.json`  
适用对象：具有医学背景、但缺少NLP标注经验的标注人员

## 1. 本字典解决什么问题

本文件不是普通标签清单。每张标签卡明确区分：

1. **医学定义**：该概念在临床医学、检验医学或公共卫生中的含义；
2. **项目操作定义**：本项目究竟标什么原文，不标什么；
3. **病例判断作用**：它影响目标病例纳入、待复核、排除、优先级，还是只用于解释；
4. **显式证据边界**：标注人员只标原文，不根据医学常识补造诊断、病原、异常或因果。

医学定义用于理解概念，不授权标注员进行临床推断。即使医学上高度提示肺炎，只要原文没有表达相应标签，仍不得补标。

### 1.1 Schema状态

- **A**：成人当前XML可用；
- **C**：儿童当前XML可用；
- **R**：项目推荐，但当前XML没有，获批前只能作为病例级证据，不得在Label Studio私创；
- **F**：外部病例表单字段，不是文本跨度实体。

### 1.2 每张卡的固定字段

- 医学定义
- 项目操作定义
- 纳入标准
- 排除标准
- 最小完整跨度
- 允许关系
- 病例判断作用
- 正例
- 近似反例
- 常见混淆与裁决

## 2. 病例级判断标签

病例级判断不是临床诊断，而是公共卫生病例发现流程中的操作性分类。每份通过隐私门禁的记录选择且只选择一个分类。

### 2.1 目标病例信号

- **Schema状态**：F，外部病例表单必填。
- **医学定义**：无对应的单一临床诊断；它表示当前记录包含可能反映活动性或感染性肺实质病变、值得公共卫生复核的信号。
- **项目操作定义**：索引临床事件内存在明确肺炎、明确肺实质感染、明确活动性肺部炎症/感染性病变/实变；证据属于患者，且未被否定、计划、条件、他人、纯既往、慢性非感染性或明确替代病因排除。
- **纳入标准**：四项同时满足：直接肺部证据；属于索引事件；断言有效；无充分排除语境。
- **排除标准**：单独症状、炎症指标、病原名称、抗感染用药、胸水、结节、慢性炎症、稳定间质性肺病、支气管扩张伴感染。
- **跨度**：不是文本跨度；另保存1—3条最小原文证据。
- **允许关系**：不建关系；由实体、断言和时间证据解释。
- **病例作用**：进入目标病例复核队列。
- **正例1**：“CT提示右下肺炎症。”
- **正例2**：“诊断：社区获得性肺炎。”
- **近似反例**：“肺炎支原体IgM阴性。”病原体名称中含“肺炎”，但没有肺炎诊断。
- **常见混淆与裁决**：同次住院早期肺炎、出院时已好转，仍可判目标；多年前既往肺炎、本次无关，判非目标。

### 2.2 待专业复核

- **Schema状态**：F，外部病例表单必填。
- **医学定义**：不是疾病严重程度等级，而是证据尚不足以确认目标、但达到预先规定复核触发条件的运营状态。
- **项目操作定义**：没有足够直接肺实质证据，但命中指南第3.2B节任一显式组合。
- **纳入标准**：急性发热加呼吸证据；明确疑似/待排肺炎；当前性质不明肺胸影像异常；当前咳嗽/咳痰加双肺湿啰音等客观听诊异常；呼吸道标本明确检出关注病原体；结构性肺病本次明确症状加重并有客观急性证据；慢性/非感染性解释不确定且出现新发或加重证据。
- **排除标准**：只因标注员“感觉不安全”；孤立轻症；完整无关病历；空白或错拼数据。
- **跨度**：不是文本跨度；保存1—3条触发规则所需的最小证据。
- **允许关系**：不建关系。
- **病例作用**：进入专业人员二次复核，而不是自动纳入目标病例。
- **正例1**：“发热2天，咳嗽咳痰，尚未行胸部影像。”
- **正例2**：“咳嗽、咳痰3天，两肺可闻及湿啰音。”无发热信息也可按B3待复核。
- **近似反例**：“偶有咳嗽1天，无发热，肺部查体正常。”属于孤立轻症，判非目标。
- **常见混淆与裁决**：孤立湿啰音不自动触发；结构性肺病只有“本次明确症状加重＋客观急性证据”才进入B5，未改善、换药或年度加重次数不能替代。数据归属不清且可能反转结论时判信息不足。

### 2.3 非目标

- **Schema状态**：F，外部病例表单必填。
- **医学定义**：不是“患者健康”或“排除所有肺部疾病”；只表示当前可用记录未达到本项目目标或复核条件。
- **项目操作定义**：记录内容充分、可判断，但明确无关，或仅有孤立轻症、长期稳定症状、纯既往事实、全部否定、慢性非感染性改变、明确替代病因或稳定结构性肺病。
- **纳入标准**：资料可用，且没有未解释的直接肺部证据或待复核组合；短文本若明确给出无关索引行为或计划，不能仅因字符少改判信息不足。
- **排除标准**：空文本、严重截断、无法归属检验、跨记录拼接。
- **跨度**：不是文本跨度；保存1—3条排除或无关证据。
- **允许关系**：不建关系。
- **病例作用**：作为真实负例，训练模型学习排除无关和过筛内容。
- **正例1**：“糖尿病复诊，无发热咳嗽。”
- **正例2**：“建议电子喉镜。”文本短但索引行为明确且无肺炎触发证据。
- **近似反例**：“无发热，但支扩基础上咳痰增加、低氧。”无发热不能排除待复核。
- **常见混淆与裁决**：完整无关病历附带病原阴性为非目标；只有孤立检验列表、无法识别索引事件时为信息不足。

### 2.4 信息不足

- **Schema状态**：F，外部病例表单必填；允许0—3条证据。
- **医学定义**：不是疾病类别；表示数据本身不足以作目标、待复核或非目标判断。
- **项目操作定义**：文本为空、严重截断、字段错位、多个记录疑似错拼、只有无法归属的项目/数值，或仅有“病情稳定、继续治疗、病史同前、前症复诊、检查如前”等无法识别索引疾病的泛化/引用语句，且缺失内容可能改变四分类。
- **纳入标准**：至少一种数据缺陷会实质影响病例分类。
- **排除标准**：内容虽少但明确无关；标注员不熟悉某疾病；一般医学不确定性。
- **跨度**：不是文本跨度；空文本证据可为0条，有残片时最多3条。
- **允许关系**：不建关系。
- **病例作用**：触发补充数据、拆分记录或门禁修复；不作为普通医学负例。
- **正例1**：空文本。
- **正例2**：“慢性病复诊，病史同前，维持原治疗。”被引用病种缺失且可能含同一疗程肺炎证据。
- **近似反例**：“高危妊娠随访，肺炎支原体IgM阴性。”索引事件清楚，可判非目标。
- **常见混淆与裁决**：孤立旧无关检查不能补足当前索引病种；短而明确无关的当前计划可判非目标。隐私阻塞不填信息不足，应设 `annotation_status=blocked_privacy`、`case_decision=null`。

## 3. 核心肺部证据标签

### 3.1 肺炎诊断

- **Schema状态**：A/C。
- **医学定义**：肺炎是肺实质的感染性炎症性疾病，可由细菌、病毒、真菌或其他病原体引起；临床诊断通常综合症状、体征和影像，但本标签不要求标注员重新诊断。
- **项目操作定义**：仅标原文明写的肺炎诊断名称，包括部位、病理形态或明确感染性类型；不从影像、症状或病原体名称推断。
- **纳入标准**：肺炎、支气管肺炎、大叶性肺炎、社区获得性肺炎、病毒性肺炎、感染性间质性肺炎。
- **排除标准**：肺炎支原体、肺炎链球菌、肺炎克雷伯菌；明确非感染性间质性肺病不作为活动性肺炎证据。“拟行CT排除肺炎”连接假设性，“不除外/待排肺炎”连接可疑，“已排除肺炎”连接否定。
- **最小完整跨度**：保留能改变诊断含义的类型和解剖限定，如 `[右下叶肺炎]`、`[社区获得性肺炎]`；不包含“诊断为、考虑、无、既往”等修饰词。
- **允许关系**：状态、时间。
- **病例判断作用**：有效且属于索引事件时为直接目标证据；被否定、计划、纯既往或他人修饰时不直接纳入。
- **正例1**：“诊断为[社区获得性肺炎]。”
- **正例2**：“胸部CT结合临床考虑[右下叶肺炎]。”同时将“考虑”标可疑。
- **近似反例**：“[肺炎支原体]IgM阳性。”只标病原体，不在词内拆出肺炎诊断。
- **常见混淆与裁决**：“间质性肺炎”需结合语境；稳定慢性/非感染性复诊不自动成为目标病例，明确病毒性或感染性时才作为直接证据。

### 3.2 肺部感染

- **Schema状态**：A/C。
- **医学定义**：病原微生物在肺实质或下呼吸道造成感染性病理过程；医学上可与肺炎重叠，但原文可能只写“肺部感染”。
- **项目操作定义**：标原文明写且解剖指向肺、两肺或肺实质的感染；不以抗菌药、炎症指标或“支气管感染”替代。
- **纳入标准**：肺部感染、两肺感染、右下肺感染、肺实质感染；“下呼吸道感染”仅在上下文明确指肺实质时纳入。
- **排除标准**：上呼吸道感染、支气管炎、支气管扩张伴感染、胸腔感染、抗感染治疗、感染指标升高。
- **最小完整跨度**：保留肺部解剖限定，如 `[两肺感染]`；不包含“提示、考虑、治疗”等。
- **允许关系**：状态、时间。
- **病例判断作用**：有效且属于索引事件时为直接目标证据。
- **正例1**：“影像结合临床提示[肺部感染]。”
- **正例2**：“诊断：[右下肺感染]。”
- **近似反例**：“支气管扩张伴感染。”不能标为肺部感染，除非另有明确肺实质感染表述。
- **常见混淆与裁决**：“肺感染可能”标肺部感染实体并连接可疑；“予抗感染治疗”本身不标肺部感染。

### 3.3 肺部组织炎症

- **Schema状态**：A/C。
- **医学定义**：肺实质组织的炎症性改变，可表现为炎性浸润、感染性病变或实变；影像描述本身并不总能确定感染病因。
- **项目操作定义**：仅标影像、病理或医生明确写出的活动性肺实质炎症、感染性病变或实变，不把所有阴影、结节、条索和渗出推断成炎症。
- **纳入标准**：右肺炎症、两肺炎症、肺内感染性病变、肺实变；部位限定应保留。
- **排除标准**：少许慢性炎症、纤维条索影、磨玻璃影但未写炎症/感染、结节、肿块、肺不张、胸水、胸膜增厚、心衰性肺水肿。
- **最小完整跨度**：如 `[右下肺炎症]`、`[两肺感染性病变]`、`[左下叶实变]`。
- **允许关系**：状态、时间。
- **病例判断作用**：明确活动性/感染性且属于索引事件时为直接目标证据；慢性或替代病因明确时为非目标语境；性质不明时可触发待复核。
- **正例1**：“CT示[右下肺炎症]。”
- **正例2**：“左下叶见[感染性病变]。”
- **近似反例**：“两肺散在斑片状模糊影。”没有明确炎症/感染/实变，不标本标签。
- **常见混淆与裁决**：“两肺渗出，可符合心功能不全”不标肺部组织炎症；按替代病因规则判病例级。

## 4. 症状、体征、严重程度和治疗支持

### 4.1 发热

- **Schema状态**：A/C。
- **医学定义**：发热是体温调节中枢设定点升高导致的受控体温升高，常见于感染和炎症；它不同于环境或散热障碍造成的高体温。
- **项目操作定义**：标原文明确表达的发热症状，不根据单个体温数值自行生成“发热”。
- **纳入标准**：发热、低热、高热、反复发热、发烧。
- **排除标准**：寒战但未写发热；体温38.3℃但无症状词；“热感”“面红”。
- **最小完整跨度**：`[发热]`、`[高热]`；时间、程度以外的修饰词不并入。
- **允许关系**：状态、时间。
- **病例判断作用**：与急性呼吸证据组合可触发待复核；单独发热不证明肺炎。
- **正例1**：“患者昨日出现[发热]。”
- **正例2**：“无[高热]，仅低热。”两个实体按原文分别处理并连接状态。
- **近似反例**：“T 38.5℃。”只标体温指标、数值和单位。
- **常见混淆与裁决**：“体温正常”不标发热，除非文本同时明确否定发热，如“无发热”。

### 4.2 咳嗽

- **Schema状态**：R。
- **医学定义**：咳嗽是由气道刺激触发的保护性反射，通过快速呼气清除分泌物或异物。
- **项目操作定义**：标原文明写的咳嗽症状；干咳、阵发性咳嗽等仍归同一标签，不细分亚型。
- **纳入标准**：咳嗽、干咳、呛咳、阵发性咳嗽。
- **排除标准**：清嗓、咳痰中的“痰”、咯血但未写咳嗽、咳嗽史属于他人。
- **最小完整跨度**：通常 `[咳嗽]`；固定表达可标 `[阵发性咳嗽]`，但不包含时间和否定词。
- **允许关系**：状态、时间。
- **病例判断作用**：与发热或结构性肺病急性恶化组合时支持待复核；孤立短期咳嗽通常非目标。
- **正例1**：“发热伴[咳嗽]2天。”
- **正例2**：“近3日[干咳]明显。”
- **近似反例**：“痰培养送检。”没有咳嗽症状。
- **常见混淆与裁决**：当前XML未批准前，只保留为病例级证据，不创建实体。

### 4.3 咳痰

- **Schema状态**：R。
- **医学定义**：咳痰是通过咳嗽将下呼吸道分泌物排出；痰的颜色和量可反映气道分泌物特征，但不能单独确定感染病原。
- **项目操作定义**：标咳痰症状及必要的固定限定，不细分痰色、黏稠度或量。
- **纳入标准**：咳痰、咳黄痰、咳白色黏痰、痰量增多。
- **排除标准**：痰培养中的标本“痰”；口腔分泌物；咯血不等同咳痰。
- **最小完整跨度**：`[咳痰]`或 `[咳黄痰]`；时间和否定词另标。
- **允许关系**：状态、时间。
- **病例判断作用**：与发热、低氧、湿啰音或结构性肺病急性恶化组合时支持待复核。
- **正例1**：“近3日[咳痰]增多。”
- **正例2**：“伴[咳黄色黏痰]。”
- **近似反例**：“取[痰]行培养。”此处标本，不是咳痰症状。
- **常见混淆与裁决**：当前XML未批准前，只保留为病例级证据。

### 4.4 气促/呼吸困难

- **Schema状态**：R。
- **医学定义**：呼吸困难是患者主观感到呼吸不适、费力或空气不足；气促常指呼吸急迫感，可有或无客观呼吸频率升高。
- **项目操作定义**：标气促、气短、呼吸困难等明确症状；不从胸闷或低氧单独推断。
- **纳入标准**：气促、气短、呼吸困难、喘不过气。
- **排除标准**：胸闷单独出现；呼吸频率增快但无主观症状词；呼吸衰竭诊断。
- **最小完整跨度**：`[气促]`、`[呼吸困难]`、`[活动后气促]`；活动后是有意义限定，可保留。
- **允许关系**：状态、时间。
- **病例判断作用**：与发热或结构性肺病急性恶化组合时支持待复核；也用于优先级解释。
- **正例1**：“活动后[气促]明显。”
- **正例2**：“患者诉[呼吸困难]。”
- **近似反例**：“R 30次/分。”只标呼吸频率测量。
- **常见混淆与裁决**：当前XML未批准前，只保留为病例级证据。

### 4.5 呼吸衰竭

- **Schema状态**：A/C。
- **医学定义**：呼吸衰竭是呼吸系统不能维持适当氧合和/或二氧化碳清除的临床综合征，可表现为低氧血症、伴或不伴高碳酸血症。
- **项目操作定义**：仅标原文明写的呼吸衰竭诊断，不依据SpO2、PaO2或吸氧自行诊断。
- **纳入标准**：呼吸衰竭、急性呼吸衰竭、Ⅰ型/Ⅱ型呼吸衰竭。
- **排除标准**：呼吸困难、低氧血症、氧饱和度下降、需吸氧但未写呼吸衰竭。
- **最小完整跨度**：保留类型和急慢性限定，如 `[急性Ⅰ型呼吸衰竭]`。
- **允许关系**：状态、时间。
- **病例判断作用**：提高复核优先级，不证明病因是肺炎。
- **正例1**：“诊断：[急性呼吸衰竭]。”
- **正例2**：“并发[Ⅰ型呼吸衰竭]。”
- **近似反例**：“SpO2 89%。”不能补标呼吸衰竭。
- **常见混淆与裁决**：同一患者慢性呼吸衰竭若与本次无关，仍可标实体并连接既往，但不自动提高当前优先级。

### 4.6 休克

- **Schema状态**：A/C。
- **医学定义**：休克是急性循环功能障碍导致组织灌注不足和细胞缺氧的临床综合征，可由感染、低血容量、心源性或其他原因引起。
- **项目操作定义**：仅标原文明写的休克诊断或状态，不根据单次低血压、心率或乳酸自行推断。
- **纳入标准**：休克、感染性休克、脓毒性休克、心源性休克。
- **排除标准**：血压偏低、休克指数升高、循环不稳定但未写休克。
- **最小完整跨度**：保留病因类型，如 `[感染性休克]`。
- **允许关系**：状态、时间。
- **病例判断作用**：提高优先级；只有肺炎证据同时存在时才说明肺炎相关重症风险。
- **正例1**：“入院后出现[感染性休克]。”
- **正例2**：“目前无[休克]表现。”实体连接否定。
- **近似反例**：“血压85/55mmHg。”不自行补标休克。
- **常见混淆与裁决**：休克不是器官衰竭标签，也不等同低血压。

### 4.7 器官衰竭

- **Schema状态**：A/C。
- **医学定义**：器官衰竭指一个或多个器官系统功能严重受损，不能维持机体基本需要，常需要器官支持；它比一般“功能不全”更严重。
- **项目操作定义**：标原文明写的器官衰竭或多器官功能衰竭；保留具体器官名称。
- **纳入标准**：肾衰竭、肝衰竭、心力衰竭、多器官功能衰竭。
- **排除标准**：慢性肾功能不全、肝功能异常、心功能Ⅱ级、单项实验室异常。
- **最小完整跨度**：`[急性肾衰竭]`、`[多器官功能衰竭]`。
- **允许关系**：状态、时间。
- **病例判断作用**：提高优先级，但不证明肺炎病因；慢性既往衰竭与当前事件需通过时间区分。
- **正例1**：“并发[急性肾衰竭]。”
- **正例2**：“出现[多器官功能衰竭]。”
- **近似反例**：“慢性肾功能不全。”不标器官衰竭。
- **常见混淆与裁决**：“心力衰竭”医学上属于器官衰竭，可标本标签；但它同时可能是肺部渗出的替代解释，病例级仍按替代病因规则处理。

### 4.8 机械通气

- **Schema状态**：A/C。
- **医学定义**：机械通气是由呼吸机以正压或负压部分或完全替代自主通气的器官支持，可为有创或无创方式。
- **项目操作定义**：标已实施或明确描述的有创/无创机械通气；计划未实施时可标实体并连接假设性。
- **纳入标准**：机械通气、有创通气、无创通气、呼吸机辅助通气。
- **排除标准**：鼻导管吸氧、面罩吸氧、高流量鼻导管、手工球囊通气、仅写“备呼吸机”。
- **最小完整跨度**：`[有创机械通气]`、`[无创通气]`。
- **允许关系**：状态、时间。
- **病例判断作用**：反映治疗支持和优先级，不证明肺炎或病原。
- **正例1**：“予[有创机械通气]治疗。”
- **正例2**：“拟行[无创通气]。”实体连接假设性。
- **近似反例**：“鼻导管吸氧3L/min。”不属于机械通气。
- **常见混淆与裁决**：高流量氧疗虽可提供一定正压效应，本项目仍不归入机械通气，除非原文明确称机械通气。

### 4.9 鼻翼煽动

- **Schema状态**：C。
- **医学定义**：鼻翼煽动是吸气时鼻翼明显外展，反映儿童为降低上气道阻力而增加呼吸功。
- **项目操作定义**：标原文明写的鼻翼煽动；否定时仍标实体并连接否定。
- **纳入标准**：鼻翼煽动、鼻扇。
- **排除标准**：鼻塞、鼻分泌物、单纯张口呼吸。
- **最小完整跨度**：`[鼻翼煽动]`。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童呼吸困难体征，提高复核优先级；不能单独证明肺炎。
- **正例1**：“查体见[鼻翼煽动]。”
- **正例2**：“无[鼻翼煽动]。”实体连接否定。
- **近似反例**：“鼻塞明显。”不是鼻翼煽动。
- **常见混淆与裁决**：只按文字标，不从视频、表情或呼吸频率推断。

### 4.10 三凹征

- **Schema状态**：C。
- **医学定义**：三凹征是吸气时胸骨上窝、锁骨上窝和肋间隙出现明显凹陷，提示吸气负压增大和呼吸功增加。
- **项目操作定义**：标原文明写“三凹征”或明确描述三处吸气性凹陷；单一部位凹陷不自行归纳为三凹征。
- **纳入标准**：三凹征、吸气时胸骨上窝/锁骨上窝/肋间隙凹陷。
- **排除标准**：胸壁畸形、漏斗胸、单纯肋间隙变窄、呼气性胸壁运动。
- **最小完整跨度**：优先 `[三凹征]`；描述性文字保留必要的三处部位。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童呼吸困难体征，提高优先级；不能单独确定病因。
- **正例1**：“患儿可见[三凹征]。”
- **正例2**：“无[三凹征]。”实体连接否定。
- **近似反例**：“漏斗胸。”属于结构性胸廓改变。
- **常见混淆与裁决**：WHO常使用“下胸壁吸气性凹陷”，并不必然等于中国语境的“三凹征”；原文只写单一“下胸壁凹陷”时不自动扩成三凹征。

### 4.11 喘鸣喘息

- **Schema状态**：C。
- **医学定义**：喘鸣是气流通过狭窄气道产生的连续、较高调音乐性呼吸音；喘息也可指患者出现伴哮鸣的呼吸费力症状。
- **项目操作定义**：标原文明写的喘鸣、喘息或哮鸣音；不把所有呼吸困难或啰音归入。
- **纳入标准**：喘鸣、喘息、哮鸣音。
- **排除标准**：湿啰音、干啰音但未写哮鸣、喉鸣/吸气性喘鸣、单纯气促。
- **最小完整跨度**：`[喘息]`、`[哮鸣音]`。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童呼吸证据和鉴别信息；可见于病毒感染、细支气管炎或哮喘，不能单独证明肺炎。
- **正例1**：“患儿出现[喘息]。”
- **正例2**：“双肺闻及[哮鸣音]。”
- **近似反例**：“双肺湿啰音。”不是喘鸣喘息。
- **常见混淆与裁决**：反复喘息可由哮喘导致；病例级仍需按肺炎证据规则判断。

### 4.12 意识障碍

- **Schema状态**：C。
- **医学定义**：意识障碍是觉醒程度或意识内容异常，包括嗜睡、昏睡、昏迷、意识模糊等病理状态。
- **项目操作定义**：标原文明写的意识障碍或明确病理性意识水平下降，不从“精神欠佳”推断。
- **纳入标准**：意识障碍、嗜睡、昏睡、昏迷、意识模糊、反应差（明确病理状态时）。
- **排除标准**：睡眠中、精神一般、哭闹、疲倦、配合欠佳。
- **最小完整跨度**：`[意识障碍]`、`[嗜睡]`、`[昏迷]`。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童严重程度和复核优先级，不证明肺炎病因。
- **正例1**：“患儿呈[嗜睡]状态。”
- **正例2**：“入院时[意识模糊]。”
- **近似反例**：“夜间睡眠可。”不是意识障碍。
- **常见混淆与裁决**：“精神萎靡”若未明确意识水平改变，不标意识障碍。

### 4.13 惊厥

- **Schema状态**：C。
- **医学定义**：惊厥是由异常脑神经元活动引起的短暂发作，可表现为强直、阵挛、意识改变或局灶性运动异常。
- **项目操作定义**：标原文明写的惊厥、抽搐或癫痫样发作；不判断病因。
- **纳入标准**：惊厥、抽搐、强直阵挛发作。
- **排除标准**：寒战、肌颤、抖动、烦躁、屏气发作但未写惊厥。
- **最小完整跨度**：`[惊厥]`、`[强直阵挛发作]`。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童危险征和优先级；不能证明肺炎。
- **正例1**：“发热后出现[惊厥]。”
- **正例2**：“无[抽搐]。”实体连接否定。
- **近似反例**：“寒战明显。”不是惊厥。
- **常见混淆与裁决**：既往热性惊厥应标实体并连接既往，不自动作为本次严重度。

### 4.14 拒食或喂养困难

- **Schema状态**：C。
- **医学定义**：拒食或喂养困难指婴幼儿不能、拒绝或明显难以完成正常饮水、吸吮或进食，可反映全身病情严重或呼吸负担增加。
- **项目操作定义**：标明确的拒食、拒奶、吸吮无力、不能进食/饮水或喂养困难。
- **纳入标准**：拒食、拒奶、喂养困难、不能饮水、吸吮无力。
- **排除标准**：食欲稍差、胃纳欠佳、挑食、一次进食减少、成人食欲下降。
- **最小完整跨度**：`[拒食]`、`[喂养困难]`、`[不能饮水]`。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童危险征和优先级，不证明肺炎病因。
- **正例1**：“患儿出现[拒奶]。”
- **正例2**：“因气促致[喂养困难]。”只标显式症状，不另标因果关系。
- **近似反例**：“食欲较前稍差。”不标。
- **常见混淆与裁决**：只有原文明确达到拒绝或明显困难时标，避免把常见轻度食欲下降过度严重化。

### 4.15 脱水征

- **Schema状态**：C。
- **医学定义**：脱水是体液丢失超过摄入导致的总身体水分不足；临床可表现为口腔黏膜干燥、眼窝凹陷、泪液减少、尿量减少、皮肤弹性下降等组合。
- **项目操作定义**：标原文明写的脱水、脱水征或明确的临床综合判断；不依据单一口渴、尿少或实验室数值自行诊断。
- **纳入标准**：脱水、轻/中/重度脱水、脱水征阳性。
- **排除标准**：口干、尿少、皮肤干燥、摄入少等单一表现；电解质异常。
- **最小完整跨度**：`[重度脱水]`、`[脱水征]`。
- **允许关系**：状态、时间。
- **病例判断作用**：儿童危险征和复核优先级，不证明肺炎。
- **正例1**：“查体考虑[中度脱水]。”
- **正例2**：“无[脱水征]。”实体连接否定。
- **近似反例**：“8小时未排尿。”可作为病例证据，但不能自行补标脱水征。
- **常见混淆与裁决**：当前标签表示综合征；具体单项表现若无相应XML标签，不私创新实体。

## 5. 时间位置和病程标签

这些标签描述文本中的时间语义，不是疾病实体。只有原文存在可选中的提示词才标，不根据章节或语法时态补造跨度。

### 5.1 当前

- **Schema状态**：A/C。
- **医学定义**：无独立医学诊断意义；表示事件相对于索引临床事件处于当前、本次或现阶段。
- **项目操作定义**：标“今、今日、目前、现、本次”等明确当前提示词，并通过时间关系连接被修饰事件。
- **纳入标准**：今、今日、目前、现、此次、本次、当前。
- **排除标准**：普通现在时陈述；检查日期；“现病史”章节标题。
- **最小完整跨度**：`[目前]`、`[本次]`。
- **允许关系**：时间；端点为症状、诊断、暴露或检测事件。
- **病例判断作用**：帮助确认实体属于索引事件；本身不改变病例分类。
- **正例1**：“[目前]仍有发热。”目前—时间—发热。
- **正例2**：“[本次]因肺炎住院。”本次—时间—肺炎。
- **近似反例**：“现病史：发热2天。”章节名不标当前。
- **常见混淆与裁决**：同句有多个事件时，只连接语义上受其修饰的事件。

### 5.2 既往

- **Schema状态**：A/C。
- **医学定义**：无独立医学诊断意义；表示事件发生于非索引的过去病史。
- **项目操作定义**：标“既往、曾、数年前患”等明确过去史提示词；具体日期不自动等于既往。
- **纳入标准**：既往、曾患、既往有、数年前患、病史多年（明确非本次时）。
- **排除标准**：同次住院早期；当前复诊明确引用并继续作为诊疗依据的旧检查；单纯日期。
- **最小完整跨度**：`[既往]`、`[曾患]`。
- **允许关系**：时间。
- **病例判断作用**：将纯既往肺炎与索引事件分开，支持排除。
- **正例1**：“[既往]有肺炎史。”
- **正例2**：“5年前[曾患]肺炎。”
- **近似反例**：“上周CT示肺炎，本次继续治疗。”若满足连续诊疗四项条件，不按纯既往排除。
- **常见混淆与裁决**：章节“既往史”可提供默认过去语境，但没有可选提示词时不补造“既往”实体；后处理可使用章节信息。

### 5.3 进行性加重

- **Schema状态**：A/C。
- **医学定义**：症状、体征或疾病在一段时间内呈持续、逐步恶化的病程趋势，而非单一时点变重。
- **项目操作定义**：仅标明确表达渐进恶化的词组。
- **纳入标准**：逐渐加重、进行性加重、持续恶化、日益加重、越来越重。
- **排除标准**：今日加重、突然加重、症状重、严重肺炎；这些不一定表示渐进趋势。
- **最小完整跨度**：`[逐渐加重]`、`[进行性恶化]`。
- **允许关系**：时间。
- **病例判断作用**：提高活动性和复核优先级，不单独证明肺炎。
- **正例1**：“气促[逐渐加重]。”
- **正例2**：“近1周症状[进行性恶化]。”
- **近似反例**：“今日咳嗽加重。”是单次变化，不标进行性加重。
- **常见混淆与裁决**：“反复发作”不是进行性加重；当前Schema没有反复标签，可由时间表达或病例证据保留。

### 5.4 持续

- **Schema状态**：A/C。
- **医学定义**：症状或疾病在观察时段内仍存在、未消失或治疗后未明显改善。
- **项目操作定义**：标“仍有、一直、持续、未愈、无好转、效不佳”等明确持续语义。
- **纳入标准**：仍有、持续存在、一直、未缓解、无好转、治疗效果不佳。
- **排除标准**：时长“3天”本身；反复但每次可完全缓解；单次出现。
- **最小完整跨度**：`[仍有]`、`[无好转]`、`[持续存在]`。
- **允许关系**：时间。
- **病例判断作用**：说明当前活动性或治疗后仍存在，用于优先级和索引归属。
- **正例1**：“治疗后[仍有]咳嗽。”
- **正例2**：“发热[持续不退]。”
- **近似反例**：“咳嗽3天。”3天是时间表达，不等于持续标签。
- **常见混淆与裁决**：“好转但仍有少量咳嗽”可标仍有；好转本身不设人工标签。

### 5.5 TimeExpression

- **Schema状态**：R。
- **医学定义**：不是医学实体；是原文中可定位的日期、相对时间、时长、病程日序或时间窗口。
- **项目操作定义**：人工只选择原文时间跨度，标准日期和区间由程序结合文档时间归一化。
- **纳入标准**：2026-08-28、7月15日、昨日、1周前、入院前2天、3天、住院第2日、近7天。
- **排除标准**：当前、既往、仍有、逐渐加重；没有时间意义的序号或检验数值。
- **最小完整跨度**：保留介词形成的相对参照，如 `[入院前2天]`；“持续3天”只标 `[3天]`。
- **允许关系**：时间。
- **病例判断作用**：帮助判断索引归属、急慢性和时序，不由人工填写标准日期。
- **正例1**：“[1周前]出现发热。”
- **正例2**：“症状持续[3天]。”
- **近似反例**：“目前发热。”目前标当前，不标TimeExpression。
- **常见混淆与裁决**：当前XML未批准前，只保留在病例级证据或自动解析结果中。

## 6. 断言和主体标签

断言标签只在原文有可选择的提示词时创建，并通过“状态”关系连接到目标实体。普通肯定陈述不补造“肯定”。

### 6.1 肯定

- **Schema状态**：A/C。
- **医学定义**：表示原文明确确认某个检测结果、事实或病原存在；不是标注员对事实真实性的评价。
- **项目操作定义**：标阳性、检出、培养见、证实、弱阳性等明确存在性结果词。
- **纳入标准**：阳性、检出、培养出、证实、发现、弱阳性。
- **排除标准**：普通陈述“患者发热”；可疑阳性、临界；项目名称无结果。
- **最小完整跨度**：`[阳性]`、`[弱阳性]`、`[未检出]`中的“未检出”不能拆成肯定。
- **允许关系**：状态；连接症状、诊断、暴露、病原体或检测相关实体。
- **病例判断作用**：确定检测或事实极性；病原肯定不等于肺炎。
- **正例1**：“肺炎支原体IgM[阳性]。”
- **正例2**：“痰培养[检出]肺炎克雷伯菌。”
- **近似反例**：“考虑肺炎支原体感染。”属于可疑，不标肯定。
- **常见混淆与裁决**：弱阳性按肯定记录原文极性，但其临床解释仍依赖标本、方法和索引事件。

### 6.2 否定

- **Schema状态**：A/C。
- **医学定义**：表示原文明确否认某症状、疾病、暴露或报告检测未发现目标。
- **项目操作定义**：标无、未见、否认、阴性、未检出、不伴等否定词，并连接其实际作用对象。
- **纳入标准**：无、未、否认、阴性、未检出、不伴、排除（仅明确结论时）。
- **排除标准**：不除外、待排；“排除肺炎”若只是检查目的而非结论；无改善中的“无”应整体标持续语义而非否定疾病。
- **最小完整跨度**：`[阴性]`、`[未检出]`、`[否认]`。
- **允许关系**：状态。
- **病例判断作用**：防止把不存在或阴性的证据当成当前事实。
- **正例1**：“[无]发热。”无—状态—发热。
- **正例2**：“肺炎支原体IgM[阴性]。”
- **近似反例**：“不除外肺炎。”不标否定，标可疑。
- **常见混淆与裁决**：并列“无咳嗽、发热、气促”语法作用域明确时，对三个实体分别连状态关系。

### 6.3 可疑

- **Schema状态**：A/C。
- **医学定义**：表示临床或检验结论存在可能性，但尚未达到确定诊断或明确阳性。
- **项目操作定义**：标疑似、考虑、不除外、待排、可疑阳性、临界等词。
- **纳入标准**：疑似、考虑、不除外、待排、可疑、临界、不排除污染。
- **排除标准**：明确确诊；明确阴性；计划实施某项检查；纯鉴别诊断列表且没有针对患者的判断语气。
- **最小完整跨度**：`[不除外]`、`[可疑阳性]`、`[待排]`。
- **允许关系**：状态。
- **病例判断作用**：疑似肺炎可触发待专业复核，但不能作为目标直接证据。
- **正例1**：“[不除外]肺炎。”
- **正例2**：“肺炎支原体[可疑阳性]。”
- **近似反例**：“拟行CT排除肺炎。”拟行标假设性，排除是检查目的，不额外标可疑。
- **常见混淆与裁决**：“考虑”有时表示治疗决策而非诊断可能性，应连接其实际目标，不可机械连接最近实体。

### 6.4 条件性

- **Schema状态**：A/C。
- **医学定义**：表示某事件只有在条件成立时才可能发生，当前不能确认条件或事件已发生。
- **项目操作定义**：标若、如出现、必要时、视情况等条件触发词。
- **纳入标准**：若、如果、如出现、必要时、视病情。
- **排除标准**：计划、建议、考虑；已经发生的事实；“如前所述”不是条件。
- **最小完整跨度**：`[若]`、`[如出现]`、`[必要时]`。
- **允许关系**：状态。
- **病例判断作用**：防止把条件性症状、检测或治疗当成当前事实。
- **正例1**：“[若]出现发热，及时复诊。”
- **正例2**：“[必要时]给予机械通气。”条件性 ↔ 机械通气。
- **近似反例**：“计划明日行CT。”属于假设性/计划。
- **常见混淆与裁决**：条件词可以同时作用多个并列事件，只有语法范围明确时逐一连边。

### 6.5 假设性

- **Schema状态**：A/C。
- **医学定义**：表示计划、建议、拟实施或预期的事件，尚不能证明已发生。
- **项目操作定义**：标拟、计划、建议、将行、考虑行等计划词。
- **纳入标准**：拟、计划、建议、将行、拟予、考虑行检查。
- **排除标准**：已完成、检查示、予以治疗（明确已实施）；疑似诊断。
- **最小完整跨度**：`[拟]`、`[计划]`、`[建议]`、`[将行]`。
- **允许关系**：状态。
- **病例判断作用**：计划检查或治疗不能作为已发生的肺炎、病原或严重度证据。
- **正例1**：“[拟]行新冠核酸检测。”
- **正例2**：“[建议]复查新冠病毒核酸检测。”假设性分别连接新冠病毒和核酸检测。
- **近似反例**：“新冠病毒核酸检测已完成。”不是计划。
- **常见混淆与裁决**：“考虑肺炎”是可疑；“考虑行CT”是计划，应根据被修饰对象判断。

### 6.6 与患者本人无关

- **Schema状态**：A/C。
- **医学定义**：这是experiencer（经历主体）属性，表示症状、疾病、暴露或检测事实属于患者以外的人。
- **项目操作定义**：标家属、母亲、父亲、同事、接触者等主体词，并连接到不属于患者的医学实体。
- **纳入标准**：母亲、家属、同事、同住人、接触者、患儿哥哥等明确他人主体。
- **排除标准**：患者本人；医生作为记录者；“家族史”章节标题但没有具体相关实体。
- **最小完整跨度**：`[母亲]`、`[同事]`、`[接触者]`。
- **允许关系**：状态。
- **病例判断作用**：防止把他人的肺炎、发热或病原结果归给患者。
- **正例1**：“[母亲]近期患肺炎。”
- **正例2**：“其[同事]新冠阳性。”
- **近似反例**：“患者照顾患病母亲。”母亲可作为他人主体，但患者的接触暴露需另按原文标暴露，不自动生成感染。
- **常见混淆与裁决**：标的是主体提示词，不是“无关”二字；同一段出现患者和家属多个事件时必须逐项连接。

## 7. 生理测量标签

### 7.1 体温

- **Schema状态**：A；儿童当前XML无此测量指标。
- **医学定义**：体温是机体核心或外周部位测得的温度，可通过口腔、腋下、耳、直肠等方式测量。
- **项目操作定义**：标测量指标名称或生命体征字段T；数值、单位、比较符和阈值另标并用测量关系连接。
- **纳入标准**：体温、T（明确生命体征字段）、腋温、耳温。
- **排除标准**：发热症状、热感、室温、药品保存温度。
- **最小完整跨度**：`[体温]`、`[T]`。
- **允许关系**：测量；也可由时间关系修饰测量事件。
- **病例判断作用**：提供客观温度数据；人工不按数值自行生成发热实体。
- **正例1**：“[T] 38.5 ℃。”
- **正例2**：“[腋温] 37.8 ℃。”
- **近似反例**：“高热3天。”标发热症状，不补体温指标。
- **常见混淆与裁决**：儿童XML缺少该指标时不得私创；仍可把温度原文保留为病例证据。

### 7.2 呼吸频率

- **Schema状态**：A/C。
- **医学定义**：呼吸频率是单位时间内完成的呼吸周期数，通常以次/分钟表示，受年龄、活动、发热和疾病影响。
- **项目操作定义**：标呼吸频率、RR或生命体征字段R；不自行按年龄阈值生成“呼吸急促”。
- **纳入标准**：呼吸频率、RR、R（明确生命体征）、每分钟呼吸次数。
- **排除标准**：心率、脉率、呼吸音、呼吸困难症状。
- **最小完整跨度**：`[呼吸频率]`、`[RR]`、`[R]`。
- **允许关系**：测量。
- **病例判断作用**：客观呼吸严重度证据；阈值解释由程序或专业规则完成。
- **正例1**：“[R] 32次/分。”
- **正例2**：“[呼吸频率] 48次/分。”
- **近似反例**：“呼吸音粗。”不是呼吸频率。
- **常见混淆与裁决**：儿童呼吸增快阈值与年龄有关，本项目不要求标注员用医学常识添加阈值判断。

### 7.3 静息状态指氧饱和度

- **Schema状态**：A/C。
- **医学定义**：脉搏血氧饱和度（SpO2）是脉搏血氧仪估计的动脉血红蛋白氧饱和百分比；静息值指患者未进行运动或负荷时的测量。
- **项目操作定义**：标SpO2、指氧、血氧饱和度；常规生命体征且未注明运动时默认静息。明确运动后/步行试验值不标为静息状态指氧饱和度。
- **纳入标准**：SpO2、指氧饱和度、血氧饱和度、静息指氧。
- **排除标准**：SaO2实验室血气结果若原文明确；PaO2；运动后SpO2；吸氧浓度。
- **最小完整跨度**：`[SpO2]`、`[静息指氧饱和度]`。
- **允许关系**：测量。
- **病例判断作用**：低氧客观证据和优先级；不自动诊断呼吸衰竭。
- **正例1**：“[SpO2] 92%（空气）。”
- **正例2**：“静息[血氧饱和度] 95%。”
- **近似反例**：“步行后SpO2 88%。”明确负荷后，不归静息标签。
- **常见混淆与裁决**：吸空气/吸氧状态应保留在病例证据，但当前XML没有氧疗状态专门关系。

### 7.4 动脉氧分压(PaO2)

- **Schema状态**：A/C。
- **医学定义**：PaO2是动脉血中溶解氧产生的分压，是动脉血气分析的氧合指标，单位常为mmHg或kPa。
- **项目操作定义**：仅标明确的PaO2或动脉氧分压，不把静脉血PO2或SpO2归入。
- **纳入标准**：PaO2、动脉氧分压、动脉血氧分压。
- **排除标准**：PvO2/静脉氧分压、SpO2、氧合指数、吸氧浓度。
- **最小完整跨度**：`[PaO2]`、`[动脉氧分压]`。
- **允许关系**：测量。
- **病例判断作用**：客观氧合和严重度证据；不自动生成低氧或呼吸衰竭诊断。
- **正例1**：“[PaO2] 58 mmHg。”
- **正例2**：“[动脉氧分压]低于正常。”
- **近似反例**：“静脉血PO2 40mmHg。”不是PaO2。
- **常见混淆与裁决**：若只写PO2且标本类型不明，不自行判断动脉或静脉。

### 7.5 吸氧浓度(FiO2)

- **Schema状态**：A/C。
- **医学定义**：FiO2是吸入气体中氧所占的体积分数，可用小数或百分比表示。
- **项目操作定义**：标FiO2或吸氧浓度；不把氧流量L/min换算成FiO2。
- **纳入标准**：FiO2、吸入氧浓度、吸氧浓度。
- **排除标准**：鼻导管3L/min、氧饱和度、PaO2、空气状态但无FiO2表达。
- **最小完整跨度**：`[FiO2]`、`[吸氧浓度]`。
- **允许关系**：测量。
- **病例判断作用**：解释氧合测量和支持强度；不证明肺炎。
- **正例1**：“[FiO2] 40%。”
- **正例2**：“[吸氧浓度] 0.5。”
- **近似反例**：“氧流量3L/min。”不换算、不标FiO2。
- **常见混淆与裁决**：室内空气理论FiO2约21%，但原文未写时不补标。

### 7.6 数值

- **Schema状态**：A/C。
- **医学定义**：测量结果的定量部分，本身没有指标语义。
- **项目操作定义**：只标与本项目测量指标明确配对的数字，不标日期、病历号、检验列表中无关数值。
- **纳入标准**：38.5、92、60、0.40等明确测量值。
- **排除标准**：2026-08-28、住院号、药物剂量、白细胞数值、无对应指标的孤立数字。
- **最小完整跨度**：只选数字及必要小数/范围，如 `[38.5]`、`[92-94]`。
- **允许关系**：测量。
- **病例判断作用**：组成可计算的客观测量。
- **正例1**：“SpO2 [92]%。”
- **正例2**：“PaO2 [58] mmHg。”
- **近似反例**：“住院第2日。”数字2属于时间表达，不标测量数值。
- **常见混淆与裁决**：多项生命体征并列时必须按指标和语义唯一配对。

### 7.7 单位

- **Schema状态**：A/C。
- **医学定义**：说明数值量纲的标准符号或文字。
- **项目操作定义**：标与本项目测量指标对应的单位。
- **纳入标准**：℃、次/分、%、mmHg、kPa。
- **排除标准**：药物mg、检验U/L、日期单位“天”作为时间表达。
- **最小完整跨度**：`[℃]`、`[次/分]`、`[%]`、`[mmHg]`。
- **允许关系**：测量。
- **病例判断作用**：保证数值可正确解释和归一化。
- **正例1**：“体温38.5[℃]。”
- **正例2**：“PaO2 58[mmHg]。”
- **近似反例**：“咳嗽3天。”天是时间单位，整体作为TimeExpression。
- **常见混淆与裁决**：单位可与多个指标相同，必须连到正确端点。

### 7.8 比较符

- **Schema状态**：A/C。
- **医学定义**：表示数值与阈值之间大小关系的符号或短语。
- **项目操作定义**：标原文明写的<、>、≤、≥、不低于、高于等比较表达。
- **纳入标准**：<、>、≤、≥、低于、高于、不超过。
- **排除标准**：趋势词“较前升高”；箭头↑↓；模糊词“约”。
- **最小完整跨度**：`[<]`、`[不低于]`。
- **允许关系**：测量。
- **病例判断作用**：支持阈值计算，不由标注员决定临床异常。
- **正例1**：“SpO2 [<]93%。”
- **正例2**：“体温[高于]38℃。”
- **近似反例**：“CRP较前升高。”不是本项目测量比较符。
- **常见混淆与裁决**：比较符、数值、单位分别标，均连接同一指标。

### 7.9 阈值判断

- **Schema状态**：A/C。
- **医学定义**：原文对测量值是否达到某临床阈值或是否异常的定性判断。
- **项目操作定义**：只标原文明写的异常、高/低于正常、达到重症标准等判断，不根据数值自行推断。
- **纳入标准**：异常、低于正常、达到阈值、低氧（明确作为测量判断时）。
- **排除标准**：标注员根据医学知识判断；来源含义不明的箭头；检验系统自动H/L但无解释。
- **最小完整跨度**：`[低于正常]`、`[异常]`。
- **允许关系**：测量。
- **病例判断作用**：保留原文对严重度阈值的解释；不等同临床诊断。
- **正例1**：“SpO2低于正常。”标 `[低于正常]`并连SpO2。
- **正例2**：“呼吸频率达到重症阈值。”标 `[达到重症阈值]`。
- **近似反例**：“SpO2 92%。”没有原文阈值判断，不补标异常。
- **常见混淆与裁决**：若系统字段明确规定↑/↓代表异常，可由项目负责人批准纳入；否则不标。

## 8. 流行病学职业和暴露标签

暴露标签记录原文事实，不表示暴露已经导致感染。允许状态、时间关系；只有病例已有呼吸证据时才影响优先级。

### 8.1 医务人员

- **Schema状态**：A。
- **医学定义**：从事医疗、护理、公共卫生、院内辅助诊疗等工作，可能因职业接触患者或医疗环境而增加特定病原暴露机会的人群。
- **项目操作定义**：标患者本人的医务职业身份，不标记录医生或他人职业。
- **纳入标准**：医生、护士、医技人员、院内直接接触患者的医务人员。
- **排除标准**：患者到医院就诊；家属为护士但患者不是；医院行政职业是否纳入需原文明写医务身份。
- **最小完整跨度**：`[护士]`、`[医务人员]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时用于复核优先级；不单独触发病例。
- **正例1**：“患者职业为[护士]。”
- **正例2**：“从事[临床医生]工作。”
- **近似反例**：“由急诊医生接诊。”医生不是患者。
- **常见混淆与裁决**：职业属于家属时连接“与患者本人无关”，不能归给患者。

### 8.2 禽、畜类从业人员

- **Schema状态**：A。
- **医学定义**：职业性接触家禽、家畜或其屠宰、加工、运输、销售环节的人员，可能面临动物源呼吸道病原暴露。
- **项目操作定义**：标患者本人的相关职业，不把一次动物接触标成职业。
- **纳入标准**：养禽/养畜人员、屠宰工、活禽销售、禽畜运输或加工人员。
- **排除标准**：普通宠物饲养、偶然参观农场、食用熟禽肉。
- **最小完整跨度**：`[家禽养殖人员]`、`[屠宰工]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时提高动物源病原复核优先级。
- **正例1**：“职业：[家禽养殖]。”
- **正例2**：“长期从事[活禽屠宰]。”
- **近似反例**：“家中养一只宠物鸟。”属于动物接触，不是从业人员。
- **常见混淆与裁决**：职业和具体接触可同时标，但必须各有原文跨度。

### 8.3 农牧民等野外作业人员

- **Schema状态**：A。
- **医学定义**：长期从事农业、牧业、林业或其他野外环境作业的人群，可能接触土壤、野生动物、气溶胶或环境源病原。
- **项目操作定义**：标患者明确的农牧或野外作业职业身份。
- **纳入标准**：农民、牧民、林业工人、长期野外作业人员。
- **排除标准**：偶尔户外运动、一次旅行、居住农村但未写职业。
- **最小完整跨度**：`[牧民]`、`[野外作业人员]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时用于环境/动物源暴露优先级。
- **正例1**：“患者为[牧民]。”
- **正例2**：“职业为[野外地质作业]。”
- **近似反例**：“周末曾露营。”不是职业。
- **常见混淆与裁决**：外出露营可按可疑环境暴露或外出史记录，不标职业。

### 8.4 病原微生物实验室检测人员

- **Schema状态**：A。
- **医学定义**：在实验室直接处理病原微生物、临床微生物标本或培养物，存在职业性实验室暴露可能的人员。
- **项目操作定义**：标患者本人明确从事病原或临床微生物实验室检测的职业。
- **纳入标准**：微生物检验人员、病原检测实验员、培养室工作人员。
- **排除标准**：普通化学实验员、影像技师、病理报告中出现“实验室”、患者做过病原检测。
- **最小完整跨度**：`[病原检测实验员]`、`[微生物检验人员]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时提高职业暴露复核优先级。
- **正例1**：“患者为[微生物检验人员]。”
- **正例2**：“在[病原实验室]从事实验操作。”标能表达职业身份的完整跨度。
- **近似反例**：“送实验室行培养。”不是患者职业。
- **常见混淆与裁决**：仅写“实验员”但实验内容不明时不归入本标签。

### 8.5 可疑动物或动物制品接触史

- **Schema状态**：A/C。
- **医学定义**：与活体、病死动物、动物分泌物/排泄物或未经充分处理的动物制品发生接触，可能构成动物源病原暴露。
- **项目操作定义**：标原文明写的动物或动物制品接触事件，不由标注员判断是否真正导致感染。
- **纳入标准**：接触病禽/病畜、清理鸟粪、处理病死动物、接触活禽、加工生动物制品。
- **排除标准**：仅写职业但无具体接触；食用充分烹熟禽肉；远距离看见动物；普通宠物史无接触描述。
- **最小完整跨度**：保留接触行为和对象，如 `[接触病死家禽]`、`[清理鸟粪]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时提高动物源病原复核优先级，不单独触发病例。
- **正例1**：“发病前曾[接触病死家禽]。”
- **正例2**：“近期[清理大量鸟粪]。”
- **近似反例**：“家中有宠物。”没有明确接触事件和风险语境。
- **常见混淆与裁决**：鹦鹉热相关禽鸟暴露与病原检测是两类证据，不能从暴露补造鹦鹉热衣原体阳性。

### 8.6 可疑环境暴露史

- **Schema状态**：A/C。
- **医学定义**：与可能含病原气溶胶、污染水体、土壤、建筑粉尘、动物排泄物或特定聚集环境发生接触。
- **项目操作定义**：标明确的环境接触事件；不把普通居住地、天气或一般外出自动视为可疑环境暴露。
- **纳入标准**：进入活禽市场、接触污染水体/冷却塔气溶胶、洞穴/鸟粪环境、施工粉尘暴露等原文明写事件。
- **排除标准**：普通居住小区、季节变化、空调使用但无污染语境、一般公共场所到访。
- **最小完整跨度**：`[进入活禽市场]`、`[接触冷却塔气溶胶]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时提高特定环境源病原复核优先级。
- **正例1**：“近期曾[进入活禽市场]。”
- **正例2**：“工作中[接触建筑粉尘]。”
- **近似反例**：“居住在老旧小区。”没有明确暴露事件。
- **常见混淆与裁决**：本任务不标地址或GIS聚集；只保存原文暴露事实。

### 8.7 外出外来史

- **Schema状态**：A/C。
- **医学定义**：患者在索引事件相关时间窗内离开常住地、从外地来到本地或有旅行/旅居经历。
- **项目操作定义**：标明确的旅行、旅居、返乡、外地来访等事件；不负责地理编码和聚集判断。
- **纳入标准**：外地返沪、近期旅行、境外归来、外来人员、异地旅居。
- **排除标准**：院内转科、同城就医、多年前迁居、籍贯信息。
- **最小完整跨度**：`[外地返沪]`、`[境外旅行]`。
- **允许关系**：状态、时间。
- **病例判断作用**：已有呼吸信号时用于复核优先级和后续调查线索，不单独触发病例。
- **正例1**：“近7天有[外地旅行史]。”
- **正例2**：“患者为[外来务工人员]，近期到本地。”需保留实际外来语义。
- **近似反例**：“籍贯安徽。”不是近期外出外来史。
- **常见混淆与裁决**：时间窗口由TimeExpression或后处理确定，标注员不自行设固定天数。

## 9. 检测标本标签

标本标签表示实验室检测所使用的患者材料，而不是症状、影像所见或解剖部位。只有标本与病原体属于同一条检验记录时才建立“标本”关系；不评价采样质量，也不依据常识补出未写明的标本。

### 9.1 咽/鼻咽拭子

- **Schema状态**：A/C。
- **医学定义**：用拭子采集咽后壁、扁桃体区或鼻咽部上皮细胞和分泌物形成的上呼吸道标本，常用于呼吸道病原核酸或抗原检测。
- **项目操作定义**：标原文明写的“咽拭子、鼻咽拭子、口咽拭子、鼻咽部拭子”；不把“咽部、鼻腔”解剖部位单独当作标本。
- **纳入标准**：咽拭子、鼻咽拭子、口咽拭子、鼻/咽联合拭子。
- **排除标准**：咽痛、咽部充血、鼻分泌物、鼻腔冲洗液、未写采样方式的“呼吸道标本”。
- **最小完整跨度**：`[鼻咽拭子]`、`[咽拭子]`；联合词完整保留。
- **允许关系**：标本；连接同组病原体。
- **病例判断作用**：说明病原结果来自上呼吸道直接采样；阳性仍需结合方法、断言和索引事件。
- **正例1**：“[鼻咽拭子]新冠病毒核酸阳性。”
- **正例2**：“[咽拭子]检出流感病毒。”
- **近似反例**：“咽部充血明显。”没有检验标本。
- **常见混淆与裁决**：“鼻拭子”若XML无独立标签且明确用于呼吸道检测，可归入本标签；不得把鼻腔冲洗液强行归入。

### 9.2 痰

- **Schema状态**：A/C。
- **医学定义**：由下呼吸道咳出、用于微生物学或其他实验室检测的呼吸道分泌物；与口腔唾液不同。
- **项目操作定义**：只有“痰培养、痰标本、痰液PCR”等采样或检验语境中的“痰”才标；症状“咳痰、痰多、黄痰”不标为标本。
- **纳入标准**：痰标本、痰液培养中的痰、自留痰、诱导痰。
- **排除标准**：咳痰、黄痰、痰量、痰鸣音、唾液；仅写“下呼吸道标本”但未明确痰。
- **最小完整跨度**：`[痰]培养`、`[诱导痰]`、`[痰标本]`。
- **允许关系**：标本。
- **病例判断作用**：支持结果来自下呼吸道材料，但不能消除定植或污染可能。
- **正例1**：“[痰]培养检出肺炎克雷伯菌。”
- **正例2**：“送[诱导痰]行PCR。”
- **近似反例**：“咳大量黄痰。”这是症状，不是检验标本。
- **常见混淆与裁决**：同一句“咳痰，痰培养阳性”中，第一个痰属于症状表达，第二个痰才是标本。

### 9.3 肺泡灌洗液

- **Schema状态**：A/C。
- **医学定义**：经支气管镜将无菌液体注入远端支气管肺泡后回收的下呼吸道标本，常称支气管肺泡灌洗液（BALF）。
- **项目操作定义**：标明确的BALF、支气管肺泡灌洗液；不因出现“支气管镜”自动补标。
- **纳入标准**：肺泡灌洗液、支气管肺泡灌洗液、BALF（语境明确）。
- **排除标准**：支气管镜检查、支气管冲洗液、灌洗操作计划、来源不明的“灌洗液”。
- **最小完整跨度**：`[支气管肺泡灌洗液]`、`[BALF]`。
- **允许关系**：标本。
- **病例判断作用**：提示下呼吸道直接取样；结果相关性通常高于上呼吸道标本，但仍需结合定植、污染和临床背景。
- **正例1**：“[BALF] mNGS检出鹦鹉热衣原体。”
- **正例2**：“[支气管肺泡灌洗液]培养曲霉菌阳性。”
- **近似反例**：“拟行支气管镜检查。”未表达标本已取得。
- **常见混淆与裁决**：支气管冲洗液与BALF采样层级不同；原文未明确BALF时不升级归类。

### 9.4 血

- **Schema状态**：A/C。
- **医学定义**：用于病原培养、核酸、抗原或抗体检测的全血、血浆或血清材料；不同成分反映直接病原证据或宿主免疫反应。
- **项目操作定义**：只标病原相关检验中的血、全血、血浆、血清；血常规、生化或“出血”不属于本标本标签。
- **纳入标准**：血培养中的血、全血PCR、血浆病原检测、血清IgM/抗体滴度。
- **排除标准**：血常规、白细胞、CRP、血气分析、咯血、出血、未用于病原检测的静脉血。
- **最小完整跨度**：`[血]培养`、`[全血]`、`[血清]`、`[血浆]`。
- **允许关系**：标本。
- **病例判断作用**：解释证据类型；血清IgM属于间接免疫学证据，不能按呼吸道标本直接检出规则触发待复核。
- **正例1**：“[血]培养检出肺炎链球菌。”
- **正例2**：“[血清]肺炎支原体IgM阳性。”
- **近似反例**：“血常规白细胞升高。”不是病原检测标本事件。
- **常见混淆与裁决**：同属“血”不代表证据强度相同；必须同时标检测方式，区分培养/核酸与抗体。

### 9.5 尿

- **Schema状态**：A/C。
- **医学定义**：采集尿液作为检测材料，可用于某些病原可溶性抗原检测，例如军团菌或肺炎链球菌尿抗原。
- **项目操作定义**：标病原检测语境中的尿或尿标本，包括呼吸相关尿抗原和检出XML内病原的尿培养；尿标本结果不是呼吸道标本证据。
- **纳入标准**：军团菌尿抗原中的尿、肺炎链球菌尿抗原、尿标本病原检测。
- **排除标准**：尿常规、尿频、尿痛。普通尿培养若检出XML内病原，仍标尿—标本—病原体和培养—检测方式—病原体，但不触发呼吸道标本阳性入口；仅写“尿抗原”且无结果时不补阳性。
- **最小完整跨度**：`[尿]抗原`、`[尿标本]`。
- **允许关系**：标本。
- **病例判断作用**：说明非呼吸道标本中的病原抗原证据；不套用“呼吸道标本明确检出”的自动入口。
- **正例1**：“[尿]军团菌抗原阳性。”
- **正例2**：“送[尿标本]行肺炎链球菌抗原检测。”
- **近似反例**：“尿培养大肠埃希菌阳性。”与肺炎病原入口无关。
- **常见混淆与裁决**：尿抗原阳性可有临床价值，但项目病例分类仍需肺炎/呼吸证据和索引事件，不能仅凭标本名称判断。

### 9.6 胸水

- **Schema状态**：A/C。
- **医学定义**：从胸膜腔积液中抽取的液体标本，可用于培养、核酸或抗原等检测；影像学“胸腔积液”本身不是已取得的标本。
- **项目操作定义**：标明确被采集或送检的胸水、胸腔积液标本、胸液；不标单纯影像所见。
- **纳入标准**：胸水培养、胸腔积液标本PCR、胸液送检。
- **排除标准**：CT示胸腔积液、胸水少量但未取样、胸腔穿刺计划。
- **最小完整跨度**：`[胸水]`、`[胸腔积液标本]`。
- **允许关系**：标本。
- **病例判断作用**：可支持胸膜腔感染相关病原证据；仍需判断其与肺炎索引事件的关系。
- **正例1**：“[胸水]培养肺炎链球菌阳性。”
- **正例2**：“[胸腔积液标本]核酸检出病原体。”
- **近似反例**：“影像提示少量胸腔积液。”未形成检验标本。
- **常见混淆与裁决**：胸水可以是感染性或非感染性；病原阴性或无病原检测时不能仅由胸水推断感染。

## 10. 病原检测方式标签

检测方式说明结果是怎样获得的。它不等于结果状态；“PCR”与“阳性”必须分别标注，方法连接病原体，结果词通过“状态”关系连接病原体或检测事件。

### 10.1 核酸检测

- **Schema状态**：A/C。
- **医学定义**：通过扩增或其他分子方法检测病原体核酸的检测，包括PCR、RT-PCR及明确的核酸扩增检测；它提示样本中存在目标核酸，不必然证明活病原或有症状感染。
- **项目操作定义**：标明确用于病原检测的核酸检测、PCR、RT-PCR、NAAT；不标肿瘤基因检测或没有病原语境的“PCR”。
- **纳入标准**：病原核酸、PCR、RT-PCR、实时荧光PCR、核酸扩增试验。
- **排除标准**：mNGS（另标）、测序、基因分型而无病原检测语境、仅计划但未实施的检测需同时连接假设性。
- **最小完整跨度**：`[核酸检测]`、`[RT-PCR]`。
- **允许关系**：检测方式。
- **病例判断作用**：与明确病原、标本和肯定结果共同解释直接检出证据；单独出现不触发病例分类。
- **正例1**：“鼻咽拭子新冠病毒[核酸检测]阳性。”
- **正例2**：“流感病毒[RT-PCR]未检出。”
- **近似反例**：“肿瘤组织EGFR基因PCR检测。”不是呼吸道病原检测。
- **常见混淆与裁决**：核酸阳性可来自残留核酸、定植或污染；标注忠实记录结果，不自行判断致病性。

### 10.2 mNGS

- **Schema状态**：A/C。
- **医学定义**：宏基因组下一代测序，对标本中的多种微生物核酸进行非靶向或广谱测序与生物信息学比对。
- **项目操作定义**：标mNGS、宏基因组测序、病原宏基因组二代测序；普通靶向测序或肿瘤NGS不标。
- **纳入标准**：mNGS、宏基因组二代测序、宏基因组高通量测序（病原语境）。
- **排除标准**：NGS但用途不明、肿瘤基因测序、16S测序未被当前Schema明确定义为mNGS。
- **最小完整跨度**：`[mNGS]`、`[宏基因组二代测序]`。
- **允许关系**：检测方式。
- **病例判断作用**：说明广谱病原检测来源；序列数、背景菌和污染需专业解释，标签本身不代表致病。
- **正例1**：“BALF [mNGS]检出鹦鹉热衣原体。”
- **正例2**：“送肺泡灌洗液行[宏基因组测序]。”
- **近似反例**：“肺癌组织行NGS。”不是病原mNGS。
- **常见混淆与裁决**：仅列出微生物序列但没有明确方法时，不反推mNGS标签。

### 10.3 抗原快速检测

- **Schema状态**：A/C。
- **医学定义**：通过免疫层析等快速方法检测病原体蛋白或其他抗原成分，通常报告阳性/阴性，性能受病程和样本量影响。
- **项目操作定义**：标抗原快速检测、抗原快检、胶体金抗原等明确快速抗原方法；不标抗体或泛称“抗原”而无检测方法。
- **纳入标准**：抗原快检、快速抗原检测、胶体金法抗原检测。
- **排除标准**：未明确“快速/快检/胶体金”等方法的普通抗原或尿抗原、IgM/IgG、抗原名称、疫苗抗原。普通抗原文本只标可明确的标本、病原和状态；当前XML不能表达其方法时记录Schema缺口，不强行映射为快速检测。
- **最小完整跨度**：`[抗原快速检测]`、`[抗原快检]`。
- **允许关系**：检测方式。
- **病例判断作用**：解释直接抗原证据；须结合标本、病原和结果状态。
- **正例1**：“鼻拭子流感病毒[抗原快检]阳性。”
- **正例2**：“新冠病毒[快速抗原检测]阴性。”
- **近似反例**：“肺炎支原体IgM抗体阳性。”这是抗体方法。
- **常见混淆与裁决**：当前XML名称含“快速”，因此原文只写“抗原检测”时不画本方法标签；不得在未批准前扩大标签含义。

### 10.4 抗体IgM

- **Schema状态**：A/C。
- **医学定义**：检测患者针对某病原体产生的IgM类特异性抗体，属于宿主免疫应答的间接证据；可受检测时机、交叉反应、持续阳性和假阳性影响。
- **项目操作定义**：标明确的病原特异性IgM或IgM抗体；不标总IgM、IgG或没有病原对应关系的免疫球蛋白。
- **纳入标准**：肺炎支原体IgM、病原特异性IgM抗体、IgM捕获法（语境明确）。
- **排除标准**：IgG单项、免疫球蛋白M总量、类风湿因子、双份血清滴度（另标）。
- **最小完整跨度**：`[IgM]`、`[IgM抗体]`。
- **允许关系**：检测方式。
- **病例判断作用**：仅为间接病原线索；单次血清IgM阳性不能等同呼吸道标本直接检出，也不能单独触发待专业复核。
- **正例1**：“血清肺炎支原体[IgM]阳性。”
- **正例2**：“鹦鹉热衣原体[IgM抗体]阴性。”
- **近似反例**：“免疫球蛋白M 2.1 g/L。”是总免疫球蛋白检测。
- **常见混淆与裁决**：阳性词仍单独标肯定；方法标签不承担结果极性。

### 10.5 抗体滴度/双份

- **Schema状态**：A/C。
- **医学定义**：以抗体滴度或急性期—恢复期双份血清的动态变化评价近期感染；成对标本出现规定倍数升高通常比单次抗体结果更有解释力。
- **项目操作定义**：标抗体滴度、双份血清、恢复期/急性期血清对照等方法性词组；“四倍升高”是动态结果，不纳入方法跨度。
- **纳入标准**：双份血清、抗体滴度、急性期与恢复期血清。
- **排除标准**：单次IgM、单次IgG阳性、没有病原语境的抗体浓度。
- **最小完整跨度**：`[双份血清]`、`[抗体滴度]`；“四倍升高”保留为病例证据，当前XML没有适合的检测结果标签时不私创。
- **允许关系**：检测方式。
- **病例判断作用**：提供时间动态的间接病原证据；仍需结合肺炎证据和索引事件。
- **正例1**：“[双份血清]肺炎衣原体抗体滴度四倍升高。”只把双份血清标为方法。
- **正例2**：“检测鹦鹉热衣原体[抗体滴度]。”
- **近似反例**：“血清肺炎支原体IgM阳性。”没有双份或滴度动态。
- **常见混淆与裁决**：若原文只有1:80等数值但未说明抗体或滴度，不自行补方法标签。

### 10.6 培养

- **Schema状态**：A/C。
- **医学定义**：将标本接种于适宜培养条件以分离可生长的细菌或真菌等活微生物；阳性结果仍可能代表定植或污染。
- **项目操作定义**：标培养、细菌培养、真菌培养、血培养等方法词；不标培养基、培养皿或只写“送检”而无方法。
- **纳入标准**：培养、痰培养、血培养、细菌培养、真菌培养。
- **排除标准**：培养基名称、药敏试验本身、拟送培养但尚未完成需同时连接假设性。
- **最小完整跨度**：方法一律只标 `[培养]`；在“血培养”中分别标 `[血]` 为标本、`[培养]` 为方法。不得把“血培养”整体作为方法跨度。
- **允许关系**：检测方式。
- **病例判断作用**：说明检出活微生物的传统方法；必须结合标本部位和临床语境判断相关性。
- **正例1**：“痰[培养]检出肺炎克雷伯菌。”
- **正例2**：“[血][培养]肺炎链球菌阳性。”血和培养分别标注并连接同一病原体。
- **近似反例**：“药敏提示对青霉素敏感。”未给出培养方法时不反推。
- **常见混淆与裁决**：“痰培养、血培养、真菌培养”中的标本/限定词不进入培养方法跨度；统一用最小词“培养”。

## 11. 病原体标签

病原体标签回答“文本提到了哪种微生物”，不回答“该微生物是否阳性、是否导致本次肺炎”。阴性、可疑、计划检查和他人结果中的病原名仍可标，但必须分别连接状态、时间、标本、检测方式或主体关系。下列医学定义用于辨别名称，不授权按症状或流行病学史反推病原。

### 11.1 新冠病毒

- **Schema状态**：A/C。
- **医学定义**：严重急性呼吸综合征冠状病毒2（SARS-CoV-2），是引起COVID-19的包膜RNA冠状病毒。
- **项目操作定义**：标SARS-CoV-2、新型冠状病毒、新冠病毒、2019-nCoV等明确名称；“新冠”仅在病原或检测语境明确时标。
- **纳入标准**：新冠病毒、SARS-CoV-2、新型冠状病毒、新冠核酸中的“新冠”。
- **排除标准**：普通冠状病毒、冠状动脉、COVID-19疫苗史；COVID-19疾病诊断若没有病原名，当前XML无疾病专用标签，不反造病原。
- **最小完整跨度**：`[SARS-CoV-2]`、`[新型冠状病毒]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出可触发待专业复核；病原名或既往阳性本身不能证明当前肺炎。
- **正例1**：“鼻咽拭子[新冠病毒]核酸阳性。”
- **正例2**：“[SARS-CoV-2]抗原阴性。”
- **近似反例**：“普通冠状病毒OC43阳性。”归普通冠状病毒。
- **常见混淆与裁决**：不要把“新冠后咳嗽”自动当当前病原阳性；按原文时间和状态标注。

### 11.2 流感病毒

- **Schema状态**：A/C。
- **医学定义**：正黏病毒科流感病毒，可引起季节性流感；临床常见甲型和乙型流感病毒，部分亚型具动物源性和公共卫生意义。
- **项目操作定义**：标流感病毒、甲/乙型流感病毒、influenza A/B及明确亚型病原名；不标“流感样症状”。
- **纳入标准**：甲流病毒、乙型流感病毒、Influenza A、H1N1/H3N2（明确流感亚型语境）。
- **排除标准**：副流感病毒、流感嗜血杆菌、流感样症状、流感疫苗。
- **最小完整跨度**：`[甲型流感病毒]`、`[Influenza A]`；保留型别/亚型。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出可触发待复核；是否为肺炎仍依赖肺部证据。
- **正例1**：“咽拭子[甲型流感病毒]核酸阳性。”
- **正例2**：“[乙型流感病毒]抗原未检出。”
- **近似反例**：“患者有流感样症状。”没有明确病原体。
- **常见混淆与裁决**：病历只写疾病简称“甲流”且没有获准的病原简称映射时，不画病原实体、不建状态关系；保留病例级原文证据并按病例规则判断。只有明确病原名称或锁定映射表批准的实验室简称才可连接状态。

### 11.3 呼吸道合胞病毒

- **Schema状态**：A/C。
- **医学定义**：呼吸道合胞病毒（RSV）是肺病毒科RNA病毒，是婴幼儿下呼吸道感染的重要病原，也可影响老年人和免疫低下者。
- **项目操作定义**：标呼吸道合胞病毒、RSV；不标“呼吸道病毒”泛称或“合胞”非病原用语。
- **纳入标准**：RSV、呼吸道合胞病毒、合胞病毒（上下文唯一明确时）。
- **排除标准**：人偏肺病毒、泛呼吸道病毒、RSV疫苗/预防抗体名称。
- **最小完整跨度**：`[呼吸道合胞病毒]`、`[RSV]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：明确呼吸道标本阳性可触发待复核；儿童常见但不能仅凭病原名判肺炎。
- **正例1**：“鼻咽拭子[RSV]核酸阳性。”
- **正例2**：“[呼吸道合胞病毒]抗原阴性。”
- **近似反例**：“呼吸道病毒九联检阴性。”未列出RSV名称时不补标。
- **常见混淆与裁决**：检测套餐标题与患者具体结果要成组；不能将套餐包含项误当阳性项。

### 11.4 腺病毒

- **Schema状态**：A/C。
- **医学定义**：人腺病毒是一组无包膜双链DNA病毒，可导致呼吸道、眼、胃肠道等多系统感染，部分型别可引起肺炎。
- **项目操作定义**：标腺病毒、人腺病毒、HAdV及明确型别；不从“腺体”或“腺样体”识别。
- **纳入标准**：腺病毒、HAdV、腺病毒7型等。
- **排除标准**：腺样体肥大、腺体、腺病毒载体疫苗语境、只写“DNA病毒”。
- **最小完整跨度**：`[腺病毒]`、`[腺病毒7型]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：明确呼吸道标本检出可触发待复核；其他部位检出需结合索引事件。
- **正例1**：“咽拭子[腺病毒]抗原阳性。”
- **正例2**：“[人腺病毒7型]核酸未检出。”
- **近似反例**：“患儿腺样体肥大。”不是病原体。
- **常见混淆与裁决**：粪便腺病毒阳性不自动视为肺炎病原证据。

### 11.5 人偏肺病毒

- **Schema状态**：A/C。
- **医学定义**：人偏肺病毒（hMPV）是肺病毒科RNA病毒，可引起上、下呼吸道感染，儿童、老年人和免疫低下者可出现较重疾病。
- **项目操作定义**：标人偏肺病毒、hMPV；原文仅写“偏肺病毒”但病原语境明确时可归入。
- **纳入标准**：人偏肺病毒、hMPV、偏肺病毒（明确为人感染病原）。
- **排除标准**：肺炎支原体、RSV、肺病毒科泛称。
- **最小完整跨度**：`[人偏肺病毒]`、`[hMPV]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确阳性可触发待复核；不能从临床症状推断。
- **正例1**：“鼻咽拭子[hMPV]核酸阳性。”
- **正例2**：“[人偏肺病毒]未检出。”
- **近似反例**：“肺炎支原体IgM阳性。”是另一病原。
- **常见混淆与裁决**：中文简称不统一时以检测报告的英文缩写和上下文为准，疑义记录而非猜测。

### 11.6 副流感病毒

- **Schema状态**：A/C。
- **医学定义**：人副流感病毒（HPIV）是一组副黏液病毒科RNA病毒，常分为1—4型，可引起哮吼、支气管炎和肺炎等呼吸道疾病。
- **项目操作定义**：标副流感病毒、HPIV及明确型别；不标流感病毒或“流感后”。
- **纳入标准**：副流感病毒、HPIV-1、3型副流感病毒等。
- **排除标准**：甲/乙型流感病毒、流感嗜血杆菌、副流感样症状。
- **最小完整跨度**：`[副流感病毒3型]`、`[HPIV-1]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确阳性可触发待复核；肺炎分类仍需肺部证据。
- **正例1**：“[副流感病毒3型]核酸阳性。”
- **正例2**：“[HPIV-1]未检出。”
- **近似反例**：“甲型流感病毒阳性。”归流感病毒。
- **常见混淆与裁决**：临床疾病简称“副流感”不能自动改写成“副流感病毒”病原实体；只有原文明确病原名称或标准病原缩写时标。

### 11.7 普通冠状病毒

- **Schema状态**：A/C。
- **医学定义**：本标签指常见季节性人冠状病毒，如229E、NL63、OC43和HKU1，通常与SARS-CoV-2等高致病性新发冠状病毒区分。
- **项目操作定义**：标普通/季节性冠状病毒及上述四种型别；不归入新冠病毒、SARS-CoV、MERS-CoV。
- **纳入标准**：HCoV-229E、NL63、OC43、HKU1、普通冠状病毒。
- **排除标准**：SARS-CoV-2、新冠病毒、MERS冠状病毒、冠状动脉。
- **最小完整跨度**：`[HCoV-OC43]`、`[普通冠状病毒]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确阳性可触发待复核；常见检出仍需结合症状和肺部证据。
- **正例1**：“鼻咽拭子[HCoV-OC43]阳性。”
- **正例2**：“[普通冠状病毒]核酸阴性。”
- **近似反例**：“SARS-CoV-2核酸阳性。”归新冠病毒。
- **常见混淆与裁决**：原文只写“冠状病毒”而无法判定类型时，不强行归入普通或新冠，应记疑难问题。

### 11.8 博卡病毒

- **Schema状态**：A/C。
- **医学定义**：人博卡病毒（HBoV）是细小病毒科DNA病毒，常在儿童呼吸道样本中检出，可与其他病毒共同检出，病原学意义需结合临床背景。
- **项目操作定义**：标人博卡病毒、HBoV及明确型别；不标普通“细小病毒”或“病毒”。
- **纳入标准**：人博卡病毒、HBoV、HBoV1等。
- **排除标准**：细小病毒B19、博卡样病毒泛称、病毒感染未明确种类。
- **最小完整跨度**：`[人博卡病毒]`、`[HBoV1]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出可触发待复核；共检出时不由标注员确定主病原。
- **正例1**：“鼻咽拭子[人博卡病毒]核酸阳性。”
- **正例2**：“[HBoV]未检出。”
- **近似反例**：“细小病毒B19 IgM阳性。”不是本标签。
- **常见混淆与裁决**：共感染列表中每个明确病原分别标注并连接同组方法、标本和状态。

### 11.9 鼻病毒

- **Schema状态**：A/C。
- **医学定义**：人鼻病毒是小RNA病毒科的一组RNA病毒，是普通感冒常见病原，也可引起下呼吸道疾病，尤其见于高风险人群。
- **项目操作定义**：标鼻病毒、人鼻病毒、HRV；不标鼻炎、鼻塞或“鼻部病毒”。
- **纳入标准**：人鼻病毒、HRV、鼻病毒A/B/C型。
- **排除标准**：鼻炎、鼻塞、鼻病毒样、肠道病毒（报告未区分时按原文处理）。
- **最小完整跨度**：`[人鼻病毒]`、`[HRV]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出可触发待复核；上呼吸道检出不单独证明肺炎。
- **正例1**：“鼻咽拭子[鼻病毒]阳性。”
- **正例2**：“[HRV]核酸未检出。”
- **近似反例**：“急性鼻炎伴鼻塞。”没有病原体。
- **常见混淆与裁决**：若报告写“鼻病毒/肠道病毒”且无法区分，不得任选其一；记录为Schema表达缺口并保留原文证据。

### 11.10 肠道病毒

- **Schema状态**：A/C。
- **医学定义**：肠道病毒属为小RNA病毒科的一组RNA病毒，包括柯萨奇病毒、埃可病毒和多种编号型别，部分可导致呼吸道或神经系统疾病。
- **项目操作定义**：标肠道病毒、Enterovirus及报告明确归属该属的型别；不从胃肠道症状推断。
- **纳入标准**：肠道病毒、EV71/EV-A71、柯萨奇病毒（若项目决定归一到上位标签）、埃可病毒。
- **排除标准**：腹泻、肠炎、鼻病毒、未明确病毒种类的“病毒性肠炎”。
- **最小完整跨度**：`[肠道病毒]`、`[EV-A71]`；保留具体型别。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出时可触发待复核；非呼吸道标本结果需结合索引事件。
- **正例1**：“咽拭子[肠道病毒]核酸阳性。”
- **正例2**：“[EV-A71]未检出。”
- **近似反例**：“急性肠炎伴腹泻。”不是病原名称。
- **常见混淆与裁决**：柯萨奇/埃可病毒是否统一到本标签应由项目映射表固定；标注员不得自行创建下位标签。

### 11.11 A族链球菌

- **Schema状态**：A/C。
- **医学定义**：A族链球菌通常指A组β溶血性链球菌，即化脓性链球菌（Streptococcus pyogenes），可引起咽炎、猩红热及侵袭性感染，肺炎较少见。
- **项目操作定义**：标A族/A组链球菌、化脓性链球菌、GAS；不标未分组的链球菌或肺炎链球菌。
- **纳入标准**：A族链球菌、A组β溶血性链球菌、S. pyogenes、GAS。
- **排除标准**：肺炎链球菌、B族链球菌、草绿色链球菌、链球菌属未分型。
- **最小完整跨度**：`[A组β溶血性链球菌]`、`[化脓性链球菌]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出可触发待复核，但咽部阳性可能反映咽炎或携带，仍需肺部证据。
- **正例1**：“咽拭子[A族链球菌]抗原阳性。”
- **正例2**：“[化脓性链球菌]培养阴性。”
- **近似反例**：“痰培养肺炎链球菌阳性。”归肺炎链球菌。
- **常见混淆与裁决**：只有“链球菌阳性”而无分型时，不强行归入A族。

### 11.12 百日咳鲍特菌

- **Schema状态**：A/C。
- **医学定义**：百日咳鲍特菌（Bordetella pertussis）是引起百日咳的革兰阴性细菌，主要感染呼吸道，临床可表现为阵发性痉挛性咳嗽。
- **项目操作定义**：只标原文明写的百日咳鲍特菌、B. pertussis；临床疾病诊断“百日咳”不是病原体提及，不自动转换。
- **纳入标准**：百日咳鲍特菌、Bordetella pertussis、B. pertussis。
- **排除标准**：副百日咳鲍特菌、其他鲍特菌、单纯百日咳样咳嗽。
- **最小完整跨度**：`[百日咳鲍特菌]`、`[B. pertussis]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：明确呼吸道标本检出可触发待复核；百日咳本身不等于肺炎。
- **正例1**：“鼻咽拭子[百日咳鲍特菌]PCR阳性。”
- **正例2**：“[B. pertussis]核酸阴性。”
- **近似反例**：“阵发性咳嗽，考虑百日咳。”只有疾病名，不画病原实体、不建状态关系；保留病例级原文证据。
- **常见混淆与裁决**：疾病“百日咳”和病原“百日咳鲍特菌”是不同概念；当前XML只有病原标签，疾病名不私自归一到病原。

### 11.13 肺炎链球菌

- **Schema状态**：A/C。
- **医学定义**：肺炎链球菌（Streptococcus pneumoniae）是有荚膜的革兰阳性双球菌，可引起肺炎、中耳炎、脑膜炎和菌血症，也可定植于鼻咽部。
- **项目操作定义**：标肺炎链球菌、S. pneumoniae、肺炎球菌；“肺炎”只是菌名组成，不另标肺炎诊断。
- **纳入标准**：肺炎链球菌、肺炎球菌、Streptococcus pneumoniae。
- **排除标准**：A族链球菌、链球菌属未分型、仅写肺炎诊断。
- **最小完整跨度**：`[肺炎链球菌]`、`[Streptococcus pneumoniae]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本、血培养或尿抗原阳性具有不同解释路径；任何一种都需结合肺部证据。
- **正例1**：“痰培养[肺炎链球菌]阳性。”
- **正例2**：“[肺炎球菌]尿抗原阴性。”
- **近似反例**：“诊断为社区获得性肺炎。”未出现病原名。
- **常见混淆与裁决**：鼻咽携带与致病不能由标注员判定；只记录标本和结果。

### 11.14 流感嗜血杆菌

- **Schema状态**：A/C。
- **医学定义**：流感嗜血杆菌（Haemophilus influenzae）是可定植上呼吸道的革兰阴性小杆菌，有荚膜型和无荚膜型，可导致肺炎及侵袭性疾病；它不是流感病毒。
- **项目操作定义**：标流感嗜血杆菌、H. influenzae；不标流感病毒或未定种的嗜血杆菌。
- **纳入标准**：流感嗜血杆菌、Haemophilus influenzae、H. influenzae。
- **排除标准**：甲/乙型流感病毒、副流感病毒、嗜血杆菌属未分型。
- **最小完整跨度**：`[流感嗜血杆菌]`、`[H. influenzae]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本明确检出可触发待复核，但定植可能需专业解释。
- **正例1**：“痰培养[流感嗜血杆菌]阳性。”
- **正例2**：“[H. influenzae]未检出。”
- **近似反例**：“甲型流感病毒核酸阳性。”不是细菌。
- **常见混淆与裁决**：中文“流感”在菌名内不可拆分成流感病毒标签。

### 11.15 军团菌

- **Schema状态**：A/C。
- **医学定义**：军团菌属为环境水体相关革兰阴性细菌，其中嗜肺军团菌可经含菌气溶胶传播并引起军团菌病，包括肺炎型疾病。
- **项目操作定义**：标军团菌、嗜肺军团菌、Legionella；不因空调、水系统暴露反推病原。
- **纳入标准**：军团菌、嗜肺军团菌、Legionella pneumophila。
- **排除标准**：军团菌病但未出现病原名称可按疾病语境记录疑问；水系统暴露；尿抗原项目无结果。

### 11.16 肺炎克雷伯菌

- **Schema状态**：A/C。
- **医学定义**：肺炎克雷伯菌（Klebsiella pneumoniae）是肠杆菌目革兰阴性杆菌，可定植于人体并引起肺炎、尿路感染、菌血症等机会性感染。
- **项目操作定义**：标肺炎克雷伯菌、K. pneumoniae；菌名中的“肺炎”不另标肺炎诊断。
- **纳入标准**：肺炎克雷伯菌、Klebsiella pneumoniae、K. pneumoniae。

### 11.17 肺炎支原体

- **Schema状态**：A/C。
- **医学定义**：肺炎支原体（Mycoplasma pneumoniae）是无细胞壁的细菌，可引起气管支气管炎和非典型肺炎；核酸、抗体等证据的时间窗和特异性不同。
- **项目操作定义**：标肺炎支原体、M. pneumoniae；菌名中的“肺炎”不另标肺炎诊断。
- **纳入标准**：肺炎支原体、Mycoplasma pneumoniae、M. pneumoniae。
- **排除标准**：支原体属未分种、生殖支原体、单纯“支原体感染”无法确认种类时记疑难。
- **最小完整跨度**：`[肺炎支原体]`、`[M. pneumoniae]`。
- **允许关系**：状态、时间、标本、检测方式。
- **病例判断作用**：呼吸道标本核酸明确检出可触发待复核；单次血清IgM阳性只是间接线索，不单独触发。
- **正例1**：“咽拭子[肺炎支原体]PCR阳性。”
- **正例2**：“血清[肺炎支原体]IgM阴性。”
- **近似反例**：“诊断肺炎。”没有病原体。
- **常见混淆与裁决**：必须同时查看标本与方法，避免把IgM套餐结果当呼吸道直接检出。

### 11.18 曲霉菌

- **Schema状态**：A/C。
- **医学定义**：曲霉属为环境中常见的丝状真菌，可造成过敏、定植、慢性肺曲霉病或侵袭性曲霉病；检出不等于侵袭性感染。
- **项目操作定义**：标曲霉菌、曲霉属及明确种名如烟曲霉；不标泛称霉菌、真菌或曲霉抗原项目而无菌名时的推断。

- **排除标准**：真菌未分型、霉菌、念珠菌、过敏性支气管肺曲霉病中若只写疾病缩写且无法定位病原名需按全文判断。

- **正例1**：“BALF培养[烟曲霉]阳性。”
- **正例2**：“[曲霉菌]核酸未检出。”
- **近似反例**：“真菌培养见霉菌生长。”未明确为曲霉。
- **常见混淆与裁决**：GM试验是曲霉相关抗原证据，但当前方法标签并未完整表达GM；保留原文并记录Schema问题，不补培养或核酸。

### 11.19 隐球菌

- **Schema状态**：A/C。
- **医学定义**：隐球菌属为有荚膜酵母样真菌，主要包括新生隐球菌和格特隐球菌，可引起肺部或中枢神经系统感染，尤其见于免疫功能受损者。

### 11.20 鹦鹉热衣原体

## 12. 关系标签

Label Studio界面中的连线可能表现为有向点击，但本项目评分会按两端的语义角色归一化，因此标注员不用记忆“先点哪一个”。“无向”只适用于点击操作层面，业务含义仍有角色：状态修饰目标、时间定位事件、测量组成归属指标、标本和方法归属同一病原检验。没有明确语义关联时，即使两个实体同句出现也不连线。

### 12.1 状态

- **Schema状态**：A/C。
- **医学定义**：不是医学实体；表示断言或主体提示词对某个临床概念的真实性、可能性、计划性、条件性或体验主体进行限定。
- **项目操作定义**：合法端点为“肯定/否定/可疑/条件性/假设性/与患者本人无关”与其实际修饰的症状、诊断、暴露、病原或检测事件。
- **纳入标准**：阴性—病原体、无—症状、不除外—诊断、拟—检查、母亲—症状。
- **排除标准**：普通肯定事实补造关系；同句但语法不修饰；把否定连到整句中最近而非实际目标的实体。
- **最小完整跨度**：关系无跨度；两端实体分别按各自规则标最小完整跨度。
- **允许端点和角色**：断言/主体提示词 ↔ 被修饰实体；点击方向忽略，端点角色不可交换。
- **病例判断作用**：防止把阴性、待排、计划或他人事件误当患者当前事实，是病例分类的关键关系。
- **正例1**：“肺炎支原体IgM[阴性]”：否定 ↔ 肺炎支原体。
- **正例2**：“[不除外]肺炎”：可疑 ↔ 肺炎诊断。
- **近似反例**：“无发热，咳嗽明显”：不得将“无”连接咳嗽。
- **常见混淆与裁决**：一个否定词明确支配并列多项时，分别建立多条状态关系；作用域不清时只连确定项并记疑难。

### 12.2 时间

- **Schema状态**：A/C；TimeExpression端点为R。
- **医学定义**：不是医学因果关系；表示时间提示词、时长或病程趋势对症状、诊断、暴露或检测事件的时间定位。
- **项目操作定义**：只连接原文明示的修饰关系，不因为同句、同段或相邻位置把一个时间词连到所有实体。
- **纳入标准**：1周前—发热、目前—咳嗽、仍有—气促、既往—肺炎。
- **排除标准**：报告日期机械连接全部结果；旧日期跨记录支配另一患者文本；医学常识推断先后。
- **最小完整跨度**：关系无跨度；时间实体保留完整相对参照。
- **允许端点和角色**：当前/既往/持续/进行性加重/TimeExpression ↔ 临床或检测事件。
- **病例判断作用**：判定索引事件归属、活动性和纯既往证据，是目标/非目标分流的重要关系。
- **正例1**：“[1周前]出现[发热]”：TimeExpression ↔ 发热。
- **正例2**：“治疗后[仍有][咳嗽]”：持续 ↔ 咳嗽。
- **近似反例**：“7月15日CT；8月1日复诊无咳嗽”：不能把7月15日连到无咳嗽。
- **常见混淆与裁决**：旧影像是否并入当前索引事件由指南“四项连续诊疗条件”决定，不能仅由一条时间连线解决。

### 12.3 测量

- **Schema状态**：A/C。
- **医学定义**：不是医学因果关系；表示数值、单位、比较符或原文阈值判断属于哪个生理指标。
- **项目操作定义**：每个测量组成连接其对应指标；一行多个生命体征时不得用最近距离代替字段归属。
- **纳入标准**：38.3—体温、℃—体温、92—SpO2、%—SpO2、＜—PaO2。
- **排除标准**：把日期数值连到体温；把氧流量连FiO2；把相邻指标的单位连错。
- **最小完整跨度**：关系无跨度；指标、值、单位分别标。
- **允许端点和角色**：数值/单位/比较符/阈值判断 ↔ 体温、呼吸频率、SpO2、PaO2或FiO2。
- **病例判断作用**：保留客观严重程度证据，避免数值错配改变病例优先级。
- **正例1**：“体温38.3℃”：数值38.3、单位℃分别 ↔ 体温。
- **正例2**：“SpO2＜92%”：比较符＜、数值92、单位%分别 ↔ SpO2。
- **近似反例**：“T 38.3，R 28”：不得把28连到体温。
- **常见混淆与裁决**：一项指标可有多个组成端点；不需要在数值与单位之间再连线。

### 12.4 标本

- **Schema状态**：A/C。
- **医学定义**：表示病原检测结果所来源的患者材料，决定结果是上呼吸道、下呼吸道、血液、尿液或胸膜腔证据。
- **项目操作定义**：仅连接同一检验记录组中的标本与病原体；检测套餐、换行或表格错位时先确认成组关系。
- **纳入标准**：痰—肺炎克雷伯菌、BALF—鹦鹉热衣原体、血清—肺炎支原体、尿—军团菌。
- **排除标准**：咳痰症状中的痰；跨行连接另一病原；影像胸水连接病原；未明标本的结果补造标本。
- **最小完整跨度**：关系无跨度。
- **允许端点和角色**：标本实体 ↔ 同组病原体。
- **病例判断作用**：区分直接呼吸道检出、间接血清学及其他部位结果，直接影响待复核入口。
- **正例1**：“痰培养肺炎克雷伯菌阳性”：痰 ↔ 肺炎克雷伯菌。
- **正例2**：“尿军团菌抗原阳性”：尿 ↔ 军团菌。
- **近似反例**：“咳黄痰；血培养肺炎链球菌阳性”：黄痰中的痰不得连接肺炎链球菌。
- **常见混淆与裁决**：不能仅靠字符最近匹配；以检验项目—标本—结果同组为准，无法复原时标 `lab_pairing_error`。

### 12.5 检测方式

- **Schema状态**：A/C。
- **医学定义**：表示病原证据由核酸、测序、抗原、抗体或培养中的哪一种技术获得，不同技术反映直接病原成分、活微生物或宿主免疫反应。
- **项目操作定义**：只连接同一检验记录组内的方法与病原体；结果词另外通过状态关系表达。
- **纳入标准**：PCR—流感病毒、mNGS—鹦鹉热衣原体、IgM—肺炎支原体、培养—肺炎克雷伯菌。
- **排除标准**：最近方法连接无关病原；把阳性作为方法；计划检查当作已经完成。
- **最小完整跨度**：关系无跨度。
- **允许端点和角色**：检测方法实体 ↔ 同组病原体。
- **病例判断作用**：区分直接检出和间接抗体证据，防止病例过筛或漏筛。
- **正例1**：“血清肺炎支原体IgM阳性”：抗体IgM ↔ 肺炎支原体。
- **正例2**：“BALF mNGS检出曲霉菌”：mNGS ↔ 曲霉菌。
- **近似反例**：“拟行流感PCR”：可连接方法与病原，但必须另连假设性，不能视为阳性证据。
- **常见混淆与裁决**：同一套餐内多个病原共用一个方法时，可对各病原分别连线；但只有明确属于该套餐的结果项才连接。

## 13. 病例表单与数据问题标签

这些是外部病例表单字段，不是文本实体，不在原文中画跨度。它们用于保障数据可解释性和隐私安全。

### 13.1 annotation_status：completed

- **Schema状态**：F。
- **医学定义**：非医学概念；表示该任务已完成允许范围内的医学标注和病例级判断。
- **项目操作定义**：文本已通过隐私检查，标注员完成四分类并按条件保存证据时选择。
- **纳入标准**：正常完成；即使判信息不足，只要不存在隐私阻塞，也为completed。
- **排除标准**：发现真实姓名、住院号等未脱敏信息后继续标注。
- **跨度/关系**：无文本跨度，无关系。
- **病例判断作用**：决定该记录能否进入医学一致性分母。
- **正例1**：完整病例判非目标并保存证据，status=completed。
- **正例2**：空文本判信息不足且0条证据，status=completed。
- **近似反例**：发现身份证号后完成病例判断；应立即停止并用blocked_privacy。
- **常见混淆与裁决**：completed不等于“数据优质”，可与truncated等非隐私问题共存。

### 13.2 annotation_status：blocked_privacy

- **Schema状态**：F。
- **医学定义**：非医学概念；表示任务因未去标识化信息而停止，以避免继续暴露或复制身份信息。
- **项目操作定义**：一旦看到真实姓名、住院号、身份证号、电话、详细住址或其他可识别字段，立即停止；`case_decision=null`、`evidence=[]`，且data_issue含privacy_block。
- **纳入标准**：任何未授权身份值残留，无论病例内容是否易判断。
- **排除标准**：合法的去标识化占位符、年龄/性别等允许研究字段、仅有任务ID。
- **跨度/关系**：无；不得复制身份值作为证据。
- **病例判断作用**：不进入医学一致性分母；重新脱敏后创建替代复标记录。
- **正例1**：正文含患者真实姓名，立即阻塞。
- **正例2**：页眉含完整住院号，立即阻塞。
- **近似反例**：“患者，男，65岁”；在项目允许字段范围内不构成privacy_block。
- **常见混淆与裁决**：不要为了说明问题而把身份值写入日志，只记录字段类型。

### 13.3 task_id

- **Schema状态**：F，外部病例表单无条件必填。
- **医学定义**：非医学概念；是去标识化任务记录的稳定唯一标识，用于把病例判断、实体、关系、反馈和裁决对应到同一任务。
- **项目操作定义**：由导入程序生成或传入，标注员只核对是否存在，不自行修改，不写入患者姓名、住院号等直接标识符。
- **纳入标准**：项目生成的匿名任务ID，如R2-001或不可逆随机ID。
- **排除标准**：患者姓名、身份证号、住院号、电话号码；同一任务每次显示不同ID。
- **跨度/关系**：无文本跨度，无关系。
- **病例判断作用**：不改变医学分类，但保证结果可追踪、可合并和可复标。
- **正例1**：`task_id="R2-001"`，同一任务在双标和裁决中保持不变。
- **正例2**：使用随机UUID且映射表由数据管理员隔离保存。
- **近似反例**：把住院号直接用作task_id；这可能暴露身份信息。
- **常见混淆与裁决**：task_id不是patient_id；纵向研究是否跨就诊合并应由数据方案另行定义。

### 13.4 evidence

- **Schema状态**：F，外部病例表单条件必填。
- **医学定义**：非医学概念；是支持病例级分类的最小去标识化原文片段集合，不是病历摘要或标注员推理文字。
- **项目操作定义**：目标、待复核、非目标保存1—3条；信息不足允许0—3条；blocked_privacy固定为空数组。每条只保留复现判定所需的最短完整语境。
- **纳入标准**：直接肺部证据、触发待复核的症状组合、明确排除/替代病因或可说明数据不足的残片。
- **排除标准**：整段病历、身份值、标注员新增医学结论、与分类无关的检查、超过3条的冗余证据。
- **跨度/关系**：不作为Label Studio实体；保留原文片段，可同时引用已标实体和关系。
- **病例判断作用**：使目标/待复核/排除结论可复核，也是错误分析和模型解释的依据。
- **正例1**：目标病例证据“CT提示右下肺炎症”。
- **正例2**：非目标证据“考虑心功能不全所致，无感染证据”。
- **近似反例**：“我认为像肺炎，应重点关注。”这是标注员推理，不是原文证据。
- **常见混淆与裁决**：信息不足的空文本可0条；隐私阻塞无论是否看见医学内容都必须0条，不能复制身份附近文本。

### 13.5 data_issue：empty_text

- **Schema状态**：F；v2.1.0外部数据问题枚举。
- **医学定义**：非医学概念；表示任务正文缺失、为空字符串、纯空格或去除分隔符后没有有效文字。
- **项目操作定义**：由导入门禁自动识别并记录，不进入普通医学标注队列；若在试标中保留，`annotation_status=completed`、病例判信息不足、evidence可为0条。
- **纳入标准**：空字符串、纯空格、只有换行或标点分隔符、text字段缺失并被转换为空。
- **排除标准**：自然短但语义完整的记录；“无不适”；只有一个明确无关计划。
- **跨度/关系**：无文本跨度，无关系。
- **病例判断作用**：不能进行医学判断，固定进入数据门禁/信息不足路径，不作为普通医学负例。
- **正例1**：`text=""`。
- **正例2**：正文只有空格和换行。
- **近似反例**：“建议电子喉镜。”短但完整，应判非目标而非empty_text。
- **常见混淆与裁决**：多个空任务不再额外标duplicate_text；先执行空文本门禁，再对非空文本去重。

### 13.6 data_issue：missing_context

- **Schema状态**：F；v2.1.0外部数据问题枚举。
- **医学定义**：非医学概念；表示文本通过“同前、如前、前症、继续原方案”等方式引用未随任务提供的内容，导致索引病种或关键证据缺失。
- **项目操作定义**：只有缺失引用可能改变病例四分类时记录并判信息不足；若当前文本自身已经明确无关或已含足够证据，可正常分类并保留该问题供回源。
- **纳入标准**：病史同前但未给病种；检查如前且旧检查可能含肺炎；前症复诊而前症未提供。
- **排除标准**：引用内容已在同任务内；当前短文本已明确无关计划；只是医学知识不足。
- **跨度/关系**：无文本跨度，无关系。
- **病例判断作用**：防止把可能属于连续肺炎疗程的缺失证据误排为非目标；触发回源补上下文和复标。
- **正例1**：“慢性病复诊，病史同前，维持治疗。”未提供病种。
- **正例2**：“前症复诊，检查如前。”缺失内容可能含肺炎直接证据。
- **近似反例**：“耳鼻喉复诊，建议电子喉镜。”索引行为明确，不因无长病史判missing_context。
- **常见混淆与裁决**：孤立旧无关检查不能替代当前索引病种；是否信息不足取决于缺失内容是否可能反转分类。

### 13.7 data_issue：none

- **Schema状态**：F。
- **医学定义**：非医学概念；表示未发现清单内的数据质量问题。
- **项目操作定义**：仅在没有其他data_issue时选择，不能与任何其他值共存。
- **纳入标准**：文本完整可归属、无重复拼接、检验可成组、无隐私残留。
- **排除标准**：任何已识别问题。
- **跨度/关系**：无。
- **病例判断作用**：表示无需数据修复，但不保证医学内容是目标病例。
- **正例1**：完整糖尿病复诊记录，判非目标且issue=none。
- **正例2**：完整肺炎住院记录，issue=none。
- **近似反例**：文本末尾明显截断；应选truncated。
- **常见混淆与裁决**：none不是“非目标”的同义词。

### 13.8 data_issue：truncated

- **Schema状态**：F。
- **医学定义**：非医学概念；表示记录在开始、中间或结尾被不自然截断，关键上下文可能丢失。
- **项目操作定义**：出现句子断裂、字段残缺、固定字符截取或关键结论缺失时选择；轻度截断仍可分类，严重到无法三分类则判信息不足。
- **纳入标准**：结尾半句、只保留检验前半段、固定1600字符切断。
- **排除标准**：原文自然简短；完整无关病例；医生本身使用省略语。
- **跨度/关系**：无。
- **病例判断作用**：提示证据不完整并可能触发信息不足或重取全文。
- **正例1**：“CT示双肺……”后文本终止。
- **正例2**：检验列表只剩项目名无结果列。
- **近似反例**：“无不适。”虽短但语义完整。
- **常见混淆与裁决**：是否信息不足取决于剩余文本能否可靠排入三分类，不由截断标签自动决定。

### 13.9 data_issue：duplicate_text

- **Schema状态**：F。
- **医学定义**：非医学概念；表示同一文本块或记录被重复拼入任务。
- **项目操作定义**：选择于非空全文精确重复，或同一任务内部大段重复，可能导致重复实体、病例分布和一致性计数失真。
- **纳入标准**：同一病程记录连续重复、同一检验表复制两遍、批次内去标识化全文哈希完全相同。
- **排除标准**：空字符串重复（先标empty_text）；不同日期真实重复描述；模板性相似但患者事实不同。
- **跨度/关系**：无。
- **病例判断作用**：不改变单例分类；主分析每个唯一文本只保留一个确定性代表，同时保留全部task_id审计映射。
- **正例1**：相同现病史连续出现两次。
- **正例2**：同一检验记录重复粘贴。
- **近似反例**：医生在入院记录和病程记录都提及发热；不一定是数据重复。
- **常见混淆与裁决**：精确重复可自动折叠；近重复只标记和抽查，不能仅凭模板相似自动删除。

### 13.10 data_issue：record_splice

- **Schema状态**：F。
- **医学定义**：非医学概念；表示来自不同患者、就诊或不连续记录的内容被错误拼接，导致索引事件无法可靠归属。
- **项目操作定义**：身份/性别/年龄矛盾、就诊号突变、叙事无过渡切换或多个患者模板合并时选择。
- **纳入标准**：同任务中患者性别突然改变；两个住院事件无标识拼接；跨患者检验混合。
- **排除标准**：同一患者多次就诊且边界清楚；会诊记录引用既往史。
- **跨度/关系**：无。
- **病例判断作用**：通常使证据归属不可靠，可能判信息不足并触发数据修复。
- **正例1**：前半为5岁男童，后半突然为72岁女性病史。
- **正例2**：两个无关联出院小结首尾相接。
- **近似反例**：同一患者“既往5年前肺炎”与本次就诊并存。
- **常见混淆与裁决**：不要用医学不一致替代数据证据；若只是诊疗矛盾而记录归属明确，可能是template_conflict。

### 13.11 data_issue：lab_pairing_error

- **Schema状态**：F。
- **医学定义**：非医学概念；表示检验项目、标本、方法、病原和结果因表格解析、换行或列错位而不能可靠配对。
- **项目操作定义**：只有无法根据原文复原哪一结果属于哪一项目时选择；可复原的复杂表格不算错误。
- **纳入标准**：阳性结果与病原行错位；标本列丢失；多个项目共用一个无法定位的结果。
- **排除标准**：套餐多病原但每行清楚；单项结果阴性；仅缺检测方法但病原结果明确。
- **跨度/关系**：无；不建立猜测性标本/方法关系。
- **病例判断作用**：防止把错误配对的阳性病原纳入病例；严重时判信息不足。
- **正例1**：项目列“流感/RSV”，结果只剩一个“阳性”且无法定位。
- **正例2**：解析后标本“血清”被移到另一病原行。
- **近似反例**：“流感A阴性，流感B阳性”每项清楚。
- **常见混淆与裁决**：不靠临床常识猜结果归属，优先让预处理修复。

### 13.12 data_issue：template_conflict

- **Schema状态**：F。
- **医学定义**：非医学概念；表示模板化字段、复制文字与患者个体化描述之间存在明确矛盾。
- **项目操作定义**：同一索引记录出现相互排斥的状态且无法由时间变化解释时选择。
- **纳入标准**：“无发热”与同刻“高热39℃”；模板写男性而正文明确女性；过敏史同时写有/无且无时间解释。
- **排除标准**：入院发热、治疗后退热；不同日期状态变化；真正的临床不确定性。
- **跨度/关系**：无。
- **病例判断作用**：降低证据可信度；若核心结论冲突无法裁决可判信息不足。
- **正例1**：同一体征表同时勾选呼吸困难“有”和“无”。
- **正例2**：模板“无发热”，同次测温40.0℃且无时间区分。
- **近似反例**：“昨日发热，今日无发热。”是时间变化。
- **常见混淆与裁决**：先检查时间和否定作用域，再判模板冲突。

### 13.13 data_issue：privacy_block

- **Schema状态**：F。
- **医学定义**：非医学概念；表示发现未充分去标识化的个人身份信息。
- **项目操作定义**：与annotation_status=blocked_privacy配套；发现后立即停止，不复制具体身份值。
- **纳入标准**：真实姓名、完整证件号、住院号、电话、可识别详细住址等。
- **排除标准**：合法研究编号；已一致替换的占位符；项目允许的非直接标识字段。
- **跨度/关系**：无。
- **病例判断作用**：阻断医学标注和一致性评分，保护研究对象隐私。
- **正例1**：页眉残留真实姓名。
- **正例2**：正文含手机号和详细地址。
- **近似反例**：“患者来自外省。”通常不足以直接识别个人。
- **常见混淆与裁决**：隐私阻塞优先于所有医学规则。

### 13.14 data_issue：other

- **Schema状态**：F。
- **医学定义**：非医学概念；用于清单未覆盖但会影响标注可靠性的数据问题。
- **项目操作定义**：只有现有枚举均不适合时选择，并在 `data_issue_note` 附一条不含身份信息、可供数据工程采取行动的简短说明。
- **纳入标准**：乱码、编码损坏、关键图像未转文字、语言无法识别等未列问题。
- **排除标准**：可归入truncated、record_splice、lab_pairing_error等已定义类别；单纯医学疑难。
- **跨度/关系**：无。
- **病例判断作用**：进入数据治理日志，必要时触发信息不足或重取数据。
- **正例1**：关键段落全部为乱码，说明“正文编码损坏”。
- **正例2**：只有“见附件影像”但附件缺失，说明“关键附件缺失”。
- **近似反例**：不确定支扩伴感染如何分类；这是指南疑难，不是data_issue。
- **常见混淆与裁决**：other不能代替empty_text或missing_context，也不能成为逃避医学裁决的兜底；没有data_issue_note时提交不合格。

### 13.15 data_issue_note

- **Schema状态**：F；当data_issue包含other时条件必填。
- **医学定义**：非医学概念；是对未被枚举覆盖的数据问题所作的简短去标识化说明。
- **项目操作定义**：只写问题类型和可执行修复动作，不复制身份值、长段原文或医学推理；建议不超过一句。
- **纳入标准**：正文编码损坏、关键附件缺失、报告仍待生成等没有专用枚举的问题。
- **排除标准**：空文本、缺上下文、截断等已有枚举；“我不确定是不是肺炎”等医学疑问。
- **跨度/关系**：无文本跨度，无关系。
- **病例判断作用**：不直接改变分类；为数据工程人员提供可路由的修复说明。
- **正例1**：`data_issue_note="关键影像附件未随任务提供"`。
- **正例2**：`data_issue_note="报告状态为待审核，需报告形成后重取"`。
- **近似反例**：`data_issue_note="患者可能是肺炎"`；这是医学推断，不是数据问题说明。
- **常见混淆与裁决**：说明必须去标识化；发现身份信息应走privacy_block，不能把身份值写进note。

## 14. 医学来源、适用边界与覆盖检查

### 14.1 医学来源层级

本字典的医学定义是面向标注的一句话综合，不替代临床指南。优先参考：国际/国家公共卫生机构的疾病与病原定义、标准医学主题词与检验医学共识、项目内经专家裁决的操作边界。若外部医学知识与本项目操作规则不同，**医学事实按权威来源理解，具体标注按锁定版项目规则执行，并提交疑难问题**。

- 肺炎一般概念：[CDC Pneumonia](https://www.cdc.gov/pneumonia/about/index.html)、[WHO Pneumonia in children](https://www.who.int/news-room/fact-sheets/detail/pneumonia)
- 呼吸道感染主题范围：[NLM MeSH: Respiratory Tract Infections](https://www.ncbi.nlm.nih.gov/mesh/68012141)
- 常见呼吸道病毒概览：[CDC Respiratory Illnesses](https://www.cdc.gov/respiratory-viruses/about/index.html)、[CDC Human Metapneumovirus](https://www.cdc.gov/human-metapneumovirus/about/index.html)
- 细菌/非典型病原：[CDC Mycoplasma pneumoniae](https://www.cdc.gov/mycoplasma/index.html)、[CDC Pertussis](https://www.cdc.gov/pertussis/hcp/clinical-overview/index.html)、[CDC Legionella](https://www.cdc.gov/legionella/hcp/clinical-overview/index.html)、[CDC Haemophilus influenzae](https://www.cdc.gov/hi-disease/hcp/clinicians/index.html)、[CDC Pneumococcal disease](https://www.cdc.gov/pneumococcal/hcp/clinical-overview/index.html)
- 真菌与衣原体：[CDC Aspergillosis](https://www.cdc.gov/aspergillosis/hcp/clinical-overview/index.html)、[CDC Cryptococcosis](https://www.cdc.gov/cryptococcosis/about/index.html)、[CDC Psittacosis](https://www.cdc.gov/psittacosis/hcp/clinical-overview/index.html)、[CDC Chlamydia pneumoniae](https://www.cdc.gov/cpneumoniae/hcp/clinical-overview/index.html)

### 14.2 提交前逐标签检查

1. 标签真实存在于锁定XML或外部病例表单；R标签未获批时不在Label Studio私创。
2. 医学定义只用于识别概念，没有替代原文生成事实。
3. 跨度是最短完整概念，不包含否定、时间、提示词、无关修饰和标点。
4. 阳性/阴性、当前/既往、计划/完成、患者/他人均通过显式实体和关系区分。
5. 标本、方法、病原和结果属于同一检验记录组；无法配对时不用距离或常识猜测。
6. 病原名不等于阳性，阳性不等于致病，致病不等于肺炎；病例级判断仍按指南证据门槛。
7. 目标、待复核、非目标必须保存1—3条最小去标识化证据；信息不足可0条。
8. 发现身份信息立即停止，病例判断为空、证据为空，并记录privacy_block。

### 14.3 本版变更边界

- 未新增或删除生产XML标签；
- 病例级仍为四分类且入口仍为B1—B6，但B3听诊异常和B5结构性肺病加重边界已澄清，受影响病例需定向回标；
- 未把任何病原体单独提升为肺炎确诊证据；
- 未把关系改成真正“无业务方向”的边；仅忽略界面点击方向，保留端点角色；
- 外部数据问题合同新增empty_text、missing_context和条件字段data_issue_note；生产XML没有修改；
- 不要求既有数据全量返工，只按Round 3裁决日志修正受影响病例和数据问题。
