- 主章节顺序为1—14。

## 3. 独立终审及修复

终审发现并已修复：

1. 补建v2.0.1 Schema锁，锁定指南、字典和两份生产XML哈希；
2. 补充 `task_id` 与 `evidence` 独立字段卡；
3. 将“拟行检查排除肺炎 / 不除外或待排 / 已排除”分别映射为假设性、可疑、否定；
4. 将条件性和假设性示例改为XML中存在的合法端点；
5. 尿培养仍保留尿标本来源，但明确不触发呼吸道阳性入口；
6. 普通抗原/尿抗原未写“快速”时不强行映射到抗原快速检测；
7. “四倍升高”按动态结果而非检测方式跨度处理；
8. 培养固定只标最小词“培养”，血/痰等另标标本；
9. 不从疾病简称“百日咳、副流感”推断病原实体；
10. XML标签标题采用精确ASCII括号，待复核入口统一为B1—B6。

## 5. 证据等级限制

此前100例结果是双医学标注智能体的探索性压力测试，只能说明规则可执行性和发现边界问题，不能替代真人标注者一致性或临床有效性验证。下一步仍须先做20例真人培训校准，再使用不少于30例独立验证集双标。
