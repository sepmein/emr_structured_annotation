# 标签效用与复杂度门禁

每个标签或关系必须回答以下问题：

1. 它会改变目标病例的纳入或排除吗？
2. 若不改变分类，会改变复核优先级吗？
3. 若只用于解释，人工标注是否比自动规则更可靠且确有审计需要？
4. 它能否仅靠原文和指南稳定识别，而不要求标注者作临床推断？
5. 它与已有标签是否有清晰、可复述的边界？
6. 是否在多个真实病例中出现，或虽少见但一旦漏标会造成严重误判？
7. 能否通过自动解析、章节默认值、属性或后处理代替新按钮？

## 处置规则

- 直接影响纳入/排除：优先保留为核心标签或属性。
- 仅影响优先级：保留少量、方向明确的类别，避免细分同义状态。
- 仅用于解释：原则上不增加人工标签；确有审计价值时说明成本收益。
- 无病例判断作用：删除、合并或不纳入v1。

## 时间模块的默认复杂度预算

在没有实证证明更多类别改善病例判断前，优先采用：

- 一个通用“时间表达”跨度，由后处理解析日期、时长或频率；
- 事件时态最多四类：当前、本次以往、计划、无法判断；
- 病程最多四类：持续/未改善、反复/慢性、加重、好转/已缓解；
- 章节提供默认时态，标注者只处理例外。

这是默认预算而非不可修改的医学真理。新增类别必须在变更提案中说明它改变了哪些病例判断，以及为什么不能由现有类别或自动化实现。
